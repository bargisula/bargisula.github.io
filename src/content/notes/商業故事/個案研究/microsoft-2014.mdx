## 決策背景

2014 年 2 月 4 日，Satya Nadella 接任微軟 CEO。上任首日對外宣告 「Mobile First, Cloud First」。

此時微軟內部的真實帳本如下：
- **Windows 部門**：2013 財年營收 192 億美元，營業利潤 92 億美元。它仍是公司的利潤引擎，也是所有人的獎金來源。
- **Cloud and Enterprise 部門**：營收 203 億美元，雖然包含 Azure，但當時 Azure 營收僅約 10 億美元且仍在虧損。
- **手機業務**：剛以 72 億美元收購 Nokia 手機業務，市佔率僅 3.4%。

<Callout type="insight">
**具體研究問題**
如果你是納德拉，接任 CEO 第 90 天，董事會要求你提交 2015-2017 三年戰略與資本配置案。你面前有兩條路：
- **A. 追加 100 億美元救 Windows Phone**：守住作業系統與終端入口。
- **B. 停止手機增量投資**：將 80% 新增 CAPEX 和研發轉向 Azure 與 Office 365。

你要用什麼財務指標說服「靠 Windows 起家」的董事會，同意方案 B？選 B 之後，未來 12 個月哪三個經營指標沒達標，你會被董事會罷免？
</Callout>

## 一、納德拉的底色：唯一沒拿過 Windows 獎金的 EVP

要理解納德拉為什麼敢選 B，必須看他與 Windows 部門的邏輯連結。

| 時間 | 崗位 | 關鍵動作與邏輯連結 |
| :--- | :--- | :--- |
| **2011-2014** | Server & Tools 總裁 | 把 Azure 從內部專案獨立 P&L。他親手驗證了兩件事：1. 企業客戶願意為雲付費；2. **訂閱制現金流（ARR）可以取代一次性授權**。這讓他腦中的成功模型是續費率，不是 License。 |
| **2011 以前** | Bing、線上服務 | 管過微軟最大虧損業務。這段經歷讓他對「燒錢換市佔但最後出不來」的路徑有創傷記憶。看 Windows Phone 會直接對標 Bing 的 ROI。 |
| **微軟之前** | Sun Microsystems | 任職於軟體部門。Sun 因死守 Sparc 工作站錯過 x86+Linux 浪潮而衰敗，形成他「平台轉移時，守舊資產等於自殺」的認知框架。 |

<Callout type="insight">
董事會其他人的簡歷是 Windows、Office、銷售。納德拉的簡歷是「在微軟內部把虧損的雲做成 10 億生意」。面對同樣的投資，兩方算的 IRR 分母完全不同。
</Callout>

## 二、數字說的故事

### 1. 微軟內部環境 (2013 財年)

| 項目 | 數字 | 備註 |
| :--- | :--- | :--- |
| Windows 部門營收 | 192 億美元 | YoY -4.3% |
| Windows 營業利潤 | 92 億美元 | 佔集團 41.2%，毛利率高達 47.9% |
| Cloud & Enterprise 營收 | 203 億美元 | 首度超過 Windows |
| Azure 估算營收 | 約 10 億美元 | YoY +150%，但單獨計算仍虧損 |
| Nokia 收購價 | 72 億美元 | 2014 Q2 完成，手機市佔僅 3.4% |
| 研發費用 | 104 億美元 | Windows 8 + Windows Phone 佔比超過 50% |

**組織事實**：當時實行「Stack Ranking」績效制，導致跨部門合作會降評。Office iPad 版早於 2012 年完成，卻因 Windows 部門反對（怕威脅 Surface）被雪藏至 2014 年。

### 2. 雲端產業外部環境 (2013-2014)

| 指標 | 事實數字 | 詮釋重點 |
| :--- | :--- | :--- |
| **全球 IaaS 市佔** | AWS 62%, Azure 8% | AWS 一家獨大，但仍有 38% 市場未被綁定 |
| **市場規模** | 2013 年 152 億美元 | YoY +45%，而傳統伺服器硬體營收在衰退 |
| **企業滲透率** | Fortune 500 僅 13% 上雲 | 87% 仍在地端，成長空間巨大 |
| **AWS 財務** | 2013 營收 38 億美元 | 營業利潤率 -3%，龍頭虧損說明「燒錢換市佔」是產業共識 |

### 3. 轉型成本表：董事會視角

| 成本類型 | 金額 / 時間 | 董事會風險 |
| :--- | :--- | :--- |
| **Nokia 減記** | 72 億美元一次性 | 已發生，屬於沉沒成本 |
| **裁員費用** | 16 億美元 (1.8 萬人) | 歐洲工會訴訟、品牌傷害 |
| **資料中心 CAPEX** | 3 年 150 億美元 | 若營收 CAGR < 30%，投資回收期將超過 7 年 |
| **Windows 授權流失** | 每年 10-15 億營收 | PC 出貨量下滑，需由雲 ARR 補上，否則總營收倒退 |

<Callout type="warning">
**數字間的剪刀差**：Windows Phone 若再投 100 億，最樂觀 2017 年拿 8% 市佔 = 32 億利潤。Azure 若投 100 億，2017 年營收達 50 億，按訂閱制 P/S 8 倍估算 = **400 億市值增量**。
</Callout>

## 三、決策框架：全員信中的「戰略文檔」

納德拉在 2014 年 7 月發布了著名的全員信，將鮑爾默的「Devices and Services」替換為「Productivity and Platforms」。

### 1. 重新定義核心資產
- **舊定義**：微軟 = Windows 公司。核心資產是 PC 桌面市佔。
- **新定義**：微軟 = Productivity + Platforms。核心資產是「人產生內容的總時間」。
- **財務翻譯**：PC 出貨下滑不可控，但全球 15 億知識工作者，每人每天工作 8 小時。只要微軟吃下 10% 時間，每人付費 5 美元/月，TAM 即達 **900 億美元 ARR**。

### 2. 資本配置公式：用「邊際 ROI」說話
- **砍掉什麼**：Nokia 手機、Windows 測試外包。一次性減記 72 億美元。
- **投入什麼**：資料中心、Office 365、Azure PaaS。CAPEX 從 35 億拉到 50 億/年。
- **邏輯對決**：內部測算 Windows Phone 再投 1 美元回報 0.3 美元；Azure 回報 1.7 美元。

### 3. 重設華爾街估值錨點
- **停止申報**：不再公布 Windows 授權銷量、PC 出貨綁定數。
- **新增披露**：商用雲 ARR、Office 365 席位數、Azure 運算使用量。
- **董事會邏輯**：軟體訂閱制 P/S 為 8-10 倍，傳統授權僅 3 倍。同樣的營收，講成 ARR 就能創造更多市值。

## 四、風險不對稱表：向董事會攤牌

納德拉在 2014 年 9 月內部戰略會使用的決策表：

| 選項 | 3 年現金投入 | 最好結果 | 最壞結果 | 風險承受度 |
| :--- | :--- | :--- | :--- | :--- |
| **A: 救手機** | 100 億美元 | 市佔 8%，損益平衡 | 市佔 3%，再虧 100 億 | **不可承受**：錯過雲窗口期，微軟會變下一個 Adobe 甚至是衰敗的 Sun。 |
| **B: All-in 雲** | 150 億 CAPEX | 2020 雲 ARR 500 億 | 雲繼續虧，但 Office 現金流可扛 5 年 | **可承受**：利潤表難看 3 年，但公司還有 Office 續命。 |

<Callout type="insight">
董事會最終接受點：方案 A 的最壞結果是公司戰略級死亡。方案 B 的最壞結果是「可控的虧損」。董事會選了後者。
</Callout>

---

## 五、組織與績效：消除內部阻力

1.  **廢除 Stack Ranking**：因為雲業務需要跨部門合作（例如 Office 要在各平台運行），不廢除就沒人願意配合 Azure 做適配。
2.  **P&L 合併**：把 Windows 併入 Cloud & Enterprise。Windows 從獨立利潤中心變成本中心，KPI 改成「幫助 Azure 拉客戶」。
3.  **人事節省**：用裁員節省的 10 億美元，直接補貼雲端的 CAPEX。

## 本案關鍵數字

- **72 億美元**：Nokia 手機業務的最終減記金額。
- **150 億美元**：三年內投入資料中心的預估 CAPEX。
- **44 億美元**：2014 Q4 首次披露的商用雲 ARR。
- **1.8 萬人**：2014 年 7 月宣布的裁員規模，為微軟史上最大。
- **13 倍**：2014 年微軟的 PE 值（轉型成功後一度超過 35 倍）。
- **900 億美元**：納德拉為董事會畫出的「生產力工具」潛在市場規模（TAM）。
