## 儀表板顯示什麼

每次執行 `/dsmm-pipeline` 後，儀表板會新增一張分析卡，包含：

| 區塊 | 內容 |
|---|---|
| 流水線步驟 | 五個市場的衝擊方向（高/中/低）與時間軸 |
| 資產含義表 | 10Y、DXY、股票、商品的方向與幅度 |
| 驗證檢查點 | 每個預測的到期日、閾值、實際值、CONFIRMED/WRONG |
| 關鍵觀察 | 下一個重要催化劑日期 |

逾期未驗證的 VCP 會標記 ⚠️ 警示。

---

## 如何執行

**啟動推演**（重大總經數據發布後）：
```
/dsmm-pipeline NFP 2026-07-02：+188K（預期 +150K）
```

**驗證到期 VCP**：
```
/dsmm-verify RUN-20260606-2320
```
