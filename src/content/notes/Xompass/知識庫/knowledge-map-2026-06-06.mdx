### TC-001　NFP 超預期 → 利率上行

**觸發條件：** 非農就業月增 > 市場預期 + 5萬人  
**最新觸發：** 2026-06-05，NFP +17.2萬（預期 +8.5萬），10年期公債升8bp → 4.55%

```
勞動市場：就業強勁，失業率低檔
→ 貨幣市場：降息預期下降，Fed put 後退
→ 金融市場：長端殖利率↑，估值折現率升高
→ 商品市場：融資成本升，資本支出計畫壓縮
```

**資產含義**

| 資產 | 方向 | 幅度 |
|---|---|---|
| 10年期美債 | 殖利率↑ | 每次事件 8–15bp |
| 高倍數成長股 | 估值壓縮 | NTM P/E 收縮 5–10% |
| GLW / 光纖基建 | 進場窗口縮窄 | 接近 4.6% 上限 |

**失效條件：** Fed 明確啟動降息循環 OR 失業率突破 5%

```
貨幣市場：BOJ 升息，JGB 殖利率上升
→ 金融市場：日本機構美債實質報酬接近零
→ 金融市場：1.1兆美元美債持倉結構性減碼
→ 貨幣市場：長端殖利率上行壓力，非景氣循環驅動
```

**失效條件：** BOJ 暫停升息 OR 美日利差縮窄至換匯成本以下（美債殖利率 < 4%）

**觸發條件：** 10年期殖利率單月上行 > 25bp（目前 8bp，閾值未到）

```

→ 金融市場：MBS 存續期自動延長 → 持有機構存續期超標
→ 金融市場：規則強制賣長債（避險操作）
↻ 長債供給增加 → 殖利率再升 → 自我強化循環
```

**資產含義**

| 資產 | 方向 | 幅度 |
|---|---|---|
| 30年期美債 | 殖利率↑↑ | 自我強化，每 25bp 觸發約 500–800 億機械賣出 |
| MBS 資產 | 價格↓ | 負凸性放大跌幅 |

**失效條件：** Fed 宣布購買 MBS OR 利率下行超過 30bp OR 屋主還款率回升
