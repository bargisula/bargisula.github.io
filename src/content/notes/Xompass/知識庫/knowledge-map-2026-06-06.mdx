### TC-001　NFP 超預期 → 利率上行

**觸發：** 非農就業月增 > 市場預期 + 5萬人

```
勞動市場：就業強勁
→ 貨幣市場：降息預期下降
→ 金融市場：長端殖利率↑，估值折現率升
→ 商品市場：融資成本升，資本支出壓縮
```

**資產含義：** 10年期公債殖利率每次事件 +8–15bp；高倍數成長股 NTM P/E 收縮 5–10%；GLW 進場窗口縮窄（接近 4.6% 上限）

**失效：** Fed 明確啟動降息 OR 失業率突破 5%

---

### TC-002　日本結構性減碼美債

**觸發：** JGB 殖利率 > 1.2% AND 美日換匯成本 > 3.5%（現況：JGB 1.5%，換匯成本 4%+）

```
貨幣市場：BOJ 升息，JGB 殖利率上升
→ 金融市場：日本機構美債實質報酬接近零（0.55%）
→ 金融市場：1.1 兆美元美債持倉結構性減碼
→ 貨幣市場：長端殖利率上行壓力，非景氣循環驅動
```

**資產含義：** 10年期公債估計貢獻 15–30bp 結構性抬升；每次 BOJ 升息後日圓緩步升值

**失效：** BOJ 暫停升息 OR 美債殖利率 < 4%

---

### TC-003　MBS 凸性自我強化

**觸發：** 10年期殖利率單月上行 > 25bp（目前 8bp，未達閾值）

```
金融市場：利率上行 → MBS 現金流延後 → 存續期延長
→ 金融市場：持有機構被迫賣長債（規則避險）
↻ 長債供給增加 → 殖利率再升 → 循環
```

**資產含義：** 30年期公債自我強化下行；每 25bp 觸發約 500–800 億美元機械賣出

<Callout type="warning">
信心值 0.58：機制邏輯完整，但從未真實觸發。目前距離 25bp 閾值仍有 17bp，不宜作為主要配置依據。觀察點：CPI 2026-06-10。
</Callout>

**失效：** Fed 購買 MBS OR 利率下行超 30bp

---

### TC-004　AI Capex 擴張 → AD 右移

**觸發：** 任一超大雲端單季 capex 指引 QoQ > 10%

```
商品市場：Hyperscaler AI 資本支出加速 → I 大幅上升
→ 商品市場：AI 供應鏈（晶片/光互連/電力）需求拉升
→ 勞動市場：技術人才工資上升，AI 基礎設施工人需求增
→ 金融市場：供應商股價重估，backlog 擴大
```

**宏觀含義（AD 框架）：** AI capex 目前是 AD 的正向衝擊，屬建設期。供給端（AS）尚未跟上，短期方向 = 商品價格上行 + 勞動市場局部緊張。

**資產含義：** NVDA / AVGO 直接受益；COHR / GLW / CIEN 光互連二階受益；VRT / Eaton 電力基建

**三來源確認（信心值 0.88 來源）：**
- AVGO Q2 FY2026：AI 半導體 +143% YoY，訂單/出貨 > 3倍，Q3 指引 160億美元
- CIEN Q2 FY2026：hyperscaler capex 上調，能見度延伸至 2027+
- Regime（2026-05-22）：CMO 確認 AI_capex_cycle

**失效：** 超大雲端 capex 連續兩季下修 OR AI ROI 敘事崩潰

## 三、架構說明

<Callout type="insight">
**下一步設計：5 市場 Agent 流水線**

目前傳導鏈是靜態 JSON（分析一次就固定）。計畫中的架構是動態流水線：

事件進入 → 金融市場 Agent 分析 → 輸出 `market_change.json` → 貨幣市場 Agent 讀入繼續分析 → … → 財政動態 Agent → 彙整輸出

每個 Agent 只負責一個市場，輸出「本市場受影響的指標 / 方向 / 時間軸 / 傳給誰」。這樣財政動態自然成為最後一棒，不需要獨立建鏈。

**掃描來源：** CIEN（再掃：2026-08-01後）、COHR（2026-08-01後）、AVGO（2026-09-01後）
</Callout>
