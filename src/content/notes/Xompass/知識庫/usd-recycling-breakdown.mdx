## 核心命題

美元體系的穩定依賴「美元回流閉環」：美國進口 → 美元流出 → 貿易盈餘國（日、中、海灣）持有美債 → 美元回流 → 美國低成本融資。

當這個閉環在多個節點同時斷裂，美國必須靠**更高殖利率**（而非美元霸權紅利）才能賣出同等數量的債，形成長期增長稅，且有財政主導陷阱風險。

**這是結構性退潮，不是週期性波動。**

---

## 三條拋債動機（同時啟動）

```
A. 通膨預期升高       → 持債者拋售（實質報酬惡化）
B. 去美元化           → 央行儲備多元化拋售（戰略轉向）
C. EM 匯率危機        → 緊急拋售保護幣值（土耳其型）
```

A/B/C 三條動機的**來源不同，但結果相同**：美債邊際需求下降，殖利率必須上升以清算供需缺口。

## 傳導鏈

```
觸發：外資官方儲備機構大規模撤出美債
  │
  ├─ 需求側缺口 → 殖利率上升（term premium 擴大）
  │     10Y: 4.6%、30Y: 5.2%+（2026/5，2007 年以來最高）
  │
  ├─ Fed 政策壓力：
  │     通膨數據惡化（CPI 3.8%、PPI 6.0%）
  │     × 新主席 Warsh（鷹派文化）就任
  │     × 鴿派 Waller 轉向（就任同日）
  │     → Fed 升息機率 70%（CME, 2026/5）
  │
  ├─ 財政滾債成本暴增：
  │     更高利率 × 龐大存量債務
  │     → 利息支出占財政比例上升
  │     → 財政赤字更難收斂
  │
  └─ 路徑分叉：
        A. 更高殖利率自我清算（通縮性緊縮）
             → 壓抑資本投資、房地產、消費信貸
             → 長期增長速度下降
        B. Fed 被迫貨幣化（QE 救債市）★
             → 通膨惡化 → 實質利率更負
             → 更多外資撤退（惡性循環）
             → 財政主導陷阱（歷史上極難退出）

★ B 路徑是市場當前低估的尾部風險
```

## 強化節點：Fed 信心溢酬（政治干預風險）

**觸發事件（2026-05-22）：** Warsh 在白宮宣誓（1987 年葛林斯潘以來首位，象徵政治從屬）。川普同日在造勢場公開預告「利率很快下降」，前後矛盾但皆為真實訊號。

### Warsh 的三難困境

<Callout type="warning">

| 選項 | Warsh 的行動 | 市場反應 | 殖利率結果 |
|---|---|---|---|
| A：依數據升息 | 川普公開批評 | 「Warsh 能撐多久」不確定性溢酬 | 長端上升 |
| B：屈服降息 | 市場讀為「Fed 不再對抗通膨」| 外資拋售加速 | 長端反而更高 |
| C：按兵不動 | 不確定性本身就是 term premium 來源 | 持續不確定溢酬 | 長端居高 |

**三個選項，長端殖利率都不會降。**

</Callout>

### 最危險的不是「被迫降息」

是**「市場無法區分 Fed 決策是數據驅動還是政治驅動」**。

一旦這個不確定性被定價，每次 FOMC 都包含一個**永久性的政治不確定溢酬**：

```
Fed 信心溢酬 → term premium 結構性擴大
  → 長端殖利率高於通膨預期應有水準
    → 即使通膨改善，10Y 也可能無法回到 4.3% 以下
      → GLW 等資本密集股的進場條件被永久推遲

美元悖論（反常訊號）：
  Warsh 升息 + 美元指數不升甚至下跌
  → 市場在拋棄「美元資產本身」，不只是利率調整
  → 去美元化加速確認
```

這個節點是 `usd-recycling-breakdown` 主鏈的**加速器**，不是獨立事件：兩個力量同向疊加（外資退出 + 政治不確定溢酬），外資退出的理由從「利率差」升級為「美元體制可信度」。

## 政策選項評估

<Callout type="data">

| 選項 | 有效性 | 說明 |
|---|---|---|
| 增加石油供給 | 有效但有限 | 打供給端方向正確，但 energy→PCE 第二波已在傳導，油供增加壓不住；大規模增產需 6-12 個月 |
| 關稅 | 無效，可能反效果 | 關稅解決貿易赤字，財政赤字靠稅收與支出結構——兩個不同缺口；關稅實質是消費稅，短期推高通膨 |
| 強制各國投資美國 | 短期有效，長期加速自我毀滅 | 被脅迫的流入是脆弱的，槓桿失效即刻反轉；1970s 石油美元是自願合作，現在靠脅迫，品質截然不同 |
| **AI 生產力紅利** | **唯一真正出口** | GPT 第二階段（2028-2035）TFP 增速提升 → 稅基擴大 → 財政赤字靠成長稀釋；但時間差是問題 |

</Callout>

```
債市壓力：現在（2026）
AI 生產力紅利：2028 年後
危險視窗：2026-2028（最需要警戒）
```

## 歷史先例

| 事件 | 機制 | 結局 | 類比含義 |
|---|---|---|---|
| 英國 2022 Truss 時刻 | 擴張財政 × 升息方向矛盾 → 英鎊+英債同時崩潰 | 英格蘭銀行緊急 QE，Truss 45 天下台 | 財政主導陷阱可在幾週內引爆；美國版本時間尺度更長（數月至數年）但方向相同 |
| 日本 YCC 2022-2024 | 人工壓住殖利率上限 | 2024 年被迫放棄，10Y 從 0.25% 升至 1.5%+ | 貨幣化（B 路徑）只能延緩，無法避免最終調整 |
| 1970s 美國滯脹 | 越戰財政赤字 + 石油衝擊 + 尼克森關閉黃金窗口 | Volcker 升息至 20% 才打破通膨預期 | 若通膨預期失錨，所需修正利率遠高於市場預期 |
