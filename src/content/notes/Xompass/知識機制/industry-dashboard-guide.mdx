## 儀表板位置

👉 **[開啟産業分析儀表板 →](/industry)**

---

## 儀表板顯示什麼

每次執行 `/industry-pipeline` 後，儀表板會新增一張分析卡，包含：

| 區塊 | 內容 |
|---|---|
| 論點主張 | IF-THEN-BECAUSE 格式的一句話論點 |
| 信心進度條 | 整體信心值（0-100%） |
| 四維結論卡 | 需求 / 供給 / 競爭 / 技術替代各自一句話 |
| Kill Switch | critical / major 殺手條件數量 |
| 驗證檢查點 | 各維度 VCP 的到期日與裁定狀態 |

---

## 如何執行

**啟動產業分析**（法說後、重大新聞後、或主動分析）：
```
/industry-pipeline 光傳輸系統 "CIEN 法說：backlog 創新高"
/industry-pipeline AI 伺服器供應鏈
```

**驗證到期 VCP**（財報發布後）：
```
/industry-verify IND-20260606-OPT
```
