### NVIDIA Harness + Agent OS 框架

**Harness 定義（NVIDIA 官方）：**
> "Autonomous agents require a software layer called a harness to turn the model into an agent with functions like orchestration, context, memory, tool use and security."

**作業系統類比：**

| 1990 年代 PC | 2026 年 AI |
|---|---|
| 硬體（CPU/RAM） | 模型（Claude/GPT） |
| 作業系統（Windows） | Harness / Agent OS |
| 應用程式 | AI 應用（財報分析器/客服 agent） |

誰定義 runtime 標準，誰收所有 agent 的過路費。三方競爭：NVIDIA（硬體往下）、Microsoft（Windows 原生）、Anthropic（model API 往上攻 control plane）。

**AVGO 的機會：** 不是自己做 Harness，而是成為所有 Harness 必須跑在上面的硬體地基。加入 FUSION = 讓 Tomahawk 成為 NVIDIA Harness 生態強制標準組件。等同 Intel 對 Windows 的關係。

### 新 Insight：INS-2026-06-05-006

**命題：** 「AI agent 時代的平台標準制定者將取得持續性過路費收益；硬體層的標準制定者比軟體層更難被替代」

**因果鏈：** AI 模型無法直接執行任務 → harness 層為必需 → harness 需向下定義異質計算協作介面 → 介面標準制定者收過路費 → 硬體介面切換成本是軟體的 10 倍以上 → 硬體標準更難被替代

**Tier：** L1，confidence 0.65
**升格條件：** AVGO 加入 FUSION 宣布（第二次獨立事件驗證）
