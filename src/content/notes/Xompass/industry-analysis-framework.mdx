## Step 0：執行前確認

**在開始寫作前，必須回答這個問題：**

> 什麼具體事件，讓這個題目在「本週」值得分析？

| 合法觸發 | 不合法觸發 |
|---|---|
| 財報發布 | 「這個題目很重要」 |
| 重大交易 / 入股 | 「市場關注度高」 |
| 技術突破公告 | 「長期趨勢向好」 |
| 政策或法規變化 | 「近年來 AI 快速發展」 |
| 競爭對手重大動作 | 無日期的模糊訊號 |

**沒有明確觸發事件 → 改做快篩，不做完整產業分析。**

## Step 1：模式選擇

```
topic 是公司 ticker → Company 模式
  模組 2 = 該公司財報快照 + 模組 3 = 核心護城河

topic 是產業 / 技術 → Industry 模式
  模組 2 = 需求分析，模組 3 = 供給五力
```

兩種模式的七模組結構相同，模組 2–3 內容不同。

---

## 七模組規範（Industry 模式）

### 模組 1｜產業定位（含觸發事件）

- 一句話：這是什麼（規模、主要用途）
- **觸發錨點**：具體事件 + 日期，這是文章存在的理由
- 主要替代方案比較表格（`Callout type="data"`）

### 模組 2｜需求分析

<Callout type="warning">
「需求強勁」不算需求分析。必須量化到**誰買 / 買多少 / 買多久**，並說明需求是加速還是減速。
</Callout>

- 付款方 + 規模 + 能見度
- 需求斜率（增速的方向與數字）
- TAM + CAGR（來源 + 年份）
- 需求剛性：必選 vs 可選，判斷理由一句

### 模組 3｜供給分析（含五力）

五力分析必須導出結論，不是填格子：

| 力 | 必填內容 |
|---|---|
| 現有競爭者 | 前三名市占合計 |
| 進入壁壘 | 建廠成本 / 認證年限 / 專利數 |
| 買家議價力 | 前三大客戶佔比 |
| 替代品威脅 | 替代技術名稱 + 效費比差距 |
| 供應商議價力 | 關鍵原料來源集中度 |

<Callout type="insight">
五力分析結尾**必填**：利潤池沉澱在哪一層？為什麼？這是整個供給分析唯一有投資意義的結論。
</Callout>

### 模組 4｜技術分析

- 現行技術的物理極限（數字）
- 下一代技術：名稱 + 成熟時間點（季度）+ 效能提升幅度
- 技術轉折點佔位者：誰領先、領先幅度量化
- 瓶頸說明（`Callout type="warning"`）：哪個環節卡住整條鏈

### 模組 5｜供應鏈地圖

- 上下游層次：原料 → 核心製程 → 組件 → 系統
- 每一層主要玩家（**台股直接標在鏈條裡**：代號 + 角色）
- 受益程度：高（直接受益、難替代）/ 中 / 低
- 格式：`Callout type="data"` 表格

### 模組 6｜催化劑與時程

- 未來 3–6 個月，3–5 個具體催化劑
- 時間軸表格：時間 ｜ 事件 ｜ 影響方向（↑ / ↓ / 觀察）
- 至少一個 1–2 個月內可觀察的最近期催化劑
- **至少一個下行催化劑，含量化幅度**（如「需求遞延 2 季 → 相關股 -15% 至 -25%」）

### 模組 7｜個股點名

- 美股：最多 3 家，每家一句論點（含數字）
- 台股：已在模組 5 標位；此處補充受益評級簡述
- **禁止**：做個股完整估值（那是 Company 模式的範疇）

### 結尾（必填）

`Callout type="quote"` — 一句話原創洞見

<Callout type="warning">
結尾洞見不能是文章總結。必須是「市場低估了 X」或「這個局面讓人重新思考 Y」的視角，不能出現在公司 IR 或官方媒體中。
</Callout>

## 分析深度標準

每個模組的輸出必須包含三件事：

<Callout type="data">

| 要求 | 說明 |
|---|---|
| 數據錨點 | 具體數字，附來源年份 |
| 癌點 | 這個正面信號的弱點（散戶常漏掉的） |
| 結論句 | 這個維度加分還是扣分，一句話判斷 |

</Callout>

文章結尾必須有一句「**論點失效條件**」：在什麼具體情況下整個邏輯失效。

## 寫作風格規範

<Callout type="data">

| 禁止 | 要求 |
|---|---|
| 「可能受益」「或許會」 | 明確說方向，或說「目前無法確認」 |
| 「近年來 AI 快速發展」 | 具體觸發事件 + 日期 |
| 「技術壁壘高」 | 「複製 InP 垂直整合需要 5–7 年、逾 30 億美元資本支出」 |
| 用 IR 語言改寫 | 直接跳過，找數字 |
| 「很高的成長率」 | 「YoY +73%」 |
| 「競爭激烈」 | 「前三名市占合計 78%，新進者需 5 億美元建廠 + 3 年認證」 |

</Callout>

**目標語氣範例：**
> 「NVIDIA 的 20 億美元不是財務投資，是供應鏈保險。」
> 「利潤不在做電纜的組裝廠，在掌握特殊包層製程專利的那一層。」

## 品質驗收清單

CEO push 前對照確認：

- [ ] 模組 1 有具體觸發事件（含日期）
- [ ] 模組 2 需求量化到「誰買 / 買多少 / 買多久」
- [ ] 模組 3 有五力結論（利潤池在哪一層）
- [ ] 模組 4 技術極限有數字，下一代有時間點
- [ ] 模組 5 供應鏈每一層有玩家，台股有角色標示
- [ ] 模組 6 有下行催化劑 + 量化影響幅度
- [ ] 結尾有 `Callout type="quote"` 原創洞見
- [ ] 沒有「可能」「預計」「或許」替代判斷
- [ ] 數字有來源可追溯
- [ ] 無裸 `$數字`
