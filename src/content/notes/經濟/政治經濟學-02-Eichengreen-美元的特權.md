## 一個 1960 年代的詞，為什麼 2011 年還在用

「Exorbitant Privilege（過度特權）」——這是法國財政部長德斯坦 1960 年代罵美國的原話。意思是：美元是全球儲備貨幣，讓美國可以用幾乎沒有風險溢價的利率無限借錢，然後全世界掏錢幫它買單。

Barry Eichengreen 把這個詞拿來當書名，不是在替美國辯護，也不是在罵美國。他要問的是：**這個特權從哪裡來，現在還剩多少，以及美國能否把它維持下去——還是特權本身正在腐蝕美國的基礎。**

他的工具不是數學模型，而是 800 年的金融歷史。IMF、聯準會都把他當顧問——「你跟他吵歷史，你輸」那種。

---

## 一、特權的具體內容：三張王牌

| 特權 | 機制 |
|------|------|
| **借自己的錢** | 中國買美債，等於用人民幣換美元，再借給美國消費。美國的外債是以自己能印的貨幣計價 |
| **通膨賴帳** | 美元貶值 10%，全世界儲備資產縮水，美國的外幣負債自動減輕——不是違約，是隱性重組 |
| **制裁當武器** | 把一國踢出 SWIFT，它的美元資產就凍結。2022 年俄羅斯是真實示範，沒有任何其他貨幣有這個能力 |

這三張牌加在一起，讓美國可以長期維持龐大的經常帳逆差，而不用面對一般國家逆差太大就會遇到的貨幣危機。

## 二、美元霸權三部曲

### 第一幕：英鎊霸權（1914 年前）

倫敦是全球金融中心，英鎊佔全球貿易結算的約 60%。英國的秘密不是軍事，而是制度：倫敦的票據交換所、保險市場（勞合社）、股票市場，形成全球沒有替代品的金融基礎設施。

一戰摧毀了這個基礎：英國從世界最大債權國變成債務國，向美國借了天文數字的戰債。美國從此取代英國成為全球最大債權國，但美元霸權沒有立刻接班——原因是美國 1920–30 年代不願意承擔「全球最後貸款者」的責任，讓大蕭條得以蔓延。

**教訓：霸權不只需要錢，還需要承擔維護全球體系的責任和成本。**

### 第二幕：布列敦森林（1944–1971）

1944 年，美國持有全球 70% 的黃金，答應以「35 美元 = 1 盎司黃金」無限兌換。其他國家貨幣釘美元，美元釘黃金——這是一個階層式的固定匯率體系。

Eichengreen 點出一件事：布列敦森林能運作，不是因為匯率規則設計得好，而是因為**美國 GDP 佔全球 50%，海軍有 1,000 艘艦艇**。制度的威信來自背後的實力，不是條文本身。

特里芬難題在 1960 年代逐漸顯現：全世界要美元流動性 → 美國必須長期逆差 → 逆差累積讓外國對美國黃金儲備產生懷疑 → 戴高樂派軍艦去紐約把美元換成黃金運回巴黎。1971 年，美國黃金存底從 1944 年的全球 70% 降至約 22%，尼克森關閉兌換窗口，布列敦森林終結。

### 第三幕：後布列敦森林（1971–至今）

黃金錨沒了，美元為什麼還是霸主？Eichengreen 列出四根支柱：

| 支柱 | 說明 |
|------|------|
| **慣性** | 全球貿易計價、石油合約、衍生品清算全用美元，轉換系統的成本遠大於繼續用美元的成本 |
| **市場深度** | 美債市場超過 27 兆美元，歐元區債市碎裂成德法義各國，人民幣不可自由兌換，沒有替代品 |
| **危機時的安全感** | 2008 年美國自己闖禍，全世界反而買美債避險——因為只有美國敢印足夠的錢來救全球體系 |
| **網路效應** | 大家都用美元，你不用就被孤立。轉換需要全球協調，單一國家沒有動機先跑 |

## 三、特權的代價：美國自己也痛

Eichengreen 最重要的貢獻，是把「美元霸權是美國的紅利」這個直覺翻轉過來：

**特里芬難題 2.0**

```
世界要美元流動性
→ 美國必須長期逆差
→ 逆差 = 進口多於出口
→ 製造業空心化
→ 鐵鏽帶失業
→ 川普、貿易保護主義、政治撕裂
```

這不是巧合，這是霸權貨幣的結構性成本。英國 1914 年後也走過同樣路徑——帝國的金融義務讓國內工業漸漸失去競爭力。

更具體的例子：2000–2010 年，中國購買了超過 1 兆美元的美債，壓低了美國的長期利率。低利率讓房貸變便宜 → 房市泡沫 → 2008 金融危機。所以美元霸權間接製造了美國有史以來最嚴重的金融危機之一。

**特權不是免費午餐，它的帳單以另一種形式寄回來。**

## 四、美元會死嗎：三個劇本

### 劇本一：多極儲備，緩慢失血（機率 40%）

歐元、人民幣、黃金各佔全球儲備的約 20%，美元降至 40%。類似 1914–1944 年英鎊美元共治的過渡期。

前提條件：
- 歐元區建立財政聯盟，歐洲公債市場統一（目前仍是政治禁忌）
- 中國資本帳全面開放，人民幣可自由兌換（目前無明確時間表）

結果：美國借款利率上升 1–2 個百分點，鑄幣稅消失，財政壓力增加。不會崩，但特權大幅縮水，美國政府赤字空間收縮。

### 劇本二：突然死亡（機率 10%）

美國財政失控引發通膨、賴債，或在重大地緣衝突中暴露軍事極限。外國央行集體拋售美債，美元在數月內貶值 30–40%，類似 1956 年英鎊蘇伊士危機。

低機率，但不是零。Eichengreen 指出：1991 年蘇聯解體、2010 年歐債危機，事前沒有任何主流分析師給出高機率預測。**「沒人覺得會崩」是崩潰前夕的標準氛圍。**

### 劇本三：繼續獨霸（機率 50%）

只要美軍保持壓倒性優勢、科技持續領先、法律體系維持可信度，慣性和網路效應就能讓美元再維持 50 年。

**Eichengreen 押這個劇本，但附帶警告：** 霸主貨幣的特權會讓政客有動機無限舉債、無限擴大赤字，因為「反正全世界會買我的債」。這個心態如果失控，美元的終結不會來自外部挑戰，而來自美國政府自己。

## 五、和同時代思想家的對話

| 學者 | 立場 | 與 Eichengreen 的交集或分歧 |
|------|------|--------------------------|
| **克魯曼** | 美元霸權短期無可替代，浮動匯率是最佳緩衝 | 高度一致——Eichengreen 的歷史研究支撐了克魯曼的理論框架，克魯曼 DD-AA 模型的歷史案例幾乎全引 Eichengreen |
| **Bhagwati** | 貿易自由化是解方，制度問題要靠治理改革 | 互補——Bhagwati 談貨物流動，Eichengreen 談資本流動，前者樂觀，後者更謹慎 |
| **Rodrik** | 超全球化削弱了民族國家的政策空間 | 有張力——Eichengreen 認為美元體系是可以改革的，Rodrik 更悲觀，認為金融全球化從根本上破壞了民主問責 |

三人共同的認知：**1990–2000 年代那種「只要開放市場，一切會自動變好」的過度樂觀是錯的。** 差別在診斷的深度和藥方的激進程度。

## 一句話總結

美元霸權的本質是**網路效應加上沒有替代品**，不是美元本身有多好。它讓美國便宜借錢，也讓美國製造業空心化；讓聯準會成為全球最後貸款者，也讓美國政客有無限透支的幻覺。

Eichengreen 的結論不是「美元快死了」，而是更令人不安的一句話：**美元霸權最大的威脅不是中國或歐洲，是美國自己管不住自己的財政。**
