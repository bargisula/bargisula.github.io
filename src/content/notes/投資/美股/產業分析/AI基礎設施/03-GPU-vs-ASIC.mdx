## 先釐清一個常見誤解

「ASIC 會取代 GPU」——這句話說對了一半，說錯了一半。

正確的版本是：**ASIC 正在取代 GPU 做推論；GPU 在訓練場景的地位，目前沒有人能撼動。**

這不是技術優劣的問題，而是任務需求不同，導致最優解不同。

---

## 訓練 vs 推論：兩種完全不同的工作

<Callout type="data">

| 維度 | 訓練（Training）| 推論（Inference）|
|---|---|---|
| 任務 | 從頭學習，反覆更新模型參數 | 接收輸入，產出結果 |
| 資料流 | 隨機、動態，每次都不一樣 | 固定模型，重複相同計算 |
| 規模 | 萬卡以上 GPU 叢集，數週到數月 | 單次請求，毫秒內回應 |
| 彈性需求 | 高——架構常改，算子不固定 | 低——模型定型後幾乎不變 |
| GPU 優勢 | 通用、彈性、NVLink 萬卡互連 | 功耗偏高，每 token 成本高 |
| ASIC 優勢 | — | token/s 高 3–10 倍，成本低 50% |

</Callout>

白話說：**訓練是研發部門，每天都在改需求；推論是生產線，做的永遠是同一件事。**

研發部門需要通用機器（GPU），生產線需要專用機器（ASIC）。

---

## GPU 的通用性從哪裡來——也是它最大的弱點

要理解為什麼 GPU 在訓練場景無敵、推論場景卻這麼貴，得先搞清楚 GPU 怎麼跑推論。

一個大型語言模型（比如 70B 參數的模型）有大約 140GB 的「模型權重」——就是訓練完成後固定下來的所有參數。這些權重平常存在 HBM（高頻寬記憶體）裡。

**問題出在推論的過程：**

<Callout type="insight">

**GPU 推論的記憶體搬運問題：**

當你輸入一段文字請 GPU 生成回覆，它必須執行「自回歸生成」——每次只生成一個 token（一個字或字片段），然後把這個 token 加回輸入，再生成下一個。

每生成一個 token，GPU 就必須：
1. 把全部 140GB 的模型權重從 HBM 搬到 GPU 核心旁的 SRAM（運算暫存區）
2. 做一次矩陣乘法，算出下一個 token
3. 再生成下一個 token，再搬一次

一個 H100 的 HBM 頻寬是 3.35 TB/s。140GB 的權重，每次生成 token 都要讀一遍——理論上每個 token 至少要等 42 毫秒。

這就是為什麼 GPU 在**單使用者、低批次推論**時，算力利用率只有 5–10%：它大部分時間在等記憶體搬資料，不在算數。

</Callout>

**但這同時解釋了 GPU 的通用性：**

因為權重存在 HBM、每次運算時才載入，GPU 今天可以跑 GPT-5，明天可以跑 LLaMA 4，後天可以跑任何新架構的模型——只要把新的權重換進 HBM 就好。這個「每次都重新搬」的設計，讓 GPU 對任何模型都適用。

換句話說：**GPU 的通用性，正是因為它不把任何東西焊死在晶片上。代價，是每次推論都要付出記憶體搬運的時間與能耗。**

## 為什麼 ASIC 在推論上這麼強？

ASIC（Application-Specific Integrated Circuit，特定應用積體電路）是把某一種計算「焊死」在電路裡的晶片。

以 Transformer 推論為例——它的核心計算就是矩陣乘法加 Attention。如果把這兩個操作設計成專用電路，不需要通用控制邏輯、不需要浮點調度、不需要 CUDA 中介層，直接讓電流走最短路徑完成計算：

<Callout type="insight">

**ASIC 的效率優勢從哪裡來：**

- GPU：先把計算需求翻譯成 CUDA 指令 → CUDA 呼叫底層硬體 → 硬體執行
- ASIC：輸入直接觸發電路，沒有翻譯層

AWS Inferentia2 的 Transformer 推論速度比 H100 快 4 倍，能耗低 60%。Google TPU v6 每 token 成本比 H100 低約 2.3 倍。這不是微幅優化，是量級差距。

</Callout>

</Callout>

## CUDA 護城河：比硬體更深的軟體壁壘

很多人以為 NVIDIA 的護城河是 GPU 硬體。**不是。最深的護城河是 CUDA 生態。**

CUDA 是 NVIDIA 2006 年推出的並行運算平台，今天它的護城河體現在三個層面：

<Callout type="insight">

**第一層：PyTorch 綁定**

全球 85%+ 的 AI 研究用 PyTorch 開發。PyTorch 的預設後端是 CUDA。你要換成 AMD ROCm 或其他替代方案？沒問題——但每次升版都可能有相容性問題，每次換算子都要重新測試。

**第二層：算子庫生態**

CUDA 上有 cuDNN（深度學習）、cuBLAS（矩陣運算）、TensorRT（推論優化）等數十個高度優化的算子庫。這些庫是 NVIDIA 工程師花了十幾年調出來的，沒有直接替代品。換平台 = 這些庫的效能優化全部重來。

**第三層：切換成本**

一個熟悉 CUDA 的 AI 工程師，要切到 AMD ROCm 或 Google XLA？估計需要 3–6 個月適應 + 大量偵錯。企業不想付這個代價，除非 NVIDIA 的成本貴到無法接受。

</Callout>

這就是為什麼 AMD 的 MI300X 在硬體規格上有競爭力（HBM 容量甚至比 H100 大），但市占率始終在個位數。**軟體生態的護城河比硬體本身更難攻破。**

---

## ASIC 的軟體問題

ASIC 的最大弱點，同樣在軟體這一層。

每改一代 ASIC 架構，配套的編譯器、算子映射、模型優化工具全部要重寫。Google 有上千人的 TPU 軟體團隊，亞馬遜、Meta 也配置了大量資源。這不是小公司能複製的投入。

<Callout type="warning">

**ASIC 的隱性成本：**
- 硬體更新週期 18–24 個月，軟體棧要跟著重新對齊
- 支援的模型架構有限（為 Transformer 優化的 ASIC，遇到新架構就卡住）
- 工程師招募難——懂 TPU 軟體的人比懂 CUDA 的人少一個數量級

結論：**只有規模夠大、算力需求夠穩定的超大規模雲端商，才有資本養一條 ASIC 軟體棧。** 中小型 AI 公司和新創，短期內不會離開 NVIDIA。

</Callout>

## 激進解法：LPU 與晶圓晶片——把權重塞進晶片裡

如果 GPU 推論慢的根本原因是「每次都要從 HBM 搬權重」，那最直接的解法是：**把模型權重直接放進晶片上的 SRAM，不需要搬運。**

這就是 LPU 和晶圓晶片的核心邏輯。兩者都是在問同一個問題：**如果記憶體搬運是瓶頸，為什麼不把記憶體和計算放在同一個地方？**

### LPU（Language Processing Unit）— Groq

Groq 發明的 LPU（語言處理單元），架構與 GPU 根本不同：

<Callout type="insight">

**Groq LPU 的設計哲學：**

GPU 是「算力等記憶體」，Groq LPU 是「記憶體就在計算旁邊」。

LPU 的核心是 TSP（Tensor Streaming Processor）架構：模型的每一層權重，在編譯時就被靜態分配到晶片上特定的 SRAM 區塊，推論時資料「流過」已就位的權重，不需要動態搬運。

結果：
- **首 token 延遲**：GPU H100 約 200–500ms，Groq LPU 約 10–30ms
- **生成速度**：GPU H100 約 30–60 tokens/s，Groq LPU 最高達 500+ tokens/s
- **能耗**：每 token 約只有 GPU 的 1/5

</Callout>

**LPU 的天花板：** SRAM 比 HBM 貴 10–20 倍，密度低很多。一片 Groq 晶片約有 230MB SRAM——足以跑 7B–13B 的模型，但跑 70B 以上就需要多片組合。巨型模型（100B+）在單一 LPU 上無法直接跑。

Groq 的市場定位因此很清晰：**低延遲推論、即時語音 AI、需要極快首 token 的場景**——不跟 GPU 搶訓練，也不跟 ASIC 搶批次推論。

---

### 晶圓晶片（Wafer-Scale Engine）— Cerebras

Cerebras 走的是更激進的路：**把整片晶圓變成一顆晶片。**

<Callout type="data">

**Cerebras WSE-3 vs NVIDIA H100 規格對比**

| 規格 | Cerebras WSE-3 | NVIDIA H100 |
|---|---|---|
| 晶片面積 | 46,225 mm²（整片晶圓）| 814 mm² |
| 計算核心數 | 900,000 核 | 16,896 CUDA 核 |
| **片上 SRAM** | **44 GB**（全在晶片上）| 約 50 MB |
| 記憶體頻寬（片上）| 21 PB/s | — |
| 外部記憶體 | 不需要 HBM | 需要 80GB HBM3 |
| 需要 CoWoS 封裝 | 否（整片晶圓即成品）| 是 |
| 單顆售價 | ~$250 萬+ | ~$30,000 |

</Callout>

<Callout type="insight">

**為什麼晶圓晶片能這麼快：**

傳統 GPU 把晶片切成小塊再封裝，晶片之間的通訊要走封裝基板（慢），記憶體（HBM）也在晶片外面（更慢）。

Cerebras WSE-3 的 44GB SRAM 全部在晶片上——頻寬達 21 PB/s（H100 HBM 的 6,000 倍）。模型權重直接放在片上 SRAM，推論時計算單元和記憶體在同一顆晶片的不同區域，訊號只需要走幾毫米的銅線，不需要進出晶片封裝邊界。

結果：**對能裝進 44GB 的模型，Cerebras 可以做到比 H100 快 10–20 倍的推論，能耗低 80%。**

</Callout>

**晶圓晶片的現實問題：**

<Callout type="warning">

1. **良率挑戰**：整片晶圓上有 10 億個電晶體，任何一個區域有缺陷就要繞路——製造複雜度極高，Cerebras 有一套自研的「冗餘架構」處理這個問題，但成本仍高
2. **模型大小限制**：44GB SRAM 可以裝 70B 模型（FP16），但 100B+ 需要多片聯機，跨片通訊又成為瓶頸
3. **定價極高**：$250 萬一顆，不是一般公司能部署的設備
4. **Cerebras 剛於 2026 年 5 月在那斯達克掛牌（估值約 350 億美元）**，是算力賽道的新興上市標的

</Callout>

## 中國算力：出口管制下的平行宇宙

2022 年至今，美國對中國的 AI 晶片出口管制一波波升級。H100、A100 全面禁止，H800、A800 縮水版也在 2023 年跟著被禁，最新的 H20 也在 2025 年被納入管制。

中國 AI 產業面臨兩個選擇：**等、或是自己造。**

<Callout type="data">

**中國主要算力方案對比**

| 廠商 | 產品 | 對標 | 現況 |
|---|---|---|---|
| 華為 | Ascend 910C | H100 | 量產中，效能約 H100 的 60–70%，良率仍有差距 |
| 華為 | Ascend 910D（傳聞）| H200 / B100 | 2026 年測試中，樣品已交少數客戶 |
| 壁仞科技（Biren）| BR100 | A100 | 良率問題，2025 年產能受限 |
| 寒武紀（Cambricon）| 思元 590 | 推論加速器 | 中低端推論場景，不做大模型訓練 |
| 天數智芯（Iluvatar）| BI-V150 | 訓練加速器 | 規模尚小 |

</Callout>

<Callout type="insight">

**華為是唯一真正的替代方案，但差距仍在**

Ascend 910C 的算力約是 H100 的 60–70%，但生態系統遠落後於 CUDA。中國 AI 廠商（百度、阿里、騰訊、字節）在需要的情況下使用，但也在各自開發軟體棧以繞過限制。

更關鍵的問題是製程：華為使用中芯國際（SMIC）的 7nm 製程，而 NVIDIA 使用台積電 4nm。製程差距意味著功耗和效能都有結構性落差，短期內無法彌補。

</Callout>

### 出口管制的雙面效應

<Callout type="data">

| 面向 | 影響 |
|---|---|
| 對 NVIDIA | 中國市場直接收入損失（原本約佔 Data Center 15–20%），但市場轉向其他地區 |

</Callout>

## 訓練 vs 推論的長期分工預測

到 2027–2028 年，市場普遍預期 ASIC 的推論市占率將超過 30%（現在約 15–20%）。但這**不代表 GPU 的絕對需求下降**——因為：

1. 模型訓練規模持續擴大，Scaling Law 沒有停止
2. 每個季度都有新模型發布，舊的 ASIC 方案要重新對齊
3. ASIC 的推論需求釋放，反而拉動更多訓練算力來生成更多模型

<Callout type="insight">

簡單說：**ASIC 切走了推論市場，但訓練市場的蛋糕也在同步變大。** NVIDIA 輸掉的是市占率，贏的是總量——只要 Scaling Law 持續，GPU 需求的絕對值不會萎縮。

</Callout>

## 三大風險

<Callout type="warning">

**① ASIC 替代速度超預期**
若超大規模雲端商的 ASIC 推論佔比在 2026 底就超過 40%（比預期快兩年），NVIDIA Data Center 的指引將面臨向下修正壓力，市場估值需要重新定價。

**② 出口管制升級造成台積電業務衝擊**
若美國把台積電先進製程服務全面納入對中管制，台積電在中國的業務佔比（目前約 10–15%）將快速歸零，短期衝擊毛利率。

**③ 中國 ASIC 自主化進度超預期**
若華為 Ascend 系列在 2027 年良率明顯改善、效能追上 H100，中國市場的 NVIDIA 替代空間將快速壓縮，NVIDIA 的主權 AI 業務（中東、東南亞）也可能面臨競爭。

</Callout>

GPU 和 ASIC 不是對手，是分工。GPU 負責「想清楚」（訓練），ASIC 負責「快速執行」（推論）。NVIDIA 的護城河不在晶片有多快，而在 CUDA 讓你換不掉它。真正的風險不是 ASIC 崛起，而是哪一天有人打造出「夠好用」的 CUDA 替代生態——但那一天，目前看不到。
