但油價 $110、中東戰火未熄、下週 Trump-Xi 峰會——Goldilocks 坐在一個有熊的森林裡。

## 今日三件事

<Callout type="insight" title="① NFP +115K vs 預期 62K——Goldilocks 劇本成立">

**四月就業報告是今日最大變數，已確認：超預期但不過熱。**

- 新增就業 +115,000（預期 +62,000）
- 失業率 4.3%（原地不動，符合預期）
- 強項：醫療 +37K、運輸倉儲 +30K、零售 +22K
- 弱項：聯邦政府 −9K、科技業 −13K、製造業 −2K

**解讀邏輯：**

| 數字解讀 | 市場含義 |
| :--- | :--- |
| 就業強→不是衰退 | 「軟著陸」敘事存活，risk-on 有底氣 |
| 就業不算爆熱 | Fed 不需要升息，降息預期不會大幅後退 |
| 科技 −13K | 科技業仍在精簡，但不影響 AI 資本支出邏輯 |

Fed 目前維持利率在 3.5–3.75%，四月會議按兵不動，全年預計僅一次降息。這份 NFP 不會改變這個路徑——但給了市場「就業有韌性」的信心。

**短期方向：看多。就業韌性 + 晶片鬆綁 + 外交對話 = 三重利多並行。**

</Callout>

<Callout type="insight" title="② SMCI 財報：毛利修復比數字更重要">

Super Micro（SMCI）本週公布 Q3 FY2026 財報：

| 指標 | 實際 | 預期 |
| :--- | ---: | ---: |
| **調整後 EPS** | $0.84 | $0.62 |
| **營收** | $10.24B | $12.33B |
| **毛利率** | **10.1%** | — |

EPS 超預期，營收miss——但市場給的是 **+18~20%** 的反應，原因只有一個：**毛利從 Q2 的 6.4% 回到 10.1%**。

過去一年 SMCI 被質疑的最大問題就是毛利率崩潰。10.1% 的回升代表管理層對定價權的重新掌握，不是一次性異常。

**Q4 指引：** 營收 $11B–$12.5B，EPS $0.65–$0.79。

**產業瀑布（SMCI 的反彈受益誰）：**

```
SMCI AI 伺服器需求確認
    │
    ▼ 第一層（直接）
    SMCI 本身（股價已反應）
    │
    ▼ 第二層（零組件）
    NVDA GPU 採購量確認 → H100/H200 供應持續吃緊
    散熱方案廠（液冷需求隨伺服器機架密度上升）
    │
    ▼ 第三層（基礎設施）
    電力 / 資料中心 REIT / 銅線廠（高密度機架耗電增加）
```

</Callout>

<Callout type="warning" title="③ 地緣複合風險：油價 $110 + Trump-Xi 峰會下週登場">

**美伊衝突：** 中東戰事持續，Strait of Hormuz 受威脅，WTI 原油現價約 $110/桶。油價維持高位代表：
- 通膨壓力不會消失（Fed 降息更難）
- 航空、物流、化工類股成本承壓
- 能源股（XLE）有短期支撐，但全球需求若放緩會翻臉

**Trump-Xi 峰會：5/14–15 北京。**

這是今年最大地緣政治事件之一。背景：
- 日內瓦 90 天停火協議，但中方被指控違反關鍵礦產協議條款
- 川普揚言對中加徵 50% 關稅
- 晶片出口鬆綁傳言是「峰會前熱身」？還是真正鬆綁？

**下週半導體股的走勢，很可能取決於峰會後的首篇聲明。**

| 峰會結果情境 | 晶片股反應 |
| :--- | :--- |
| 達成框架協議，鬆綁具體化 | QCOM / NVDA / AMD 再漲一波 |
| 「友好但無結論」 | 已 price-in，震盪回吐 |
| 破局或川普推文施壓 | 快速回調，止損確認 |

</Callout>
