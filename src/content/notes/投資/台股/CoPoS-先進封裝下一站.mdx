CoWoS 是過去三年 AI 算力爆發的封裝主角，但它有個物理天花板：圓形晶圓。
AI 晶片面積越做越大，圓形邊緣的廢料率直線上升，每片晶圓能切出的有效面積已逼近極限。
CoPoS 的出現不是技術炫技，是供應鏈面對算力需求的唯一出路——換一塊更大的面板。

---

## 一、技術定位：CoPoS 是什麼，為什麼現在重要

**CoPoS = Chip-on-Panel-on-Substrate**

把 CoWoS 裡的「圓形矽中介層（Silicon Interposer）」換成「方形玻璃面板（Glass Panel）」，其餘堆疊邏輯相同：底部是基板，中間是玻璃面板負責佈線，頂部是 HBM + GPU 晶片。

<Callout type="data" title="CoPoS vs CoWoS 關鍵差異">
| 項目 | CoWoS（現在） | CoPoS（下一代） |
| :--- | :--- | :--- |
| 中介層材質 | 矽晶圓（圓形） | 玻璃面板（方形） |
| 面積利用率 | ~65% | 95%+ |
| 尺寸上限 | ~600mm² | 理論無限（600×700mm 面板） |
| 佈線精度 | 高 | 更高（玻璃熱膨脹係數低） |
| 成本（成熟後） | 基準 | 預估降 20–30% |
| 台積電量產時程 | 現在 | 2028–2029 |
</Callout>

**為什麼「現在」重要？**

H100 封裝面積約 814mm²，已超過單片 CoWoS reticle 上限。
B200 超過 1,000mm²，台積電用多片拼接（CoWoS-L）硬拉，良率壓力極大。
下一代「Rubin」預計超過 1,500mm²，圓形晶圓物理上已接近無解。
CoPoS 是台積電自己給出的答案：改換面板，不再硬撐圓形。

## 三、瓶頸→溢出：CoWoS 裝不下，CoPoS 接手

這是整個邏輯的核心。不理解這個環節，其他都是在貼新聞。

**瓶頸在哪裡？**

CoWoS 的矽中介層從 12 吋圓形晶圓切出，邊緣天然浪費。
- 圓形晶圓直徑 300mm，可用面積約 70,000mm²
- 切 600mm² 的大晶片，邊緣廢料讓良率掉到 65% 以下
- 台積電 CoWoS 月產能：2024 年 35K → 2025 年 70K → 2026 年目標 130K
- **即便產能翻四倍，面積利用率問題不解決，依然不夠**

<Callout type="warning" title="CoWoS 的物理天花板">
AI 晶片大型化的速度 > CoWoS 產能擴充的速度。
這不是台積電不努力，是圓形晶圓的幾何學問題——越切越大，邊緣廢料比例越高。
B200 之後的 Rubin 架構，CoWoS 已無法單純靠產能數字解決。
</Callout>

**溢出往哪裡去？**

```
CoWoS 圓形晶圓 → 面積利用率 65% → 大晶片良率崩
    ↓ 溢出方向
CoPoS 方形玻璃面板 → 面積利用率 95%+ → 同樣成本切出 46% 更多有效面積
    ↓ 誰受益
1. 玻璃面板供應鏈（采鈺 pilot → 全面投產）
2. ABF 基板升規（欣興、南電：更大面板 = 更大基板需求）
3. 玻璃製程設備（弘塑、均華、洪碩）
    ↓ 誰被替代
矽中介層供應商（日廠 Shinko、Ibiden 台廠份額受壓）
```

**量化理解：** 若 CoPoS 面積利用率 95% vs CoWoS 65%，同樣一片面板：
- CoWoS：可切 65 個單位
- CoPoS：可切 95 個單位
- **差距 46%** — 在算力需求每年翻倍的情況下，這個差距就是能否供貨的分水嶺

## 四、現在在哪裡：敘事期 vs 數字期

<Callout type="insight" title="CoPoS 目前處於「敘事期」，2027 年進入「數字期」">
**敘事期（現在 → 2027）**
- 采鈺 2026 年試產線建置，無量產數字
- NVIDIA Rubin 是否採用 CoPoS 尚未官方確認
- 玻璃基板良率、量產成本仍是未知數
- 股價反映預期，非現實，波動大

**數字期（2027 → 2028）**
- 試產良率數據出爐
- NVIDIA 正式採購訂單
- 台積電 CoPoS 正式列入資本支出計畫
- 相關供應商開始有真實營收貢獻
</Callout>

**投資含義：** 現在佈局買的是「如果」，2027 年後才是「因為」。
敘事期股價容易因為一則傳聞漲停，也容易因為一個延遲訊息跌停。
敘事期適合小部位長持，數字期才是加碼點。

## 五、關注清單：這些訊號出現，代表邏輯成立

<Callout type="warning" title="CoPoS 五個關鍵檢查點">
**① 采鈺（6789）試產良率**
目標：玻璃面板中介層良率達到 90%+（業界估計量產門檻）
觀察方式：法說會、供應商月報、台積電法說 Q&A

**② NVIDIA Rubin 封裝規格確認**
目標：NVIDIA 官方或供應鏈透露 Rubin 採用 CoPoS 或 CoWoS-P（panel）
觀察方式：NVIDIA 技術白皮書、TSMC 技術論文（IEDM、VLSI）

**③ 台積電 CoPoS 列入資本支出**
目標：台積電法說明確提及 CoPoS 投資金額或時程
觀察方式：每季台積電法說、年度技術論壇

**④ ABF 基板升規訂單**
目標：欣興、南電接到 CoPoS 規格基板訂單（大尺寸、高層數）
觀察方式：法說會月營收年增率加速

**⑤ 玻璃基板本地化**
目標：台廠出現具競爭力的玻璃基板供應商
觀察方式：工研院技術授權、新創或既有廠商擴廠公告
</Callout>

## 六、誰是輸家：CoPoS 崛起的替代效應

<Callout type="warning" title="潛在受壓族群">
| 受衝擊環節 | 說明 |
| :--- | :--- |
| **矽中介層供應商**（Shinko、Ibiden） | CoPoS 將矽中介層換成玻璃，這兩家日廠的核心產品被替代，台廠目前無此業務，影響有限 |
| **CoWoS 設備純玩家** | 若 CoPoS 設備邏輯與 CoWoS 差異大，CoWoS 專用設備廠商訂單成長放緩 |
| **傳統 OSAT 無升級者** | CoPoS 封裝高度整合，無法跟上 panel-level 製程的 OSAT 被邊緣化 |
| **玻璃上游本地空缺** | 台廠目前沒有玻璃基板供應能力，原材料利潤外流至日本（康寧玻璃）、韓國（三星 SDI） |
</Callout>

<Callout type="quote" title="一句話結論">
CoPoS 不是 CoWoS 的競爭者，是它的繼承者——CoWoS 幫台積電打下先進封裝江山，CoPoS 讓這個江山繼續往前走而不崩塌。台廠受益的邏輯不是「新技術概念炒作」，而是「圓形晶圓的物理極限逼出來的必然升級」。
</Callout>
