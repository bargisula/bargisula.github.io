你身體所有的感覺、力氣、思考，都建立在 37 兆個細胞上。細胞健康，你就有能量；細胞出問題，疾病就跟著來。本篇從「細胞是什麼」開始，一路講到粒線體、氧化壓力、慢性發炎，最後給你保養實戰方法。

## 第一章：先認識細胞 —— 你身體的基礎單位

### 1. 人體有哪些細胞？它們在幹嘛？

人體有 200 多種細胞，分工極其精細。

| 細胞種類 | 主要工作 | 一句話比喻 |
| :--- | :--- | :--- |
| **紅血球** | 運送氧氣、帶走二氧化碳 | 外送員，不載別的 |
| **白血球** | 免疫部隊（B細胞、T細胞、巨噬細胞等） | 警察 + 特種部隊 |
| **神經細胞** | 傳電信號，掌管思考、感覺、運動 | 身體的光纖網路 |
| **肌肉細胞** | 收縮產生力量（心肌、骨骼肌、平滑肌） | 發動機 |
| **皮膚細胞** | 組成屏障，防水防菌 | 城牆 |
| **脂肪細胞** | 存能量、保溫、分泌荷爾蒙 | 倉庫 + 內分泌員 |
| **幹細胞** | 能變成其他細胞，負責修補更新 | 萬能預備工人 |

> **免疫小知識：抗體是誰做的？**
> *   **抗體** = 精準飛彈，專門黏住特定病毒或細菌。
> *   **B 細胞**：製造者。遇到敵人後會變身為「漿細胞」，24小時不停生產抗體。
> *   **T 細胞**：殺手。直接幹掉被感染的細胞，或指揮其他免疫部隊。
> *   **免疫系統** = 白血球 + 抗體 + 其他免疫分子。

### 2. 細胞的共同架構：一個迷你城市

| 零件 | 功能 | 比喻 |
| :--- | :--- | :--- |
| **細胞膜** | 雙層磷脂，決定誰能進出 | 外牆兼海關 |
| **細胞質** | 果凍狀基質 | 工作池 |
| **細胞核** | 裝著 DNA（蛋白質設計圖） | 市長辦公室 |
| **核糖體** | 照指令組裝蛋白質 | 組裝機 |
| **內質網 (ER)** | 粗糙ER做蛋白，平滑ER做脂質、解毒 | 工廠產線 |
| **高基氏體** | 蛋白質加工、打包、寄送 | 物流中心 |

> **特殊案例：** 紅血球為了多裝氧氣，把細胞核跟粒線體都丟了，所以它不會分裂、壽命只有 120 天。

## 第二章：深入發電廠 —— 粒線體

### 1. 粒線體特性
*   **雙層膜**：內膜往內折成「嵴」，皺褶越多，發電面積越大。
*   **自帶 DNA**：mtDNA，環狀，**只來自媽媽**。主要管發電機零件。
*   **數量看需求**：耗能高的（心、腦、肌肉）有幾千個，皮膚可能僅幾百個。
*   **粒線體自噬**：粒線體會分裂融合，太爛的會被回收。

### 2. 核心任務：細胞呼吸（食物變 ATP）

| 步驟 | 地點 | 核心功能 |
| :--- | :--- | :--- |
| **1. 糖解** | 細胞質 | 葡萄糖拆成丙酮酸，產生少量 ATP |
| **2. 克氏循環** | 粒線體基質 | 將能量交給電子載體 (NADH)，放出 CO₂ |
| **3. 電子傳遞鏈** | 內膜 | 產生電壓差，推動 ATP 合成酶，消耗氧氣變水 |

> **能量公式：** 葡萄糖 + O₂ → ATP + H₂O + CO₂（這就是為什麼我們需要吃飯與呼吸）。

## 第三章：能量工廠的敵人 —— 氧化壓力

### 1. 自由基是什麼？
電子不成對、極度不穩定的「土匪」分子。它們會搶別人電子引發連鎖破壞，這叫 **氧化**。
*   **來源**：發電時漏出的活性氧 (ROS)、抽菸、空污、紫外線、油炸物、壓力、發炎。

### 2. 氧化壓力 = 消防隊不夠
當自由基數量超過身體的抗氧化系統（SOD、穀胱甘肽、維生素 C/E）時，就會產生 **氧化壓力**。

### 3. 粒線體是最大受害者
*   **mtDNA 受傷**：缺乏組蛋白保護，壞掉會導致發電機零件出錯。
*   **惡性循環**：零件錯 → 漏更多電子 → 產生更多 ROS → 破壞更重。
*   **後果**：慢性疲勞、腦霧、老得快。與失智、糖尿病、癌症強相關。

## 第四章：悶燒的火 —— 慢性發炎

*   **急性發炎**：紅腫熱痛，是免疫系統在修復（如割傷、感冒）。
*   **慢性發炎**：低度、持續且無明顯症狀的「悶燒」。
*   **成因**：內臟脂肪、長期壓力、高糖飲食、睡不好、環境毒素。
*   **萬病之源**：動脈硬化、失智、憂鬱症、發炎老化 (Inflammaging)。

## 第五章：細胞保養術 —— 5 大實戰招式

### 1. 抗發炎飲食：給好燃料
*   **多吃**：彩色蔬果（多酚）、Omega-3（深海魚）、特級初榨橄欖油、薑黃、發酵食物。
*   **少吃**：糖、精緻澱粉、反式脂肪、炸物、酒精。

### 2. 補足抗氧化軍團
*   **天然來源**：芭樂 (C)、杏仁 (E)、巴西堅果 (硒)、牡蠣 (鋅)。
*   **輔助品**：輔酶 Q10（粒線體專用）、NAC（幫助合成最強抗氧化劑穀胱甘肽）。

### 3. 運動：系統升級
*   **Zone 2 有氧**：快走、慢跑（心率約 180-年齡）。**粒線體最愛**。
*   **重訓**：增加肌肉量（粒線體大本營），對抗胰島素阻抗。
*   **HIIT**：刺激粒線體效率，但一週 1 次即可。

### 4. 壓力管理：關掉發炎開關
*   **修復模式**：透過冥想、4-7-8 呼吸、曬太陽、真實社交來啟動副交感神經，降低皮質醇。

### 5. 睡好覺：系統維修
*   **排毒**：深睡時大腦會沖刷掉廢物（如失智相關蛋白）。
*   **再生**：生長激素分泌，修復粒線體。
