情緒的背後是化學。當你感到快樂、焦慮、愛意或絕望，本質上是特定分子在神經元之間的突觸縫隙中流動。了解這些分子，就是了解情緒的物質基礎。

---

## 一、什麼是神經傳導物質

神經元之間不直接接觸，訊號傳遞靠的是**突觸間隙**中的化學分子。

**傳遞流程：**
1. 突觸前神經元受到電訊號觸發
2. 神經傳導物質從囊泡釋放到突觸間隙
3. 與突觸後神經元的受體結合 → 產生興奮或抑制效果
4. 剩餘的分子被回收（再攝取）或分解

> **藥物的作用點**幾乎都在這個流程上：SSRI 阻斷血清素的再攝取；苯二氮平強化 GABA 受體；古柯鹼阻斷多巴胺回收。了解機制，就能理解為什麼藥物這樣設計。

---

## 二、七種關鍵神經傳導物質

### 1. 多巴胺（Dopamine）— 動力與預期

**常見誤解：** 多巴胺不是「快樂物質」，它是**「預期與動力」**的物質。

大腦釋放多巴胺的時機不是在你得到獎賞時，而是在**你預期將要得到獎賞**的時候。這就是為什麼滑手機停不下來——每次下滑都在製造「也許下一則會很有趣」的預期。

| 功能 | 說明 |
| :--- | :--- |
| 動機與趨近行為 | 驅動你去追求目標 |
| 獎賞學習 | 強化「做這件事有好結果」的連結 |
| 注意力與執行功能 | 前額葉需要多巴胺才能集中 |
| 運動控制 | 基底核的多巴胺控制動作流暢度 |

**失衡後果：**
- 不足 → 無動力、快感缺失（憂鬱症的核心症狀之一）、ADHD、帕金森氏症（運動控制喪失）
- 過多 → 強迫性行為、成癮、思覺失調症的部分症狀

---

### 2. 血清素（Serotonin）— 穩定與滿足

血清素是情緒的**底線調節器**，它不製造快樂的高峰，而是維持情緒的穩定基線。

有趣的是，90% 的血清素存在於腸道，而非大腦——這是腸腦軸（Gut-Brain Axis）研究的核心，也解釋了為什麼壓力會影響消化，消化問題也會影響情緒。

| 功能 | 說明 |
| :--- | :--- |
| 情緒穩定 | 維持平靜、防止情緒劇烈波動 |
| 睡眠調節 | 是褪黑激素的前驅物質 |
| 食慾控制 | 調節飽足感 |
| 社會行為 | 與地位感、自信有關 |

**失衡後果：**
- 不足 → 持續低落、易怒、睡眠障礙、強迫思考、對社會排斥過度敏感
- 過多（通常由藥物引起）→ 血清素症候群：心跳過速、顫抖、高燒，嚴重可致命

---

### 3. 正腎上腺素（Norepinephrine）— 警覺與壓力反應

又稱去甲腎上腺素，是大腦的**警報系統**。危險來臨時第一個啟動，讓你進入戰或逃狀態。

| 功能 | 說明 |
| :--- | :--- |
| 注意力調控 | 決定什麼值得注意 |
| 戰或逃反應 | 提升心率、血壓、肌肉張力 |
| 情緒強度 | 放大情緒記憶的刻印強度 |
| 喚醒狀態 | 調節睡眠-清醒週期 |

**失衡後果：**
- 不足 → 注意力渙散、疲勞、難以專注（與 ADHD 有關）
- 過多 → 慢性焦慮、過度警覺、PTSD 的閃回與驚嚇反應

> **多巴胺、血清素、正腎上腺素**合稱「單胺類神經傳導物質」，是大多數情緒藥物的主要靶點。

---

### 4. GABA（γ-胺基丁酸）— 大腦的煞車

GABA 是主要的**抑制性**神經傳導物質，功能是降低神經元的過度活躍。

沒有 GABA，大腦會陷入持續亢奮，就像引擎沒有煞車一樣。

| 功能 | 說明 |
| :--- | :--- |
| 抗焦慮 | 抑制杏仁核的過度警覺 |
| 肌肉放鬆 | 降低肌肉張力 |
| 促進睡眠 | 降低整體神經活動以進入睡眠 |
| 防止癲癇 | 防止神經元過度同步放電 |

**失衡後果：**
- 不足 → 焦慮症、恐慌症、失眠、癲癇
- 強化（藥物作用）→ 鎮靜、抗焦慮、昏睡；過度強化（酒精、苯二氮平過量）→ 呼吸抑制

---

### 5. 麩胺酸（Glutamate）— 大腦的油門

GABA 是煞車，麩胺酸就是**油門**——大腦最主要的興奮性神經傳導物質。

幾乎所有學習與記憶都需要麩胺酸參與。

| 功能 | 說明 |
| :--- | :--- |
| 學習與記憶 | 突觸可塑性的核心（LTP 長期增強） |
| 認知功能 | 思考、推理、語言處理 |
| 情緒調節 | 與壓力回應和獎賞迴路互動 |

**失衡後果：**
- 過多 → 神經毒性（神經元過度興奮至死亡），與阿茲海默症、中風後損傷有關
- 系統異常 → 思覺失調症的部分症狀（NMDA 受體假說）

> 近年來備受關注的**氯胺酮（Ketamine）抗憂鬱作用**，正是透過阻斷麩胺酸的 NMDA 受體，在數小時內產生快速抗憂鬱效果，打破了「單胺假說」主導情緒治療數十年的局面。

---

### 6. 催產素（Oxytocin）— 連結與信任

俗稱「愛的荷爾蒙」，但更準確的描述是**「降低社交風險感知」的物質**。

催產素讓你更願意相信、更願意靠近，但它並不區分好人與壞人——它讓你對熟悉的人更親近，同時對陌生群體更疏遠，這是它複雜的一面。

| 功能 | 說明 |
| :--- | :--- |
| 親密關係與依附 | 促進親子、伴侶之間的連結 |
| 信任感 | 降低對他人意圖的警戒 |
| 壓力緩解 | 與他人接觸時降低皮質醇 |
| 社會記憶 | 幫助記憶社交對象的臉孔與情緒 |

**失衡後果：**
- 不足 → 社交迴避、難以建立親密感、自閉症譜系的部分社交困難
- 情境複雜性 → 過量或在錯誤情境下激活，可能強化族群內外的對立

---

### 7. 腦內啡（Endorphins）— 天然止痛與愉悅

腦內啡是大腦自行製造的**類鴉片物質**，在疼痛或劇烈運動時釋放，功能是壓制疼痛訊號並製造愉悅感。

所謂的「跑者愉悅感（Runner's High）」就是腦內啡大量釋放的結果。

| 功能 | 說明 |
| :--- | :--- |
| 止痛 | 結合鴉片受體，阻斷疼痛訊號 |
| 愉悅感 | 製造短暫的幸福感 |
| 社交連結 | 笑聲、接觸、共同節律（如唱歌跳舞）都會觸發 |
| 壓力緩解 | 降低皮質醇，平衡交感神經 |

**失衡後果：**
- 系統受損 → 慢性疼痛、運動後無法恢復愉悅感
- 外源性鴉片（海洛因、嗎啡）→ 佔用受體，導致大腦停止自產，形成依賴

## 三、它們如何共同塑造情緒

神經傳導物質從不單獨運作，情緒是多個系統同時交互的結果：

| 情緒狀態 | 主要涉及物質 | 機制 |
| :--- | :--- | :--- |
| **快樂** | 多巴胺、腦內啡、血清素 | 獎賞預期 + 止痛愉悅 + 穩定基線 |
| **愛意** | 催產素、多巴胺、正腎上腺素 | 連結感 + 追求動力 + 心跳加速 |
| **焦慮** | 正腎上腺素過多、GABA 不足 | 警報持續啟動、煞車失靈 |
| **憂鬱** | 多巴胺不足、血清素不足 | 無動力 + 情緒基線下沉 |
| **恐懼** | 正腎上腺素、麩胺酸 | 戰或逃啟動、記憶強刻印 |
| **平靜** | GABA、血清素、腦內啡 | 抑制過度活躍 + 穩定基線 + 疼痛緩解 |

## 四、日常行為如何影響這些物質

不一定要靠藥物，許多行為會直接改變神經傳導物質的水平：

| 行為 | 主要影響 |
| :--- | :--- |
| **有氧運動** | 提升多巴胺、血清素、腦內啡；降低皮質醇 |
| **日照** | 促進血清素合成（色胺酸代謝需要光） |
| **深度睡眠** | 修復多巴胺受體敏感度；恢復 GABA 系統 |
| **正念冥想** | 增加前額葉 GABA；降低杏仁核的正腎上腺素反應 |
| **社交與肢體接觸** | 釋放催產素與腦內啡 |
| **完成目標** | 多巴胺獎賞迴路激活（小目標頻繁完成比大目標偶爾完成效果更好） |
| **高糖高脂食物** | 短暫多巴胺上升，長期卻降低受體敏感度 |

---

## 結語

情緒不是虛無縹緲的感受，而是物質在特定迴路中流動的結果。理解這些物質，不是為了把情緒還原為冷冰冰的化學反應，而是為了更清楚地看見：**你的情緒有其原因，你的大腦在努力做它設計來做的事。** 當系統失衡時，這不是意志力的問題，而是系統需要被調整。
