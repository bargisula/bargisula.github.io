大腦每時每刻都在產生電訊號。當數百萬個神經元同步振盪時，會形成可被偵測的電場波動——這就是**腦波（Brain Waves）**。腦波不是一種，而是多種頻率同時存在，當下的意識狀態決定哪種頻率主導。

---

## 一、腦波怎麼被測量

**腦電圖（EEG，Electroencephalography）** 是主要工具：在頭皮放置電極，記錄皮質神經元集體活動產生的電位變化，解析度在毫秒等級。

EEG 的優點是時間解析度極高，能即時追蹤腦狀態的變化；缺點是空間解析度差，只能看到表層皮質的綜合訊號，無法精確定位深層結構。

> **頻率（Hz）** 是腦波分類的基礎：每秒振盪幾次，決定它屬於哪個波段。

---

## 二、五種主要腦波

### 1. Delta 波（0.5–4 Hz）— 最慢，最深

**對應狀態：** 深層無夢睡眠、昏迷、深度麻醉

Delta 是振幅最大、頻率最低的腦波，出現在意識完全抽離的狀態。這個階段是身體修復的核心時機：生長激素在此大量釋放，免疫系統進行修復，記憶進行鞏固。

| 特性 | 說明 |
| :--- | :--- |
| 頻率 | 0.5–4 Hz |
| 振幅 | 最大（75–200 μV） |
| 正常出現 | 深度睡眠（N3 階段） |
| 清醒時出現 | 腦損傷、腫瘤、嚴重憂鬱的警示信號 |

**異常：** 清醒狀態下出現局部 Delta 波，通常指向病變區域，是神經科診斷的重要線索。

---

### 2. Theta 波（4–8 Hz）— 邊緣地帶

**對應狀態：** 淺眠、入睡邊緣、深度冥想、創意狀態、情緒處理

Theta 是意識與潛意識交界的頻率，也是「直覺」和「靈感」最常被描述的狀態。海馬迴（負責記憶）在 Theta 頻率下最為活躍，這也是為什麼學習後的睡眠能鞏固記憶。

| 特性 | 說明 |
| :--- | :--- |
| 頻率 | 4–8 Hz |
| 正常出現 | 入睡前、REM 睡眠、深度冥想、恍神 |
| 特殊意義 | 情緒記憶的提取與處理在此進行 |

**ADHD 的關聯：** ADHD 患者清醒時 Theta 波比例偏高（大腦像在「半睡半醒」），這是神經回饋訓練的主要靶點之一。

---

### 3. Alpha 波（8–13 Hz）— 放鬆的清醒

**對應狀態：** 放鬆但清醒、閉眼休息、輕度正念、心流前期

Alpha 是大腦「怠速」時的頻率。你閉上眼睛放鬆、讓思緒漂浮，Alpha 就會升高。它代表大腦不在積極處理任何任務，但隨時可以被激活。

| 特性 | 說明 |
| :--- | :--- |
| 頻率 | 8–13 Hz |
| 振幅 | 中等（30–50 μV） |
| 最強位置 | 枕葉（視覺皮質），閉眼時最明顯 |
| 功能 | 抑制不相關的感覺輸入，幫助專注 |

**Alpha 阻斷（Alpha Blocking）：** 一旦睜眼或開始思考，Alpha 立刻被 Beta 取代。這個現象被用來測試大腦的警覺反應。

> 許多人焦慮時 Alpha 明顯下降，冥想訓練最直接的效果之一就是增加 Alpha 活動。

---

### 4. Beta 波（13–30 Hz）— 主動思考

**對應狀態：** 清醒、思考、對話、解決問題、焦慮

Beta 是日常清醒生活的主要頻率，幾乎所有認知任務都在 Beta 主導下進行。

Beta 可進一步細分：

| 子波段 | 頻率 | 特性 |
| :--- | :--- | :--- |
| **低 Beta** | 13–17 Hz | 放鬆的專注，輕度警覺 |
| **中 Beta** | 17–23 Hz | 積極思考、處理任務 |
| **高 Beta** | 23–30 Hz | 高度警覺、緊張、焦慮 |

**問題在於高 Beta：** 現代人長期處於高 Beta 狀態，這與慢性壓力、焦慮、入睡困難直接相關。大腦需要從 Beta 「降速」到 Alpha 才能入睡，無法切換的人就是失眠者的常見腦波模式。

---

### 5. Gamma 波（30–100 Hz）— 高度整合

**對應狀態：** 高度專注、複雜問題處理、靈光乍現、深度冥想（資深禪修者）

Gamma 是頻率最高的腦波，代表大腦不同區域的**高度同步整合**。它出現在資訊跨區域整合的瞬間——當你突然「想通了一件事」，或者需要同時整合視覺、聽覺、語言和情緒時。

| 特性 | 說明 |
| :--- | :--- |
| 頻率 | 30–100 Hz |
| 振幅 | 最小（難以偵測） |
| 正常出現 | 洞察時刻、感覺整合、高度專注 |
| 研究發現 | 資深禪修者（數萬小時）靜息狀態 Gamma 基線顯著高於常人 |

**與意識的關係：** 部分神經科學家認為 Gamma 的跨區域同步是「意識整合」的神經基礎，但這仍是科學界的爭議話題。

## 三、五種腦波的對比總覽

| 波段 | 頻率 | 意識狀態 | 振幅 | 失衡方向 |
| :--- | :--- | :--- | :--- | :--- |
| **Delta** | 0.5–4 Hz | 深睡、昏迷 | 最大 | 清醒出現 → 腦部病變 |
| **Theta** | 4–8 Hz | 淺睡、冥想邊緣 | 大 | 清醒過多 → ADHD 傾向 |
| **Alpha** | 8–13 Hz | 放鬆清醒 | 中 | 不足 → 焦慮、無法放鬆 |
| **Beta** | 13–30 Hz | 主動思考 | 小 | 過多（高Beta）→ 焦慮、失眠 |
| **Gamma** | 30–100 Hz | 高度整合、洞察 | 最小 | 異常過多 → 癲癇風險 |

## 四、睡眠週期中的腦波

睡眠不是一個均一的狀態，而是不同腦波輪番主導的週期：

```
清醒 → Alpha ↑
入睡 → Theta ↑（N1，容易驚醒）
淺睡 → Sleep Spindles + K 複合波（N2，約佔 50%）
深睡 → Delta ↑（N3，身體修復、記憶鞏固）
REM  → Beta/Theta 混合（做夢，情緒整理）
```

每個週期約 **90 分鐘**，一夜 4–6 個週期。前半夜 Delta（深睡）比例高，後半夜 REM 比例增加——這是為什麼睡 6 小時和睡 8 小時在夢境體驗上差異很大。

> **Sleep Spindles（睡眠紡錘波）：** N2 階段特有的 12–15 Hz 短暫爆發波，被認為是記憶鞏固的關鍵機制，也是阻止外部刺激打斷睡眠的「守門人」。

## 五、腦波與疾病

| 疾病 | 腦波特徵 |
| :--- | :--- |
| **癲癇** | 發作時出現大量同步高振幅尖波；EEG 是診斷金標準 |
| **ADHD** | 清醒時 Theta/Beta 比值過高（大腦皮質活性不足） |
| **焦慮症** | Alpha 顯著下降，高 Beta 持續存在 |
| **憂鬱症** | 左前額葉 Alpha 不對稱增加（左側過度抑制） |
| **阿茲海默症** | Alpha、Beta 整體下降；Delta、Theta 異常增加 |
| **失眠** | 入睡時高 Beta 無法消退；深睡 Delta 比例不足 |

## 六、神經回饋（Neurofeedback）：訓練腦波

神經回饋是一種用腦波做生物回饋的訓練：即時偵測你的腦波，用聲音或視覺信號告訴你「現在是什麼狀態」，讓你學會有意識地調節。

**常見應用：**
- ADHD：訓練降低 Theta、提升 Beta（SMR 波）
- 焦慮與失眠：訓練提升 Alpha，降低高 Beta
- 運動員與表演者：訓練 Alpha/Theta 邊界（「入流」狀態）

**限制：** 研究顯示效果因人而異，訓練周期長（通常 20–40 次），成本高，且難以排除安慰劑效應。目前對 ADHD 的證據相對最強，其他應用仍在研究階段。

## 七、改變腦波的方法

| 方法 | 主要效果 | 機制 |
| :--- | :--- | :--- |
| **冥想** | 提升 Alpha、Theta；資深者增加 Gamma | 訓練前額葉調控；降低預設模式網絡活動 |
| **有氧運動** | 增加 Alpha；降低高 Beta | 降低皮質醇；提升血清素、多巴胺 |
| **閉眼休息** | 立即提升 Alpha | 減少視覺輸入，皮質進入怠速 |
| **深呼吸** | 降低高 Beta；提升 Alpha | 刺激迷走神經，啟動副交感神經 |
| **雙耳節拍（Binaural Beats）** | 誘導目標頻率（理論上） | 左右耳聽到微小頻差，腦自動同步 |
| **自然聲音／白噪音** | 穩定 Alpha；降低過度活躍 Beta | 提供均勻感覺輸入，減少雜訊干擾 |

> **雙耳節拍的爭議：** 商業產品宣稱能「同步大腦到特定狀態」，但目前研究顯示效果微弱且個體差異大，與其依賴它，不如直接練習冥想或控制呼吸。

## 結語

腦波是大腦電活動的節律快照，它告訴我們大腦當下正在做什麼——不是思考什麼內容，而是**以什麼模式運作**。從癲癇診斷到睡眠分期，從焦慮評估到冥想研究，腦波是神經科學最直接的測量窗口之一。理解腦波，就是理解意識狀態本身的物理結構。
