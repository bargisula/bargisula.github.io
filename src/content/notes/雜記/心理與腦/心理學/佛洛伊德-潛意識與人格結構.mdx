西格蒙德·佛洛伊德（Sigmund Freud）是精神分析學派的創始人，他的理論徹底改變了我們看待人類心智的方式。他認為，人類行為的背後並非完全由理智控制，而是受到深層心理動力的驅使。

---

### 1. 潛意識的「冰山理論」

佛洛伊德將人類的心智比喻為一座冰山，大部分的運作都隱藏在意識可及範圍之外。

| 層次 | 描述 | 比喻 |
| :--- | :--- | :--- |
| **意識** | 目前覺察到的思考與知覺 | 冰山露出水面的尖端 |
| **前意識** | 只要刻意回想就能提取的資訊 | 接近水面的區域 |
| **潛意識** | 存放壓抑的慾望、恐懼與創傷 | 巨大的水下主體 |

<Callout type="warning" title="核心理論">
  **潛意識**是左右行為最強大的力量。佛洛伊德認為，心理疾病往往源於潛意識中未解決的衝突。
</Callout>

---

### 2. 人格結構：內在的權力鬥爭

人格並非單一整體，而是由三個不斷互動且經常衝突的系統構成：

*   **本我 (Id)**
    *   **原則**：享樂原則 (Pleasure Principle)
    *   **特質**：生而有之，代表原始慾望（性、飢餓）。要求立即滿足，不顧現實。
*   **自我 (Ego)**
    *   **原則**：現實原則 (Reality Principle)
    *   **特質**：心智的「決策者」。負責協調本我的慾望與外界現實的限制。
*   **超我 (Superego)**
    *   **原則**：完美原則 (Moral Principle)
    *   **特質**：內在的道德警察。代表社會規範與理想，監督自我的行為。

<Callout type="insight" title="心理動力">
  當這三者失去平衡，焦慮便會產生。自我的任務就是要在本我的衝動、超我的嚴苛以及現實的殘酷之間，找到一個脆弱的平衡。
</Callout>

### 3. 夢的解析：潛意識的康莊大道

佛洛伊德認為夢是**「願望的達成」**，透過夢境，我們能窺視潛意識的秘密。

*   **顯意 (Manifest Content)**：夢中表面的情節、影像。
*   **隱意 (Latent Content)**：夢背後隱藏的真實願望或恐懼。

<Callout type="link" title="分析方法">
  透過「自由聯想」與「夢的解析」，治療師可以協助個體揭開顯意的偽裝，找出深層的隱意。
</Callout>

### 4. 性心理發展階段

佛洛伊德認為「力比多」（性力）在不同年齡會集中在不同的區域，形塑人格。

| 階段 | 年齡 | 焦點區域 | 人格特質與挑戰 |
| :--- | :--- | :--- | :--- |
| **口腔期** | 0-1 歲 | 嘴巴 | 依賴、信任感建立 |
| **肛門期** | 1-3 歲 | 肛門 | 控制感、權威與規矩 |
| **性器期** | 3-6 歲 | 生殖器 | 性別認同、戀母/戀父情結 |
| **潛伏期** | 6-青春期 | 無 | 社交、學習與同儕關係 |
| **兩性期** | 青春期後 | 生殖器 | 成熟的親密關係 |

<Callout type="data" title="固著現象">
  如果在某個階段遭遇挫折或過度溺愛，會產生**「固著」（Fixation）**。例如，口腔期固著的人成人後可能過度依賴他人或有暴飲暴食的傾向。
</Callout>

### 5. 自我的防衛機制

為了緩解焦慮，自我也會發展出多種**防衛機制**：

1.  **壓抑 (Repression)**：將痛苦記憶硬塞回潛意識。
2.  **投射 (Projection)**：將自己的負面慾望推給別人。
3.  **反向作用 (Reaction Formation)**：表現出與真實慾望相反的誇張行為。
4.  **昇華 (Sublimation)**：將衝動轉化為高度社會價值的行為（如藝術創作）。

### 總結

<Callout type="quote" title="經典名言">
  「未經表達的情感永遠不會消亡。它們只是被活埋，並將在未來以更醜陋的方式出現。」
</Callout>

佛洛伊德雖然在「性」的議題上備受爭議，但他揭示了人類**非理性**與**潛意識**的力量，這點至今仍深深影響著文學、藝術與心理諮商。
