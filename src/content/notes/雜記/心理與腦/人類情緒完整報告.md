## 一、情緒是什麼？人為什麼需要情緒

### 1. 情緒的定義
情緒 (Emotion) 是大腦對內外刺激的「快速評估系統」。它同時包含 3 個層面：

| 層面 | 說明 | 例子 |
| :--- | :--- | :--- |
| **生理反應** | 荷爾蒙、神經、內臟變化 | 心跳加速、冒汗、肌肉緊繃 |
| **主觀感受** | 你意識到的感覺 | 「我很害怕」、「我很開心」 |
| **行為傾向** | 情緒驅動你去做的事 | 恐懼 → 逃跑；憤怒 → 攻擊 |

> **核心功能：** 情緒不是麻煩，而是演化留下的生存工具。它幫助我們在 0.1 秒內判斷「靠近還是遠離」，比理性思考快 20 倍。

### 2. 情緒的分類

*   **6 大基本情緒**：跨文化、嬰兒期即存在。
    *   快樂（重複行為）、悲傷（求助）、憤怒（排除障礙）、恐懼（避開危險）、驚訝（警覺）、厭惡（避免中毒）。
*   **社會情緒**：需要自我意識與社會規則。
    *   羞愧、內疚、驕傲、嫉妒、共情（功能是維持群體合作）。

| 概念 | 持續時間 | 針對性 | 例子 |
| :--- | :--- | :--- | :--- |
| **情緒** | 強烈、短暫 | 針對具體事件 | 被狗追恐懼 5 分鐘 |
| **心境** | 微弱、持續 | 無明確對象 | 整天悶悶不樂 |
| **情感** | 穩定、長期 | 針對特定人事物 | 愛家人、熱愛音樂 |

## 二、情緒的生成機制：大腦如何運作

情緒是「身體感覺 + 前腦評估 + 經驗解釋」三方合作的結果，主要走兩個路徑：

### 1. 快路徑：活下來優先（約 0.12 秒）
*   **路徑**：刺激 → 丘腦 → **杏仁核** → 下視丘 → HPA 軸 → 全身警報。
*   **現象**：心跳加速、瞳孔放大。這解釋了為什麼被嚇到時，身體會先於意識做出反應。

### 2. 慢路徑：精準評估（多花約 0.3 秒）
*   **路徑**：刺激 → 丘腦 → 感覺皮質 → **前額葉評估** → 杏仁核 → 調整反應。
*   **現象**：前額葉 (PFC) 作為「情緒煞車」，負責分辨「是蛇還是繩子」。前額葉受損者容易暴怒或長期焦慮。

> **建構情緒理論 (Lisa Barrett)：** 情緒是「猜」出來的。
> **公式：** 情緒 = 身體感覺 + 情境 + 過去經驗 + 文化標籤。
> *同樣的心跳加速：*在鬼屋標記為「恐懼」；在告白現場標記為「心動」。改變解釋，就能改變情緒。

## 三、情緒失調：常見的情緒疾病

當快慢路徑、煞車系統或標記系統失靈，即演變為疾病。

| 疾病 | 核心機制 | 大腦變化 | 典型症狀 |
| :--- | :--- | :--- | :--- |
| **憂鬱症 (MDD)** | 煞車卡死 + 獎賞失靈 | 前額葉活性低、單胺類遞質不足、海馬迴萎縮 | 持續低落、失去興趣、無價值感 |
| **焦慮症 (GAD)** | 威脅雷達過度敏感 | 杏仁核過活躍、前額葉壓不住、GABA 不足 | 無法控制的擔心、心悸、失眠 |
| **恐慌症** | 身體訊號災難化解釋 | 杏仁核 + 腦島過度反應 | 突然窒息感、害怕失控、預期性焦慮 |
| **躁鬱症 (Bipolar)** | 油門與煞車皆損壞 | 多巴胺、麩胺酸波動劇烈 | 躁期亢奮亂花錢、鬱期重度憂鬱 |
| **PTSD** | 創傷記憶無法更新 | 杏仁核敏感、海馬迴縮小、抑制失敗 | 閃回、惡夢、過度警覺 |
| **ADHD** | 前額葉多巴胺不足 | 前額葉、基底核活性低 | 衝動、執行功能缺損、情緒調節差 |

## 四、治療：修復失調的系統

治療分為「修硬體」（生理治療）與「改軟體」（心理治療）。

### 1. 生理治療：化學物質與腦區調整

#### A. 抗憂鬱劑：修復煞車與獎賞系統

| 類型 | 常見藥物 | 機制 | 應用 | 注意事項 |
| :--- | :--- | :--- | :--- | :--- |
| **SSRI** | 樂復得、憂必晴、百憂解 | 增加血清素，強化煞車 | 憂鬱、焦慮、強迫症 | 2-4 週起效，不可驟停 |
| **SNRI** | 速悅、千憂解 | 提升血清素與正腎上腺素 | 憂鬱、慢性疼痛 | 可能使血壓升高 |
| **NDRI** | 威克倦 | 提升多巴胺與正腎上腺素 | 憂鬱、戒菸、ADHD 輔助 | 不影響性功能，癲癇禁用 |
| **NaSSA** | 樂活憂 | 直接促進遞質釋放 | 憂鬱伴隨嚴重失眠 | 嗜睡、體重增加 |

#### B. 抗焦慮劑與穩定劑

*   **BZD (苯二氮平)**：如贊安諾、安定文。強化 GABA，30 分鐘內壓住杏仁核。**具成癮性，僅限短期救急**。
*   **情緒穩定劑**：
    *   **鋰鹽 (Lithium)**：躁鬱症預防首選，需監測血中濃度與腎功能。
    *   **帝拔癲 (Valproate)**：穩定神經細胞膜。
    *   **樂命達 (Lamotrigine)**：針對躁鬱症憂鬱期，需預防嚴重皮膚過敏。

> **ADHD 專區：利他能 (Ritalin) / 專思達 (Concerta)**
> 這些藥物能補足前額葉的多巴胺，讓「行政中心」重新上線。ADHD 患者常共病憂鬱，當前額葉能管住行為後，情緒通常會連帶改善。

#### C. 非藥物生理治療
*   **rTMS (經顱磁刺激)**：利用磁場活化左前額葉，適用於難治型憂鬱。
*   **正念冥想**：長期練習可增加前額葉與杏仁核的連結，改變腦結構。

### 2. 心理治療：重訓大腦迴路

| 療法 | 核心技術 | 修復環節 | 適合對象 |
| :--- | :--- | :--- | :--- |
| **CBT (認知行為)** | 抓負面想法 → 找證據 → 換想法 | 修正「認知解釋」 | 憂鬱、焦慮、恐慌 |
| **DBT (辯證行為)** | 痛苦耐受 + 情緒調節 | 強化前額葉煞車 | 邊緣人格、情緒不穩 |
| **ACT (接納承諾)** | 接納情緒而不對抗 | 停止與情緒打架 | 慢性痛苦、焦慮 |
| **EMDR (眼動)** | 回憶時進行眼動引導 | 幫助海馬迴處理創傷 | PTSD、重大創傷 |

## 五、用藥與治療的關鍵觀念

1.  **藥物不是快樂丸**：它負責將情緒從 -10 拉回 0（恢復功能）。0 到 +10 的幸福感需靠心理治療、運動與人際連結。
2.  **試藥期與戒斷**：每個人對藥物反應不同，通常需試 2-3 種才找到合適的。**減藥必須花 6-8 週慢慢降**，以免觸電感或情緒反彈。
3.  **合併治療效果最佳**：藥物先把情緒穩住，心理治療才有空間重建迴路。

## 結語

*   **情緒** = 大腦用身體狀態預測世界的方式。
*   **情緒疾病** = 預測系統失準、煞車失靈、或前額葉沒油。
*   **治療** = 藥物調化學物質（修硬體） + 心理治療重建迴路（改軟體）。
