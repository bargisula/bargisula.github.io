| 現代商業要素 | 16 世紀東亞的情況 | 結果 |
| :--- | :--- | :--- |
| **需求端** | 中國缺銀繳稅、日本缺生絲與硝石、歐洲缺絲綢瓷器 | **三邊剛需爆表** |
| **供給端** | 日本石見銀山、中國江南生絲、印度硝石香料 | **三邊產能爆表** |

## 一、王直：一個人開了一整家「東亞亞馬遜」

王直的身份 = 平台創始人 + CEO + CTO + 法務 + 保安隊長。他為這個死結提供了完整的「雲端解決方案」：

| 平台功能 | 王直的方案 | 現代對標 |
| :--- | :--- | :--- |
| **基礎設施** | **雙嶼港**：在舟山填海造港，掛「五峰旗」受保護 | 菜鳥網絡 + 寧波港 |
| **支付系統** | **三角清算**：日銀→葡萄牙貨→中國生絲。補日本劣錢坑 | 支付寶 + SWIFT |
| **風險控管** | **五萬部隊**：佛郎機炮大船。丟貨王直賠 | 平台規則 + 順豐保價 |
| **商家運營** | **預付款制度**：預付徽州絲農、分期賣硝石給大名 | 淘寶小二 + 地推鐵軍 |
| **法務公關** | **多面外交**：對明「守海疆」，對日「進貢」 | GR (政府關係) |

## 三、平台倒閉後的連鎖反應 (1559 後)

1559 年王直在杭州被處死，明朝普天同慶，但接下來發生的事證明：**殺掉平台創始人，等於自斷供應鏈。**

1.  **行業大亂：** 物流還在，但平台沒了。小平台遍地開花，從「收保護費」轉向「上岸搶劫」，這才是「嘉靖大倭寇」突然變兇的原因。
2.  **黑市通膨：** 王直死後，生絲價格從 1 擔 500 兩飆漲到 2000 兩。明朝省了平台費，卻虧掉了整個江南的 GDP。
3.  **政策轉向：** 10 年後的 1567 年，明朝終於認慫實施「隆慶開關」。朝廷發現：合法交稅比跟海盜交易便宜。

## 四、誰繼承了王直的遺產？

王直雖然被殺，但他的「商業模式」被後來者全部接收並合法化了。

*   **鄭芝龍、鄭成功：** 繼承了五峰旗與武裝護航模式。
*   **豐臣秀吉：** 繼承了牌照與抽水模式（朱印船制度）。
*   **德川家康：** 繼承了匯兌與鑄幣模式（長崎會所）。
*   **荷蘭 VOC：** 繼承了武裝公司模式，領取政府授權書合法收保護費。

如果說明朝是把 App Store 下架的政府，葡萄牙是賣手機的硬體商，那 **王直就是越獄後自己搭伺服器、寫支付、做客服、養網警的民間版喬布斯。**
