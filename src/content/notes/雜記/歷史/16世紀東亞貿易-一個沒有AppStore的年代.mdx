| 現代商業要素 | 16 世紀東亞的情況 | 結果 |
| :--- | :--- | :--- |
| **需求端** | 中國：缺白銀繳稅。日本：缺生絲穿衣、缺硝石打仗。歐洲：缺絲綢瓷器 | **三邊剛需爆表** |
| **供給端** | 日本：石見銀山年產 10 萬兩。中國：江南生絲年產百萬擔。印度：硝石香料管夠 | **三邊產能也爆表** |

</Callout>

## 一、王直出場：他一個人開了一整家「東亞亞馬遜」

王直的身份 = 平台創始人 + CEO + CTO + 法務 + 保安隊長。他為這個死結提供了完整的「雲端解決方案」：

| 平台功能 | 王直的方案 | 解決哪個死結 | 現代對標 |
| :--- | :--- | :--- | :--- |
| **1. 基礎設施** | **雙嶼港**：舟山填海造港，建倉庫、船廠、炮台。誰掛「五峰旗」誰受保護 | **物流死結**：沒港口、沒航線、沒保險 | 菜鳥網絡 + 寧波港 |
| **2. 支付系統** | **三角清算**：日銀→澳門買葡貨→賣到中國換生絲→日本賣絲換銀。自鑄「金背錢」補日本劣錢坑 | **支付死結**：銀不能出海，錢不互信 | 支付寶 + SWIFT + USDT |
| **3. 風控部門** | **五萬部隊**：佛郎機炮大船 + 中日混編陸軍。明軍來就賄賂，黑吃黑就剿滅。丟貨王直賠 | **安全死結**：海盜、官軍、詐騙橫行 | 平台規則 + 順豐保價 + 公安局 |
| **4. 商家運營** | **徽州 + 九州 BD**：徽州老鄉包銷生絲，預付款鎖產能；日本大名包銷硝石，分期付款送教官 | **獲客死結**：買賣雙方互不信任，不敢先款 | 淘寶小二 + 地推鐵軍 |
| **5. 法務公關** | **三語合約**：對明「替天子守海疆」，對日「五峰船主進貢」，對葡「允許傳教」 | **法理死結**：三邊法律都說他違法 | 法務部 + GR 政府關係 |

</Callout>

## 二、各方跟王直的關係：既要罵他，又離不開他

王直是所有人的「必要之惡」。 大家都想免費使用他的平台，又不想承認他合法。

| 勢力 | 嘴上怎麼罵 | 心裡怎麼想 | 真實操作 |
| :--- | :--- | :--- | :--- |
| **明朝北京** | 「倭寇王直，罪大惡極」 | 海禁是祖宗家法，認錯 = 打臉 | 下令死剿，但每年從澳門收 30 萬兩葡人關稅，那錢就是王直洗進來的日銀 |

## 三、王直被絞殺後：平台倒閉，整個東亞經濟危機

1559 年王直在杭州被殺，明朝普天同慶。但接下來 10 年發生的事，證明殺他 = 自斷供應鏈。

1.  **物流還在，平台沒了 = 行業大亂**  
    葡萄牙船還在，但沒人敢靠岸。因為沒「五峰旗」保險，上岸就被當海盜。徽州商人沒人收貨，日本大名沒人供貨。結果就是「小平台」遍地開花：徐海、葉麻、陳東各佔一個島，從「收過路費」變成「上岸搶劫」。王直在時是管理者，王直死後全變破壞者。
2.  **供需缺口沒變，黑市通脹爆炸**  
    王直活著時，長崎生絲 1 擔 = 500 兩。死後 3 年漲到 2000 兩。日本大名買不起硝石，改回用弓箭。中國江南織戶破產，出現「民變」。明朝省了平台費，虧了整個江南 GDP。
3.  **10 年後明朝自己打臉：隆慶開關 (1567)**  
    朝廷終於認慫，開放福建月港，允許民間「領票出海」。政策一改，倭寇瞬間消失 90%。因為商人發現：合法交稅都比跟海盜交易便宜。

</Callout>

## 四、誰繼承了王直的遺產？

王直沒輸，他只是從「個人獨角獸」變成「行業標準」。 德川鎖國、鄭氏台灣、荷蘭 VOC，抄的全是王直作業。

*   **五峰旗 + 雙嶼港 → 鄭芝龍、鄭成功：** 台灣「一官黨」，收過路費收到跟荷蘭開戰。
*   **牌照 + 抽水 → 豐臣秀吉：** 朱印船制度，幕府發牌，取代私旗。
*   **匯兌 + 鑄幣 → 德川家康：** 慶長金銀 + 長崎會所，平台國有化。
*   **武裝護航 → 荷蘭東印度公司 (VOC)：** 公司版王直，拿政府授權書，合法收保護費。

## 結論：用一句話給王直定性

如果說明朝是把 App Store 下架的政府，葡萄牙是賣手機的硬體商，那 **王直就是越獄後自己搭伺服器、寫支付、做客服、養網警的民間版喬布斯。**

他被絞殺，不是因為他做海盜，而是因為他做得太成功，成功到讓皇帝沒面子。他死後 50 年，他的所有「違法功能」全部被朝廷一個個「合法化」：開港 = 隆慶開關；發牌照 = 朱印船；收稅 = 長崎海關；鑄幣 = 慶長金銀。

<Callout type="insight">
**歷史的諷刺：** 你把搭平台的人殺了，最後還是得把平台再搭一遍，只是招牌換成你的。信長、秀吉、家康能統一日本：他們繼承的不是王直的船，而是王直的平台思維 —— **物流可以外包，平台必須姓德川。**
</Callout>
