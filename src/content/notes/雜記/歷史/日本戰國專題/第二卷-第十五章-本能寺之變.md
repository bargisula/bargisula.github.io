1582年5月29日，信長住進京都本能寺，準備6月1日出陣打毛利。
兵力：100人。近侍只有森蘭丸、森力丸、森坊丸三兄弟+小姓30人。
他對光秀說：「你先去，我隨後到。」
光秀回：「是。」
6月2日凌晨，光秀到。 帶的不是先鋒，是1萬3千討死軍。
口號：「敵在本能寺！」
信長死，森蘭丸死，光秀只當三天天下人。
戰國，終。

## 一、本能寺：魔王最後一夜，100人對1萬3

本能寺，不是寺，是京都市中心豪華旅館。
法華宗本山，院子大，房間多，離皇宮近。
信長為啥住這？ 三個原因：
1. **裝逼**：本能寺是「天下第一名剎」，住這=告訴天皇「我來了」。
2. **方便**：離二條御所500米，隨時見天皇。
3. **大意**：京都附近全是自己地盤，柴田在北陸，秀吉在中國，家康在堺港。「全日本沒人敢動我。」

6月1日夜，信長行程：
- **喝茶**：跟千宗易喝茶，聊「天下布武後搞茶道」。
- **下棋**：跟村井貞勝下棋，贏了。
- **睡覺**：森蘭丸鋪床，「蘭丸，明早叫我。」
- **兵力佈置**： 門口4個衛兵，院子裡30個小姓。鐵炮？沒帶。
他以為光秀在趕去中國的路上。

光秀在哪？
6月1日，丹波龜山城。雨。
光秀開會：「諸君，信長可伐乎？」
明智秀滿：「主公，下決定吧。」
齋藤利三：「佐久間信盛、林秀貞，前車之鑑。」
光秀：「我非反織田，我反信長一人。」
「今夜，過桂川，直奔本能寺。」

部隊口號：「敵在本能寺！」
士兵問：「敵不是毛利？」
隊長：「少廢話，跟著走。」
1萬3千人，冒雨行軍。 沒人逃。
因為光秀平時待兵好，信長待兵狠。

凌晨4點，包圍本能寺。

## 二、開打：森蘭丸戰死，信長自焚，六天魔王退場

時間線，還原本能寺最後2小時：

- **4:00，明智軍到。**
森蘭丸值夜，聽見盔甲聲，衝出去看。
回來狂喊：「主公！明智謀反！」
信長爬起來：「光秀？不會。難道是……」
森蘭丸：「旗印是桔梗紋，明智軍！」
信長：「是非成敗轉頭空。」 穿衣服，拿刀。

- **4:10，進攻。**
明智軍，鐵炮齊射，弓箭覆蓋。
本能寺圍牆是土牆，一轟就塌。
森蘭丸，18歲，帶30小姓堵門口。
《信長公記》記：「蘭丸奮戰，槍刺七人，鐵炮中七彈而死。」
森力丸，16歲，弟弟，「兄長等等我」，戰死。
森坊丸，13歲，最小，「主公，我來了」，戰死。
森家三兄弟，全滅。

- **4:40，本能寺起火。**
明智軍放火燒房。 信長退到內殿。
小姓女房們切腹。信長對身邊小川祐忠說：
「女人小孩，莫要受辱。你介錯。」
小川祐忠砍完女房，信長說：「你也去吧。」

- **5:00，自焚。**
信長最後一句話，眾說紛紜：
- **版本1**：「然らば是非に及ばず」=「是非成敗，不說了。」
- **版本2**：「女はくるな」=「女的別過來。」 怕屍體被辱。
然後點火，切腹。享年49歲。

火太大，明智軍衝進去，找不到屍體。
光秀：「首級呢？」
找不到。 信長讓小姓把屍體燒成灰了。
所以後世傳說：「信長沒死，跑了。」
其實死了， 只是沒留全屍。

- **5:30，二條御所。**
織田信忠，信長嫡長子，住二條御所，兵1500。
明智軍轉攻二條。 信忠打2小時，寡不敵眾，切腹。24歲。
織田家，家主+繼承人，一夜沒了。

## 三、三天天下：光秀為啥敗？因為沒人跟他

6月2日，光秀進京都，發**《討伐信長理由書》**：
「信長，第六天魔王，佛敵，朝敵，殘虐不仁。」
「我明智光秀，替天行道。」

然後等各路大名響應。
結果：

| 大名 | 反應 | 原因 |
| :--- | :--- | :--- |
| **柴田勝家** | 北陸，回不來 | 下雪，路斷 |
| **丹羽長秀** | 大阪，觀望 | 「光秀你瘋了」 |
| **德川家康** | 堺港，伊賀穿越逃跑 | 「我兵少，不摻和」 |
| **細川藤孝** | 光秀親家，剃頭出家 | 「我兒娶你女兒，但我不跟你反」 |
| **筒井順慶** | 大和，洞ヶ峠觀望 | 「誰贏我幫誰」 |
| **羽柴秀吉** | 中國，5天狂奔200公里 | 「光秀，我來取你命」 |

光秀在京都，等3天，沒一個大名投他。
為啥？
1. **名分**：信長是「天下人」，光秀是「叛臣」。跟光秀=跟全織田家為敵。
2. **速度**：秀吉5天從備中殺回來，「中國大返還」。光秀來不及聯合。
3. **人心**：信長再殘暴，也是主君。日本武士道，背主=垃圾。

6月13日，山崎之戰。
秀吉3萬 vs 光秀1萬。
筒井順慶關鍵時刻倒戈，加入秀吉。
光秀大敗，逃亡。
在小栗栖被農民竹槍捅死。享年55歲。
辭世句：「順逆無二門，大道徹心源。五十五年夢，覺來歸一元。」

從本能寺到死，11天。
史稱「三日天下」。

## 四、本能寺黑幕：光秀為啥反？四種說法

400年了，沒定論。但怨氣是真的。

1. **野心說**：光秀想當天下人
光秀漢詩寫：「五月雨，染霧籠碧天。」
「我心如碧天，何日能晴？」
他覺得自己比信長有文化，比秀吉有謀略。
信長不死，他永遠是家臣。

2. **怨恨說**：四條怨氣
上一章說了：搶功+羞辱+沒收領地+殺母。
安土城宴會，信長打他頭：「禿頭！」
武士的頭，比命重要。

3. **黑幕說**：有人指使
- **朝廷黑幕說**：正親町天皇恨信長，想立信忠。
- **將軍黑幕說**：足利義昭在流放地，寫信給光秀。
- **耶穌會黑幕說**：信長要滅佛教，也要滅天主教，光秀信天主教。
證據？沒。 但光秀死太快，沒口供。

4. **偶發說**：被逼的
信長讓光秀去中國， 但把丹波近江收走。
等於「你去送死，老家沒了」。
光秀：「橫豎是死，不如搏一把。」

弗洛伊斯記：
「光秀叛，非一人之心。全日本恨信長者，皆光秀也。」
「信長燒寺、殺降、羞辱家臣，積怨如山。」
「本能寺火，是怨氣點的。」

## 五、阿市的哭：兄長死了，女兒沒了

本能寺之變，阿市在北之莊城。
柴田勝家從上野回來，帶回消息：「夫人，主公沒了。」
阿市沒哭，問：「茶茶呢？」
勝家：「在安土，被明智秀滿劫走。」
阿市：「備轎，我去京都。」

到京都，本能寺燒成灰。
阿市在灰裡，撿到一片金箔瓦。
是安土城的瓦，信長送她的。
她對勝家說：
「兄長49歲，燒比叡山，烤長島，屠越前，餓石山。」
「殺人太多，終於輪到自己。」
「勝家，你我，以後也這樣。」

1年後賤ヶ岳，勝家敗。
阿市跟勝家自殺前，說：
「兄長本能寺，我北之莊。
「織田家女兒，沒一個好死。」

茶茶被秀吉救走，後來成豐臣夫人。
阿市如果知道，會說：
「從魔王的外甥女，變猴子的女人。
「茶茶，你命比我還苦。」

## 六、世界同期番外：1582年6月21日，信長死，教皇改曆法

| 國家/地區 | 當時在忙什麼 | 歷史巧合 |
| :--- | :--- | :--- |
| **大明 萬曆十年** | 張居正死，萬曆抄家。國本動搖 | 大明：信長死，張居正死。東西帝國支柱同年崩 |
| **葡萄牙王國** | 已亡國，澳門聽西班牙 | 葡萄牙：信長最大客戶死，軍火生意崩。澳門衰落 |
| **西班牙王國** | 1582年10月改格里曆，刪10天 | 西班牙：信長死於儒略曆6月2日=格里曆6月21日。他死，舊曆法跟著死 |
| **奧斯曼帝國** | 後宮干政，蘇丹被架空 | 奧斯曼：信長被家臣殺，蘇丹被後宮殺。君主都死於身邊人 |
| **英格蘭王國** | 備戰無敵艦隊，德雷克封爵 | 英國：信長死，日本亂。英國趁機搶南蠻貿易 |
| **法蘭西王國** | 亨利三世絕嗣，內戰 | 法國：信長死，瓦盧瓦死。1582年，統治者淘汰年 |

**世界總結：**
1582年6月21日，格里曆，信長死。
1582年10月，格里曆上線，世界少10天。
信長死，舊曆法也死。
新時代：秀吉檢地，家康鎖國，英國打西班牙。
本能寺一把火，燒掉戰國，也燒掉中世紀。

> **本章金句**
> 本能寺之變，信長用死給戰國上最後一課：「魔王也會死。」
> 1. **兵再少也要帶**。 100人住京都，1萬3千人圍城。自信=自殺。
> 2. **家臣要哄**。 打光秀頭，收光秀地，殺光秀母。怨氣攢夠，本能寺見。
> 3. **火燒多了，會燒自己**。 比叡山、長島、越前、石山、天目山，燒一路。最後一把火，燒在本能寺。

1582年6月2日凌晨，森蘭丸喊：「明智來了！」
信長笑：「是非成敗轉頭空。」
點火，切腹。
森蘭丸18歲，抱著信長一起燒。「主公，我來了。」

火光裡，信長想起桶狹間，2千打2萬。
想起長篠，3000鐵炮打武田。
想起安土城，6層天守看地球儀。
最後想起阿市：「妹，哥先走了。」

火滅，魔王退場。
戰國結束。
天下，從織田家，掉到地上。
猴子、光秀、家康，三個人搶。
最後猴子撿到，叫豐臣秀吉。

**六天魔王，六天結束：**
- 第一天：尾張傻瓜。
- 第二天：桶狹間。
- 第三天：燒比叡山。
- 第四天：長篠鐵炮。
- 第五天：安土天守。
- 第六天：本能寺火。

信長，49歲，完。
