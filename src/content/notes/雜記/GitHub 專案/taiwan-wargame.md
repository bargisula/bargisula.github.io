# 🛡️ 台海兵棋推演系統 (v3.0)

> **「未料勝，先料敗；以數據洞察變數，以模擬預見未來。」**

面對高度複雜且充滿變數的戰略情境，傳統的直覺分析已不足夠。**台海兵棋推演系統**是一款專為學術研究與決策支援打造的「量化分析工具」。它將軍事、後勤、政治與國際干預等變數模型化，透過成千上萬次的模擬，找出通往穩定的關鍵變數。

---

### 🌟 核心亮點：為什麼它與眾不同？

| 特點 | 說明 |
| :--- | :--- |
| **蒙地卡羅統計分析** | 執行數百次隨機種子模擬，產出勝率分布與信賴區間，拒絕單一的「定數預測」。 |
| **強化學習 (RL) 演化** | 採用 REINFORCE 演算法，讓 AI 藍紅兩軍在反覆對抗中尋找最優防禦策略與進攻漏洞。 |
| **多維度變數建模** | 涵蓋颱風路徑、能源封鎖、斬首行動、核武脅迫及國際介入等多種極端情境。 |
| **互動式戰略地圖** | 結合 GeoJSON 與實時數據，視覺化呈現機場、軍港、雷達站及部隊動態。 |

---

### 🛠️ 深度分析模組

*   **📊 敏感度與反事實分析：** 
    「如果美軍延後三天介入會發生什麼？」、「如果防空效能提升 20% 對戰局的影響？」系統支援即時調整參數，觀察結果的動態變化。
*   **📂 豐富的情境資料庫：** 
    內建 33 個預設情境，涵蓋從 2024 封鎖演習到 2027 全面登陸的各種評估框架，讓研究者能快速切換不同假設。
*   **📉 多維度勝負條件：** 
    定義了 11 種結局（如台北淪陷、能源投降、彈藥耗盡、政治瓦解等），全面反映現代戰爭的複雜面向。

---

### 💻 技術棧與系統架構

為了追求運算效率與極致的視覺展現，系統採用了最前沿的技術：

*   **Backend:** Python 3.11 + FastAPI + DuckDB (高性能數據查詢)
*   **Frontend:** React 18 + Vite + Tailwind CSS (流暢的互動體驗)
*   **RL Engine:** 輕量化 NumPy 實作（無需重型 GPU 框架，在一般筆電即可運行）
*   **Visuals:** Recharts + GeoJSON 圖層 (數據與地理資訊的完美融合)

---

### 💡 結語

**台海兵棋推演系統**將「戰爭」這門藝術，轉化為可以被拆解、觀察與優化的「科學」。它不是為了預測戰爭，而是為了透過模擬與學習，讓我們更深刻地理解衝突的代價與和平的邏輯。
