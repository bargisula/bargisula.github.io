## ⏰ 定時節奏

建議按固定頻率主動觸發：

| 頻率 | Skill | 說什麼 | 產出 |
|---|---|---|---|
| **每日**（早上） | `daily-report` | 「今日日報」 | 台灣理財 + 勞動 + 軍事新聞草稿，確認後推上部落格 |
| **每週**（週末 / 週一） | `us-weekly-report` | 「寫美股週報」 | 三層供應鏈瀑布，找本週受益 / 輸家，推上部落格 |
| **每週**（有重要數據時）| `macro-scan` | 「總經掃描」 | CPI、FOMC、就業數據週才值得跑；輸出 risk-on / risk-off 判斷 |

## 🖐️ 手動觸發時機

有具體事件才觸發，不需固定頻率：

| 何時觸發 | Skill | 說什麼 |
|---|---|---|
| 看到值得記錄的市場新聞、分析師觀點 | `flash` | 貼新聞 or 說「記下來」 |
| 想回顧本月快訊記錄 | `/flashlog` | `/flashlog` 或 `/flashlog 黃金` |
| 財報發布（持倉 / 觀察股） | `earnings` | 「看 NVDA 財報」 |
| 財報後股價大漲大跌，判斷值不值得深研 | `quick-scan` | 「快篩 PLTR」 |
| 看到 Seeking Alpha / Barron's 選股清單 | `stock-scout` | 貼文章 + 「幫我篩」 |
| 有 AI 供應鏈重大新聞（NVIDIA、TSMC、SK Hynix） | `ai-infra-scan` | 貼新聞 + 「怎麼看」 |
| 黃金有重大行情（金價破位 / 央行大量購金） | `gold-analysis` | 「黃金現在怎麼看」 |
| 對某行業建立投資世界觀、找瓶頸標的 | `leopold-model` | 「Leopold模型 資料中心」 |
| 決定深研某標的，要寫成部落格文章 | `stock-analysis` | 「分析 AVGO」或「深度分析 CRWD」 |
| 有個股名字想快速了解基本面 | `/stock-scan` | `/stock-scan NVDA` |

## Skills 完整清單

### 📊 個股 / 選股分析

| Skill | 觸發詞 | 功能 | 輸出 |
|---|---|---|---|
| `stock-analysis` | 「分析 NVDA」/ 「深度分析 PLTR」/ 「CoWoS 分析」 | 三模式：台股六模組瓶頸→溢出 / 美股標準七模組 / 美股深度六節原創洞察 | `投資/台股/` 或 `投資/美股/` |
| `quick-scan` | 「快篩 TICKER」「塊篩」「先掃一下」 | 財務快照 + 核心論點，判斷「值不值得繼續看」 | `投資/美股/[TICKER]-快篩.mdx` |
| `earnings` | 「看 TICKER 財報」「抓 TICKER earnings」 | 直抓 SEC EDGAR / 公開資訊觀測站，五段財報分析 | 對話輸出，詢問是否存檔 |
| `stock-scout` | 貼選股文章 + 「幫我篩」「掃這篇」 | 解析 ticker → 補估值數據 → 四維評分 → 優先清單 | 對話輸出 |
| `leopold-model` | 「Leopold模型 [行業]」「用Leopold分析 [主題]」 | 世界觀 → 物理瓶頸 → 押解決者 → 做空被替代者 | 對話輸出 |

### 📰 新聞 / 快訊

| Skill | 觸發詞 | 功能 | 輸出 |
|---|---|---|---|
| `flash` | 貼新聞 / 「記下來」「快訊」 | 自動解析情緒、標的、來源，同步寫入本機 + 部落格，git push | `flash-notes/YYYY-MM.md` + `投資/快訊/YYYY-MM.mdx` |
| `ai-infra-scan` | 貼 AI 新聞 / 「幫我解讀」「這對誰影響最大」 | 六層瓶頸框架（算力/記憶體/封裝/網路/電力/需求），輸出影響鏈 + 投資訊號 | 對話輸出 |

### 🌐 總經 / 市場框架

| Skill | 觸發詞 | 功能 | 輸出 |
|---|---|---|---|
| `macro-scan` | 「總經掃描」「這週有什麼數據」「risk-on 還是 risk-off」 | 搜尋當週重要總經指標，輸出一頁式市場模式判斷 | 對話輸出，詢問是否存檔 |
| `gold-analysis` | 討論黃金走勢 / 央行購金 / 去美元化 | 五維分析（實質利率 / 美元 / 央行 / 地緣 / 技術面） | 對話輸出 |

### ✍️ 文章 / 日報寫作

| Skill | 觸發詞 | 功能 | 輸出 |
|---|---|---|---|
| `daily-report` | 「今日日報」「寫日報」 | 搜尋台灣理財 + 勞動新聞，草稿確認後推上部落格 | `投資/理財日報/` + `勞動/勞動日報/` |
| `us-weekly-report` | 「寫美股週報」「瀑布分析」「供應鏈分析」 | 三層產業瀑布，找第二、三層間接受益者與輸家 | `投資/美股/` |

### 🛠️ 工具

| Skill | 觸發詞 | 功能 |
|---|---|---|
| `menu` | 「skill」「有哪些 skill」「列出 skill」 | 列出所有 skill，互動式選擇 |

## Commands（手動輸入 `/` 開頭）

| 指令 | 用法範例 | 功能 |
|---|---|---|
| `/flash [內容]` | `/flash 黃金 #看多 高盛目標價 3500` | 記錄市場快訊到本月 MD 檔 + 部落格 |
| `/flashlog [條件]` | `/flashlog` 或 `/flashlog NVDA #財報` | 查閱本月快訊，可篩選標的或標籤 |
| `/stock-scan [代號]` | `/stock-scan NVDA` | 個股五維掃描（價格 / 基本面 / 新聞 / 供應鏈 / 分析師）|

## 附錄

### flash 標籤規則

| 標籤 | 說明 |
|---|---|
| `#看多` / `#看空` / `#中性` | 情緒標籤（未標記預設中性） |
| `#觀點` / `#數據` / `#財報` / `#法說` / `#地緣` / `#產業` | 類型標籤 |
| 大寫英文（NVDA）或四位數（2330） | 自動識別為股票代號 |

### daily-report 確認語法

| 輸入 | 動作 |
|---|---|
| 「確認」 | 兩份都推（理財 + 勞動） |
| 「理財確認」 | 只推理財日報 |
| 「勞動確認」 | 只推勞動日報 |
| 「修改 [哪份] [哪節]：[內容]」 | 修改草稿後重新預覽 |

### stock-analysis 模式速查

| 觸發詞 | 模式 | 框架 |
|---|---|---|
| 「分析 NVDA」「寫文章 AVGO」 | 美股標準 | 七模組（定位 / 財務 / 護城河 / 瓶頸 / 台股連動 / 催化劑 / 風險） |
| 「深度分析 PLTR」「深挖 CRWD」 | 美股深度 | 六節原創洞察，先討論架構再動筆 |
| 「分析 CoWoS」「HBM 供應鏈」 | 台股 | 六模組瓶頸→溢出（技術定位 / 供應鏈 / 瓶頸 / 時程 / 關注點 / 輸家） |
