## Skills — 對話中自動觸發

說出觸發詞，Claude 自動套用對應框架，不需手動輸入指令。

| Skill | 觸發詞 | 功能 | 輸出 |
|---|---|---|---|
| `flash` | 貼新聞、「記下來」「存起來」 | 解析市場快訊，記錄情緒標注 | `flash-notes/YYYY-MM.md` |
| `daily-report` | 「今日日報」「寫日報」 | 搜尋台灣理財 + 勞動新聞，草稿確認後推上 | 部落格 |
| `tech-analysis` | CoWoS、HBM、先進封裝、台股技術關鍵詞 | 六模組台股產業技術分析文章 | `投資/台股/` |
| `us-tech-analysis` | 美股 ticker + 「分析」「寫文章」 | 七模組美股產業分析，含台股連動 | `投資/美股/` |
| `us-weekly-report` | 「寫美股週報」「瀑布分析」「下一個受益股」 | 美股週報 + 供應鏈三層瀑布分析 | `投資/美股/` |
| `deep-analysis` | 「深度分析 TICKER」「深挖這家公司」 | 六節深度報告：業務→市場→護城河→財務→趨勢→風險 | `投資/美股/` |
| `quick-scan` | 「快篩」「塊篩」「快速掃描 TICKER」 | 精簡快篩文章，直接推上部落格 | `投資/美股/` |
| `stock-scout` | 貼選股文章 + 「幫我篩」「哪幾支值得看」 | 解析選股文章，四維評分，輸出優先清單 | 對話 |
| `ai-infra-scan` | 貼 AI 新聞 + 「幫我解讀」「這對誰影響最大」 | AI 基礎設施新聞解讀，六層供應鏈定位 | 對話 |
| `earnings` | 「看 TICKER 財報」「抓 earnings」 | 抓 SEC EDGAR 原始申報，快速財報解讀 | 對話 |
| `macro-scan` | 「總經掃描」「這週有什麼數據」「macro」 | 搜尋重要總經指標，risk-on/off 判斷 | 對話 |
| `gold-analysis` | 黃金走勢、央行購金、去美元化 | 黃金五維分析框架（自動套用） | 對話 |
| `menu` | 「有哪些 skill」「列出 skill」「menu」 | 列出所有 skill，互動式選擇 | 對話 |

## Commands — 手動輸入（`/` 開頭）

| 指令 | 用法範例 | 功能 |
|---|---|---|
| `/flash [內容]` | `/flash 黃金 #看多 高盛目標價 3500` | 快速記錄市場快訊到本月 MD 檔 |
| `/flashlog [條件]` | `/flashlog` 或 `/flashlog NVDA #財報` | 查閱本月快訊，可篩選標的或標籤 |
| `/stock-scan [代號]` | `/stock-scan NVDA` | 個股五維掃描（價格/基本面/新聞/供應鏈/分析師）|

## flash 標籤規則

| 標籤 | 說明 |
|---|---|
| `#看多` / `#看空` / `#中性` | 情緒標籤（未標記預設中性） |
| `#事件` / `#數據` / `#財報` / `#法說` / `#地緣` | 類型標籤 |
| 大寫英文（NVDA）或四位數（2330） | 自動識別為股票代號 |

## 日報確認語法

`daily-report` 輸出草稿後，輸入以下確認推送：

| 輸入 | 動作 |
|---|---|
| 「確認」 | 兩份都推（理財 + 勞動） |
| 「理財確認」 | 只推理財日報 |
| 「勞動確認」 | 只推勞動日報 |
| 「修改 [哪份] [哪節]：[內容]」 | 修改草稿後重新預覽 |
