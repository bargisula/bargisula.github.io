## 事件摘要

2026年5月19日，陸軍**聯合兵種第234旅聯兵第1營**戰車連在**南測中心**（台南內角營區）實施年度戰車砲**習會射擊**。操作 **CM11勇虎式戰車**，以105mm破甲榴彈對1,200公尺外規正靶實施靜對靜射擊。

任務區分三個階段：
1. **車外擊發**：架設手擊發裝置，確認火砲擊發效能，做為後續實彈射擊的安全前提
2. **規正射擊**（檢驗射擊）：射擊兩發，依彈著點換算修正量，再調整管狀鏡、熱像鏡、白晝鏡三鏡十字絲同步重疊，確保射控系統諸元一致
3. **不發火狀況處置**：模擬彈藥未引爆，官兵依規定時間靜置等候，完成退彈與再次擊發流程——這是戰場安全操作的核心程序，一旦失誤可能釀成膛炸或彈藥意外

整備期間，未爆彈處理組對每發105mm破甲榴彈逐發鑑濾，確認彈體與引信狀況正常，方才放行進入實彈程序。

## 核心裝備：CM11勇虎式戰車

CM11是台灣自行整合的「混種戰車」——以美製零件組合出當時台灣能取得的最佳配置：

| 部件 | 來源 |
|------|------|
| 車體（Hull） | M60A3 戰車車體 |
| 砲塔（Turret） | M48A5PI 龜殼型砲塔 |
| 火控系統（FCS） | 衍生自 M1 艾布蘭（數位彈道電腦＋熱顯像） |

**完整規格：**

| 項目 | 數值 |
|------|------|
| 戰鬥重量 | 52公噸 |
| 乘員 | 4人（車長、砲手、裝填手、駕駛） |
| 主砲 | M68A1 105mm 線膛砲 |
| 同軸機槍 | M240 7.62mm |
| 車長機槍 | 白朗寧M2 12.7mm（以色列Urdan低輪廓砲塔） |
| 引擎 | AVDS-1790-2 V12 柴油，750匹馬力 |
| 最高公路速度 | 48 km/h |
| 公路行程 | 463 km |
| 夜視系統 | AN/VSG-2 熱顯像儀（全天候） |
| 測距儀 | AN/GVS-5 Nd-YAG 雷射測距 |
| 砲塔正面裝甲 | 178mm（最厚處） |
| 對2000m固定目標首發命中率 | 82% |

CM11的優勢集中在**火控系統**——來自M1艾布蘭的數位彈道電腦與熱顯像夜視，比M60A3的類比光學系統領先一個世代，讓CM11具備全天候作戰與動對靜射擊能力。

**主要弱點**：龜殼型M48砲塔防護力不如M60A3的長鼻型砲塔；砲塔內部空間狹小，電子設備散熱不足；引擎750hp在現代標準中偏弱。

## 105mm破甲榴彈：為什麼選HEAT而非穿甲彈？

此次射擊使用的「105mm破甲榴彈」屬 **HEAT（High-Explosive Anti-Tank）成形裝藥彈**，台灣型號對應 M456 系列。

HEAT的穿甲邏輯與動能穿甲彈（APFSDS）不同：

- **動能彈**（翼穩脫殼穿甲彈）：靠高速金屬棒動能硬穿裝甲，速度越快效果越好，射程越遠動能越低
- **HEAT**：靠引爆後銅藥型罩形成的高速金屬射流貫穿裝甲，**穿甲能力不受距離衰減**，適合1,200公尺習會射擊課目

然而 M68A1 是**線膛砲**，砲彈旋轉會讓金屬射流因離心力分散，降低HEAT效能。因此 M456 彈藥設計了滾珠軸承，使彈體外壳高速旋轉而內部裝藥保持低速——這是線膛砲使用HEAT的工程折衷。

此次習會射擊目的非測試穿甲效果，而是校正砲管與瞄準系統（規正）——HEAT在此僅作為標準射擊彈藥使用。

## 規正射擊的技術邏輯：為何要對三鏡？

此次射擊重點之一是「**三鏡對正**」：

```
管狀鏡（機械瞄準）
熱像鏡（紅外線夜視）  → 三者十字絲同步重疊
白晝鏡（光學日視）
```

戰車火控系統在震動、高溫、長期使用後，三個瞄準系統的視線軸會產生偏差，即使彈道電腦給出正確諸元，若瞄準系統「各看各的」，射擊仍會偏差。規正程序就是透過實彈找出偏差量，再逐一校準，確保三鏡在任何狀況下都對準同一目標點。

這也是習會射擊必須在**南測中心靶場**（而非駐地模擬器）實施的原因——只有真實彈著點才能提供精確的校正依據。

## 習會射擊制度：訓練層次的定位

| 層次 | 名稱 | 說明 |
|------|------|------|
| 1 | **習會射擊** | 年度基礎資格射擊，維持射手技能，在南/北測中心執行 |
| 2 | **基地鑑測** | 聯兵營完整戰術課目考核，含砲射、機動、協同火力 |
| 3 | **三軍聯合訓練測考** | 最高層次，各軍種協同射擊，等同實戰驗證 |

習會射擊是基地鑑測的**前置資格條件**——射手通過習會後，才能進入聯兵營整體的戰術層次評估。

2020年聯兵營編成後，戰車連的鑑測已整合入聯兵營架構，理論上增加了戰車與步兵、迫砲、防空協同的訓練比重。此次234旅在269旅同日完成迫砲基地鑑測的背景下分別受訓，可視為第十軍團與第六軍團同步推進年度訓練周期的平行展示。

## 關鍵脈絡：CM11的封存倒數

放在更大背景中，這次習會射擊有一層特殊意義——**CM11已確認逐步封存**。

| 項目 | 狀況 |
|------|------|
| CM11（450輛） | 2025年7月確認無升級計畫，陸續封存（非汰除） |
| CM12（100輛） | 全數後送兵整中心拆件，確定退役 |
| M60A3（460輛） | 規劃升級後繼續服役 |
| M1A2T（108輛） | 三批交付已完成，269旅首先換裝，其餘旅接續 |

234旅目前尚未換裝M1A2T，仍操作CM11。因此本次實彈訓練屬**CM11服役末期的維持性訓練**——在換裝完成前，確保現役射手不因等待換裝而喪失操砲資格。這一維持節奏正是「戰力不斷層」的具體體現。

234旅曾於2023年三軍聯合測考中，以CM11配合F-16、AH-1W武裝直升機與艦砲完成聯合火力測驗，展示中部防衛體系的整合能力。換裝M1A2T後，這一協同架構將以更強的火控與防護能力延續。

## 南測中心：台灣南部的戰力驗證節點

**正式名稱**：陸軍部隊訓練南區聯合測考中心  
**位置**：台南市內角營區（白河地區）  
**成立**：1967年（前身為陸軍第二部隊訓練考核指揮部）

南測中心是陸軍各南部旅基地鑑測的標準場地，設有戰車實彈射擊靶場、複合模擬訓練設施與整合模擬器。234旅從清泉崗南下受測屬常態——戰車射擊需要具備射程的靶場，駐地周邊通常無法滿足需求。

## 評析

**這是一次例行訓練，也是一個體制展示**

習會射擊本身是年度必須課目，沒有「要不要做」的選擇。但在520週年的媒體窗口期，陸軍選擇讓這則例行訓練見報，與584旅夜間機動、269旅迫砲鑑測共同構成當日第六軍團與第十軍團的多線平行展示——這是一種刻意的「總體戰力面貌」溝通。

**CM11時代接近尾聲，但訓練不能停**

換裝M1A2T的旅需要時間進行轉訓，在這段過渡期中維持CM11射手資格，防止「等裝備而荒廢技能」，是陸軍必須處理的實際問題。234旅此次習會，正是這個問題的正確解法。
