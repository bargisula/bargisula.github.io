# company-profile SKILL

## 觸發條件
當收到美股或台股 Ticker/公司名稱，並包含關鍵字「公司底稿」、「生成底稿」、「寫底稿」、「建立底稿」等。

---

## 執行流程

```
收到指令（例如：「幫我生成 RDW 公司底稿，推上去merge」）
  ↓
步驟 1：檢索與收集公開事實數據
  → 沿革、創辦人、總部、上市資訊
  → 近三年營收結構（業務線占比 / 客戶別 / 地理別）
  → 核心產品與規格、主要生產設施與自製策略
  → 目標市場、主要客戶、重要公開合約金額
  → 至少三家競爭對手比較（技術路線 / 市場定位 / 規模）
  → 近三年及最新季度關鍵財務指標（營收、毛利率、淨損益、現金、EPS）
  → 重要策略聯盟或收購整合事實
  ↓
步驟 2：建構 Astro MDX 檔案
  → 套用 Frontmatter 與 Callout 格式
  → 嚴格遵守「僅陳述公開事實，不含買賣建議與論點」
  ↓
步驟 3：寫入指定目錄並執行 git add/commit/push
```

---

## Frontmatter 格式規則（固定格式，不可更動）

```yaml
---
title: '【公司底稿】[TICKER] [公司中文名或英文全名]'
description: '60字內，核心業務＋一句關鍵數字'
category: '投資'
subcategory: '美股' # 台股則填台股
topic: '公司底稿'
pubDate: 'YYYY-MM-DD'
---
```

檔案第一行引入 Callout 元件：
```astro
import Callout from '@components/Callout.astro'
```

首段固定格式：
```markdown
> **底稿定位：** 僅陳述公開可驗證事實，不含論點與買賣建議。最後更新：YYYY-MM-DD
```

## 內容架構（五章節）

### 一、公司簡介
1. **沿革與背景**：表格呈現成立年、創辦人、總部、掛牌資訊、一句定位。
2. **業務分類與營收結構**：表格呈現近三年各業務線占比、客戶結構或地理占比，包在 `<Callout type="data">` 內，標注來源。

### 二、產品與技術
1. **核心產品說明**：規格比較表。
2. **供應商與製造**：主要原物料、代工廠或自製策略、主要設施。

### 三、市場與競爭
1. **目標市場與客戶**：市場定位、主要客戶、重要合約（含金額，若已公開）。
2. **競爭廠商比較表**：至少三家，列出技術路線／市場定位／規模，包在 `<Callout type="data">` 內。

### 四、財務概況
- **警示性事實**：例如產能瓶頸、毛利率暴跌、虧損擴大等，包在 `<Callout type="warning">` 內。
- **關鍵指標表**：近三年及最新季度的營收、毛利率、淨損益、現金、EPS 表格，包在 `<Callout type="data">` 內，標注來源（SEC / 財報）。

### 五、策略聯盟（選填）
- 只在合作深度對理解公司重要時才寫（例如：獨家合約、預付款已到帳、重大收購整合）。

## 格式細則

- **表格規範**：所有表格均使用標準 Markdown table。
- **貨幣格式**：數字若含貨幣符號，必須轉換為「億美元」「百萬美元」等中文寫法（例如：以 `100.00M` 或 `1.00億` 表示，不使用裸 `$` 加上數字）。
- **Callout 使用規範**：
  - 多數據表格包在 `<Callout type="data"> ... </Callout>` 內。
  - 警示性事實（如產能瓶頸、虧損擴大）包在 `<Callout type="warning"> ... </Callout>` 內。
- **結尾標註（固定格式）**：
  ```markdown
  *來源：公司財報、SEC 10-K、公司公告。事實如有異動，請更新對應章節，論點與估值另行撰文。*
  ```
