# 今日日報 SKILL

## 執行流程

```
搜尋 4 大類別新聞 → 彙整候選標題（附序號）→ 使用者挑選序號 → 產出選定類別草稿（對話中預覽）→ 等待使用者確認 → 寫檔 → git push
```

**關鍵規則：草稿確認前不寫任何檔案。**
使用者說「確認」「OK」「推上去」「全部推」→ 所有選定草稿全推。
使用者說「理財確認」→ 只推理財日報。
使用者說「勞動確認」→ 只推勞動日報。
使用者說「軍事確認」→ 只推軍事日報。
使用者說「不動產確認」→ 只推不動產日報。
使用者說「修改 [哪份] [哪節]：[修改內容]」→ 調整後重新預覽。

---

## 步驟 1：取得今日日期

取得今日日期：
- HYPHEN 格式：YYYY-MM-DD（用於檔名與 frontmatter）
- 中文格式：YYYY 年 MM 月 DD 日（用於搜尋）

---

## 步驟 2：搜尋 4 大類別新聞（近 24 小時）

一次搜尋以下 4 大類別，並在對話中彙整出候選清單（每類提供 2-3 則）：

### A. 勞動新聞 (Labor) — 序號格式：L1, L2, L3...
*   **搜尋**：「台灣 勞工 勞動部 裁罰 爭議 新聞 [今日日期]」或「台灣 基本工資 職災 勞動法規 [今日日期]」
*   **選題**：政府裁罰、政策/法規修正、重大勞資爭議、勞檢結果。

### B. 理財新聞 (Wealth) — 序號格式：W1, W2, W3...
*   **搜尋**：「台灣 理財 退休金 投資 保險 基金 [今日日期]」或「勞退 勞保 退休理財規劃 [今日日期]」
*   **限制**：**嚴禁納入任何特定個股**，聚焦於個人理財、退休金制度、基金配置。

### C. 軍事新聞 (Military) — 序號格式：M1, M2, M3...
*   **搜尋**：「weapon military news [今日日期]」或「武器 裝備 軍事 新聞 [今日日期]」
*   **選題**：武器系統亮相/測試、重大軍事部署、區域防禦或台海衝突動態。

### D. 不動產新聞 (Real Estate) — 序號格式：R1, R2, R3...
*   **搜尋**：「台灣 房市 預售屋 買賣移轉 房貸 [今日日期]」或「實價登錄 建照使照 房價趨勢 [今日日期]」
*   **選題**：房市交易量、建照使照量、房貸逾期、限貸與信用管制、預售屋市況。

## 步驟 5：寫檔與推上 GitHub

當收到使用者的確認指令（例如「確認」或「[類別]確認」）後，建立/覆蓋對應路徑的檔案，並進行 Git 操作：

```bash
git checkout main
git pull --rebase origin main  # 務必先 rebase 避免 push 被拒
# （若有未提交的修改，先 git stash，pull 後再 git stash pop）

git add [已產生的日報檔案路徑]
git commit -m "add: [理財/勞動/軍事/不動產]日報 [YYYY-MM-DD]"
git push origin main
```

## 寫作品質規則

1.  **理財日報**：深挖單一主題，嚴禁提及個股，必須包含試算表或數據比較，結尾落實到「實際應用」。
2.  **勞動日報**：三段式結構（政策事實、背景數字、個人意義），每節結尾皆需有 `>` blockquote 洞見。
3.  **軍事日報**：每則限 3-4 句，不做長篇分析，需包含武器型號與數量，結尾附一句話局勢/市場判斷。
4.  **不動產日報**：注意 category 必須是 `投資`，subcategory 為 `其他投資`，topic 為 `不動產`。
5.  **共用規則**：只用標準 Markdown，**不用 Callout 元件**，來源必須是可點擊的連結，標題須含關鍵數字或地點。
