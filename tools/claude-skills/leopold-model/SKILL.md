# Leopold 篩股模型 SKILL

## 模型來源與核心哲學

萃取自 Leopold Aschenbrenner（*Situational Awareness*）的投資邏輯：

> 不要追熱門敘事。要找**物理上確定會發生、但市場還沒定價**的事情，然後押最快解決那件事的人。

這個模型的核心假設：
- 技術進步有**物理瓶頸**，不是純敘事
- 瓶頸是可以提前識別的（用電、良率、材料、製程）
- 解決瓶頸最快的公司，獲得結構性競爭優勢
- 被瓶頸替代的舊路線，是做空標的

---

## 執行流程

```
收到指令（「Leopold模型 [主題]」）
  ↓
步驟 1：建立世界觀
  → 這個行業 3–5 年後是什麼樣子？
  → 哪個趨勢是物理上確定的（不依賴敘事）？
  ↓
步驟 2：找瓶頸
  → 阻止世界觀實現的最大物理/制度/材料障礙是什麼？
  → 用數字量化（交期、良率、成本差距、產能缺口）
  ↓
步驟 3：篩標的
  → 誰解決這個瓶頸最快？（速度、技術壁壘、市占）
  → 市場現在對這件事的定價是什麼？
  → 定價低估的理由是什麼？
  ↓
步驟 4：找輸家
  → 被替代的技術路線是什麼？
  → 誰在舊路線上有最大的沉沒成本？
  ↓
步驟 5：輸出結果（對話中，不寫檔）
```

---

## 步驟 1：建立世界觀

世界觀必須回答三個問題：

**Q1：這個行業 3–5 年後的物理現實是什麼？**
不是預測市場，是描述物理/技術/人口現實。
例：「AI 訓練算力每 6–12 個月翻倍，電力消耗必然同步成長。」

**Q2：什麼是不依賴人類決策就會發生的事？**
篩掉敘事，只留下物理或結構確定的部分。
例：「資料中心用電成長是確定的，核電重啟速度取決於政治。」

**Q3：市場現在把這件事定價到哪裡了？**
找出定價缺口——被充分定價的部分不是機會，未定價的才是。

---

## 步驟 2：瓶頸量化

瓶頸不能只是「供給不足」這種模糊說法，必須量化：

| 瓶頸類型 | 量化方式 | 範例 |
|---|---|---|
| 材料短缺 | 供給缺口 %、交期週數、價格漲幅 | 變壓器供給短缺 30%、交期 160 週 |
| 製程良率 | 良率 %、vs 競爭對手差距 | 三星 HBM4 良率問題未解，SK Hynix 領先 |
| 產能不足 | GW / 萬台 / 噸 缺口 | HBM 供給缺口 5.1%，15 年最大 |
| 法規 / 審批 | 平均等待時間、積壓案件數 | 電網互聯申請積壓 2,600+ GW |

**瓶頸篩選原則：**
- 必須是物理或制度瓶頸，不是「市場認知」瓶頸
- 必須有數字支撐
- 必須在 1–5 年內可解決（太長看不到，太短已被定價）

---

## 步驟 3：押解決瓶頸最快的標的

篩選標準（依序評估）：

**① 解決速度**
- 已量產 > 試產 > 規劃中
- 護城河：技術壁壘、市占、客戶黏性

**② 市場定價缺口**
- 問：「如果這件事確定發生，這家公司的股價合理嗎？」
- 低估的常見原因：行業太無聊、市場把它當舊類股定價、第二三層未被注意

**③ 瓶頸解決後的持續性**
- 解決瓶頸後，公司是否還有護城河？
- 還是只是過渡受益（瓶頸消失後優勢也消失）？

---

## 步驟 4：找輸家（做空邏輯）

輸家三種類型：

| 類型 | 判斷標準 | 操作方向 |
|---|---|---|
| 被替代技術 | 舊技術物理上劣於新技術，無法升級 | 做空或迴避 |
| 沉沒成本最大的廠商 | 深度押注舊路線，轉型成本極高 | 做空 |
| 供應鏈脫離的廠商 | 新供應鏈繞過它，但市場還沒注意到 | 迴避或做空 |

**注意：** 做空前確認市場已開始意識到這個替代趨勢，否則時間成本過高。

---

## 輸出格式

```
【Leopold 模型：[主題]】

▌ 世界觀
[3–4 句，描述物理上確定的趨勢，附一個關鍵數字]

▌ 核心瓶頸
[瓶頸名稱]：[量化描述]
解決窗口：[時間區間]

▌ 押標的（從快到慢）
1. [公司/代號]：[為何是最快解決者] — 定價缺口：[高/中/低]
2. [公司/代號]：...
3. ...

▌ 做空 / 迴避
- [公司/代號]：[被替代原因] — [時程]

▌ 最大風險
[如果世界觀錯了，錯在哪裡]
```

## 與其他 Skill 的差異

| | Leopold Model | stock-analysis | us-weekly-report |
|---|---|---|---|
| **起點** | 物理瓶頸 | 技術 / 公司 | 本週新聞事件 |
| **輸出** | 投資邏輯架構 | 完整分析文章（MDX）| 週報文章（MDX）|
| **是否寫檔** | ❌ 對話中輸出 | ✅ 寫入部落格 | ✅ 寫入部落格 |
| **何時用** | 建立世界觀、篩標的 | 已確定標的，要寫成文章 | 每週市場事件整理 |

典型流程：**Leopold Model → 找到標的 → stock-analysis 深度分析 → 發布部落格**
