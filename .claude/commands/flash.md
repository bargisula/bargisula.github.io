# /flash：快速記錄市場快訊

**輸入：$ARGUMENTS**

---

## 輸入格式說明

支援以下任意組合，自由輸入，不需要固定格式：

```
/flash 黃金 #看多 高盛：下半年金價目標 3500，理由是美元走弱
/flash #看空 #台積電 外資調降目標價至 980，CoWoS 需求不如預期
/flash NVDA Q2 財報 EPS 4.88 超預期，Blackwell 出貨無延遲 #事件
/flash 原油跌破 70，沙烏地增產訊號 #數據
```

**自動解析規則：**
- `#看多` / `#看空` / `#中性` → 情緒標籤
- `#事件` / `#數據` / `#法說` / `#財報` / `#地緣` → 類型標籤
- 大寫英文（NVDA、TSLA、TSM）或四位數字（2330、3711）→ 自動識別為股票代號
- 其餘文字 → 快訊主體內容

若 $ARGUMENTS 為空 → 回覆：「請輸入內容，例如：/flash 黃金 #看多 高盛目標價 3500」

---

## 執行步驟

### 1. 解析輸入

從 $ARGUMENTS 中提取：
- **情緒**：看多 / 看空 / 中性（未標記預設中性）
- **類型**：事件 / 數據 / 法說 / 財報 / 地緣（未標記則略過）
- **標的**：股票代號或主題詞（黃金、原油、美債、台股大盤）
- **內容**：去除標籤後的主體文字

### 2. 確認本月檔案路徑

```
C:\Users\alpha\flash-notes\YYYY-MM.md
```

### 3. 若檔案不存在，建立並寫入標頭

```markdown
# 市場快訊｜YYYY 年 MM 月

> 隨手記錄多空觀點、市場事件、數據與個股動態

---

## 本月標的速覽
<!-- flash-index -->
（本區塊自動更新）
<!-- /flash-index -->

---
```

### 4. 追加快訊，格式如下

```markdown
### HH:MM｜MM/DD｜{情緒圖示} {標的}

{內容}

> {類型標籤列表}

---
```

**情緒圖示規則：**
- 看多 → 🟢
- 看空 → 🔴
- 中性 / 未標記 → ⚪
- 事件（無情緒）→ 📌

**範例輸出：**

```markdown
### 09:32｜05/09｜🟢 黃金

高盛：下半年金價目標 3500，理由是美元走弱加速、央行持續購金。

> #看多 #黃金

---

### 14:15｜05/09｜🔴 台積電 $2330

外資調降目標價至 980，CoWoS 需求不如預期，下修 Q3 毛利率預測。

> #看空 #法說 $2330

---
```

### 5. 更新標頭的「本月標的速覽」區塊

掃描本月已記錄的所有標的，更新 `<!-- flash-index -->` 區塊：

```markdown
<!-- flash-index -->
| 標的 | 看多 | 看空 | 中性/事件 | 最後更新 |
|---|---|---|---|---|
| 黃金 | 2 | 1 | 0 | 05/09 |
| 台積電 | 0 | 1 | 1 | 05/09 |
<!-- /flash-index -->
```

### 6. 輸出確認

```
✅ 已記錄 → C:\Users\alpha\flash-notes\2026-05.md
   [09:32] 🟢 黃金｜高盛：下半年金價目標 3500...
   本月共 N 則快訊｜涉及標的：黃金、台積電
```

## 注意事項

- 內容主體原文存入，不修改語意
- 同一標的同日有多筆 → 全部保留，按時間順序排列
- 標的速覽表只統計計數，不做判斷
