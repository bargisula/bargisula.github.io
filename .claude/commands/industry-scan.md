# /industry-scan：產業數據採集

**用法：** `/industry-scan [產業名稱]`

純數據採集，不做判斷、不下投資結論。輸出結構化數據包後，推薦適合的分析引擎。

---

## 執行流程

```
讀 Regime 基線 → 並行搜尋四面向 → 輸出數據包 → 推薦引擎
```

---

## 步驟 1：讀取 Regime 基線

讀取 `data/regime/current.json`：
- `focus_sectors`：確認此產業是否在聚焦名單
- `suppress_sectors`：確認是否被壓制，若是則標注 ⚠️
- `regime_grid.quadrant`：當前景氣座標，影響哪類引擎優先

---

## 步驟 2：確認是否已有既存分析

讀取 `data/industry/[slug].json`（若存在）：
- 若存在且 `updated` 距今 < 30 天 → 提示「已有近期分析（{updated}），是否直接使用？」
- 若存在但已過期 → 提示「上次分析：{updated}，建議更新」，繼續採集

slug 轉換規則：產業名稱轉小寫、空格換 `-`（例：AI 基礎設施 → ai-infrastructure）

---

## 步驟 3：並行搜尋四個面向

### 面向 A｜市場規模與成長

搜尋：
- 「[產業名稱] market size TAM 2026」
- 「[產業名稱] CAGR forecast 2025 2026」

取得：
| 指標 | 數值 | 來源標注 |
|---|---|---|
| 全球 TAM | | [實時查詢] |
| 5年CAGR預估 | | [實時查詢] |
| 現階段滲透率 | | [實時查詢] |
| 主要地理市場 | | [實時查詢] |

---

### 面向 B｜需求端近期訊號

搜尋：
- 「[產業名稱] demand 2026 earnings call」
- 「[產業名稱] capex spending guidance 2026」

取得：
- 近一季財報中提及此產業的關鍵字（hyperscaler / 主要客戶）
- 需求加速或放緩的具體訊號（有數字則列）
- 庫存水位（若有公開數據）

**法說會補充（選用）：**
若需要更深的需求端訊號，可觸發 `/earnings-call-scan [產業名稱]`，
橫向比較主要公司 CEO 的措辭與態度，輸出後併入本面向。

---

### 面向 C｜供應鏈結構

搜尋：
- 「[產業名稱] supply chain key players 2026」
- 「[產業名稱] bottleneck shortage 2026」

取得：

| 層次 | 主要玩家 | 集中度 | 瓶頸存在？ |
|---|---|---|---|
| 上游 | | | Y/N |
| 中游 | | | Y/N |
| 下游 | | | Y/N |

---

### 面向 D｜競爭格局近期動態

搜尋：
- 「[產業名稱] market share 2026」
- 「[產業名稱] new entrant competitor 2026」

取得：
- 前三名市佔（CR3）
- 近三個月有無格局變化事件（併購、新進者、技術替代）

---

## 步驟 5：推薦分析引擎

根據產業特性，輸出推薦：

| 產業類型 | 推薦引擎 | 原因 |
|---|---|---|
| AI / 半導體 / 算力 | `ai-infra-scan` + `leopold-model` | 六層瓶頸地圖 + 物理確定性框架最適配 |
| 傳統週期（鋼鐵、航運、能源） | `/industry-analysis`（週期框架）+ `industry-11d` | 週期位置判斷是核心 |
| 科技 SaaS / 法規驅動（生技、金融科技）| `/industry-analysis`（監管框架）+ `sector-deep-dive` | 法規週期是主要驅動力 |
| 消費 / 零售 | `/industry-analysis`（網路效應或破壞框架）| 消費行為 + 滲透率為核心 |
| 任何產業的正式結論存檔 | `/industry-analysis` | 唯一寫入 `data/industry/` JSON 的正式引擎 |

輸出格式：

```
─────────────────────────────
以上為結構化數據原料，不含判斷。

建議引擎：[引擎名稱]
原因：[一句話]

若要正式存檔結論，最後必須跑 /industry-analysis，它負責寫入 data/industry/[slug].json。
─────────────────────────────
```

---

**注意：** industry-scan 不下 verdict，所有裁定由分析引擎處理後寫入 `data/industry/{slug}.json`。
