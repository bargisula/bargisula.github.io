# /flashlog：查閱本月市場快訊

**輸入：$ARGUMENTS**（可空白，或輸入標的/標籤篩選）

---

## 用法範例

```
/flashlog              → 顯示本月全部快訊摘要
/flashlog 黃金         → 只顯示黃金相關快訊
/flashlog #看多        → 只顯示看多觀點
/flashlog NVDA #財報   → 篩選 NVDA 財報類快訊
/flashlog 2026-04      → 查閱指定月份（YYYY-MM）
```

---

## 執行步驟

### 1. 確定查閱月份與篩選條件

- 若 $ARGUMENTS 包含 `YYYY-MM` 格式 → 讀取該月份檔案
- 否則 → 讀取本月檔案 `C:\Users\alpha\flash-notes\YYYY-MM.md`
- 解析其餘 $ARGUMENTS 作為篩選條件（標的名稱或 #標籤）

### 2. 讀取檔案

讀取對應月份的 MD 檔案。
若檔案不存在 → 回覆「本月尚無快訊記錄」。

### 3. 輸出結果

**若無篩選條件（/flashlog 空白）：**

輸出本月標的速覽表（直接讀 flash-index 區塊），再列出全部快訊標題列：

```
📋 市場快訊｜2026 年 05 月（共 N 則）

【標的速覽】
| 標的 | 看多 | 看空 | 中性/事件 |
...

【本月時間軸】
🟢 09:32 05/09  黃金｜高盛：下半年金價目標 3500
🔴 14:15 05/09  台積電｜外資調降目標價至 980
⚪ 21:00 05/09  美股開盤｜S&P 小漲 0.3%，科技股領漲
...
```

**若有篩選條件：**

只顯示符合條件的快訊完整內容：

```
🔍 篩選：黃金（共 3 則）

─────────────────────
🟢 09:32｜05/09
高盛：下半年金價目標 3500，理由是美元走弱加速、央行持續購金。
#看多 #黃金
─────────────────────
🔴 11:20｜05/08
摩根士丹利：技術面過熱，建議短線獲利了結，目標回測 3200。
#看空 #黃金
─────────────────────
```

### 4. 結尾提示

```
💡 輸入 /flash [內容] 可繼續記錄
   查其他月份：/flashlog 2026-04
```
