# /stock-scan：個股快速掃描分析

**Ticker：$ARGUMENTS**

執行以下步驟，對 $ARGUMENTS 進行快速五維掃描，輸出結構化分析報告。

---

## 步驟一：抓取即時數據

同時取得以下資料（parallel fetch）：

**1. 價格與技術面**（Yahoo Finance）
```
https://query1.finance.yahoo.com/v8/finance/chart/$ARGUMENTS?interval=1d&range=60d
```
取得：當前價格、60日收盤序列、成交量

**2. 基本面快照**（Yahoo Finance）
```
https://query1.finance.yahoo.com/v10/finance/quoteSummary/$ARGUMENTS?modules=summaryDetail,defaultKeyStatistics,financialData,recommendationTrend
```
取得：PE、Forward PE、EPS、毛利率、營收成長、分析師評級

**3. 近期新聞**（Yahoo Finance search）
```
https://query2.finance.yahoo.com/v1/finance/search?q=$ARGUMENTS&newsCount=4&lang=en-US
```
取得：最新 3–4 條新聞標題與時間，作為「今日飆升原因」的線索

---

## 步驟二：計算核心指標

從抓取的數據計算：

- **30日均價**：60日收盤序列取最後30筆的平均值
- **距離均價 %**：(現價 - 30日均價) / 30日均價 × 100
- **週漲跌**：最近5個交易日漲跌幅
- **月漲跌**：最近20個交易日漲跌幅
- **均量比**：最近5日均量 vs 30日均量（放量or縮量）

---

## 步驟三：輸出掃描報告

用以下格式輸出，不要省略任何一節：

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📊 STOCK SCAN｜$ARGUMENTS｜[公司名稱]
[掃描日期時間]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【一、價格快照】
  現價：$XX.XX
  日漲跌：+X.XX%
  週漲跌：+X.XX%
  月漲跌：+X.XX%
  30日均價：$XX.XX
  距均價：+X.X%（高於/低於均價）
  均量比：X.Xx（放量/縮量/正常）

【二、基本面五項】
  PE (TTM)：Xx  |  Forward PE：Xx
  EPS (TTM)：$X.XX
  毛利率：XX%
  營收 YoY：+XX%
  自由現金流：正/負/[具體數字]

【三、今日飆升原因】
  主要新聞：[列出 1–3 條關鍵標題 + 日期]
  核心觸發：[一句話說明是財報/合約/政策/情緒哪種驅動]
  持續性判斷：[一次性利多 / 週期性多頭 / 結構性改變]

【四、供應鏈定位】
  所屬產業：[半導體/AI基礎設施/電動車/生技/國防/其他]
  在供應鏈的層次：[第一層直接/第二層零組件/第三層設備材料]
  當前主題關聯性：[強/中/弱]——[一句話說明與本週主題的關係]
  上游依賴：[關鍵供應商或技術]
  下游客戶：[主要客戶或應用端]

【五、分析師共識】
  評級分布：Buy XX% / Hold XX% / Sell XX%
  平均目標價：$XXX
  目標價 vs 現價：+/-XX%（上漲空間）
  最新評級變動：[若有則列出，沒有則寫「近期無異動」]

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
【綜合判斷】

技術面：[強勢/整理/弱勢] — [一句話理由]
基本面：[優質/普通/偏弱] — [一句話理由]
位置判斷：[偏高/合理/偏低] — 現價距30日均 X.X%，距分析師目標 X.X%
主題關聯：[強/中/弱]

▶ 快速結論：[觀察/等待回調/可分批建倉/避開]
  理由：[2-3句，說清楚最核心的決策依據]
  關注觸發點：[什麼事件/價位出現時，判斷需要重新評估]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

---

## 注意事項

- 若 Yahoo Finance API 回傳 null 的欄位，直接寫「N/A」，不要跳過整節
- 供應鏈定位一節用知識庫判斷，若不確定所屬產業請說明
- 綜合判斷必須給出明確方向，不能只說「需要觀察」
- 若 $ARGUMENTS 不是有效 ticker（如輸入錯誤），立即說明並停止
- 掃描完成後不詢問是否加入監管清單，結果可直接作為美股快報素材使用
