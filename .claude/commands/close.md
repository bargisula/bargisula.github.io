# /close：今日收盤口語問答

**用法：** `/close`

依台灣當前時間，自動判斷哪個市場已收盤，口語回報指數漲跌與主因。只在對話輸出，不寫檔。

---

## Step 0：時間判斷

### Step 0-A：先判斷今天是否交易日

取台灣當前日期與星期：

- **今天是週六**：TW 和 US 最近收盤日都是**週五**。直接抓週五資料，跳到 Step 1。
- **今天是週日**：同上，最近收盤日是**週五**。直接抓週五資料，跳到 Step 1。
- **今天是週一至週五**：進 Step 0-B 用時間判斷。

> 假日（台灣/美國例假日）若恰好是平日，視同非交易日，往前推到最近有開盤的交易日。

### Step 0-B：平日時段判斷（僅週一至週五適用）

| 台灣時間 | 台股 | 美股 |
|---|---|---|
| 04:00–13:34 | 未收（跳過） | 已收（前一美股交易日） |
| 13:35–21:29 | 已收（今日） | 已收（前一美股交易日） |
| 21:30–03:59 | 已收（今日） | 盤中（跳過） |

- **台股已收**：台灣日期當日，session = TW post
- **美股已收**：前一美股交易日（往前推，跳過週末與美國假日），session = US post
- **兩個都未收**：直接回覆「現在兩個市場都還沒收盤」，結束

---

## Step 1：平行抓資料

依 Step 0 判斷結果，同時執行：

- 已收的市場 → 呼叫 `market-data` agent，傳入對應 market / session / date
- 已收的市場 → 呼叫 `news-scout` agent，傳入對應 topic / date / count=2

若只有一個市場已收，只跑該市場的兩個 agent。

---

## Step 2：口語合成

收到數字和新聞後，CEO 自行整合，輸出口語段落。

**格式規則：**
- 不用 markdown 表格，純文字段落
- 台股先、美股後（若兩個都有）
- 每個市場：一句說數字（指數、漲跌幅），一句說主因（從新聞提煉）
- 數字直接嵌入句子，不另起列表
- 若有特別值得注意的訊號（外資大量買賣、VIX 異常、殖利率跳動），加一句點出

**台股範例：**
```
今天台股收 22,456 點，漲 0.8%。外資買超 85 億撐盤，台積電跟著漲帶動大盤。
```

**美股範例：**
```
美股昨晚（5/22）S&P 跌 0.3%，收 5,304。聯準會官員偏鷹發言讓市場退縮，
科技股整體承壓，VIX 升到 18.2，市場情緒轉謹慎。
```

**兩個都有時，最後加一句連結：**
```
兩邊方向一致 / 台股今天沒跟美股走 / 美股弱但台股靠外資守住，
值得觀察明天開盤方向。
```

---

## 規則

- 日期必須確認是當日或前一交易日，不引用舊數據
- 數字缺失時說「數據還沒出來」，不猜測
- 口語風格：像在跟人說話，不像在讀報告
- 不提「我呼叫了哪個 agent」，直接說結果
