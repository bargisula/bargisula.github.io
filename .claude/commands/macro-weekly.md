# /macro-weekly：總經週報

每週對外發布的宏觀經濟報告。**敘事優先，數據佐證**——先找本週的核心張力，再用數字支撐它，不是把數據全部列出來讓讀者自己解讀。目標讀者：投資人，閱讀時間 3 分鐘。

---

## 設計原則

**這樣不對：**
> Fed 維持利率不變。CPI 3.1%。PMI 52.7。非農 +145k。市場上漲。

**要這樣：**
> 本週的矛盾不在 AI 本身。通膨降溫比預期快，但就業韌性讓降息時間表繼續後移——這個拉鋸決定了成長股的走法。漲了，是市場又在賭降息；跌了，是市場終於信了 Fed。

數字是佐證，不是報告本身。每個數字出現都要回答：這告訴投資人什麼？

報告使用 **MDX 格式**（`.mdx`），引入 Callout 元件做視覺區隔。

---

## 五段結構

### 第一段：本週主題（Callout insight）

用 `<Callout type="insight">` 包住本週的核心論點：
- **粗體第一句**：這週市場在面對什麼核心矛盾或拉鋸（判斷句，不是描述句）
- 第 2–3 句：一邊的論點是什麼（具體數字）
- 第 4–5 句：另一邊的論點是什麼（具體數字）
- 最後一句：這個矛盾還沒解決——不強行給結論

字數：150 字以內，拒絕流水帳。

---

### 第二段：本週數據（表格 + 小結）

**只放 3 個最重要的指標**，格式：

```
| 指標 | 數值 | 方向 | 含義 |
|---|---|---|---|
```

表格之後必須接**數據小結（1-2 句）**：
- 把表格的意思說出來，不讓讀者自己解讀
- 說清楚「這些數字組合在一起告訴我們什麼」

---

### 第三段：Regime 座標（景氣象限 + 敘事）

用文字版 2×2 矩陣標示當前位置：

```
             低通膨 ←──── 通膨 ────→ 高通膨
高成長  ┌──────────────┬──────────────┐
   ↑    │   擴張 / 復甦  │    過熱      │
        │  (Recovery)  │  (Overheat)  │
        ├──────────────┼──────────────┤
低成長  │     衰退       │   滯脹  ★   │
   ↓    │  (Recession)  │(Stagflation) │
        └──────────────┴──────────────┘
```

★ 標示當前位置，若有方向則加 → 或 ↑ 等箭頭符號。

矩陣後接敘事段（3-4 句）：
- 現在在哪個象限，往哪個方向移動
- 「確信度」：高確信 / 中確信 / 觀察期
- 對資產配置最直接的含義（一句話）

---

### 第四段：推演（核心風險的情境分析）

取本週最重要的一個外生變數，展開 **2–3 個情境**：

```
情境一：{名稱}（機率 ~XX%）
觸發條件：{什麼事情發生}
連鎖效應：{第一步} → {第二步} → {對持倉的影響}

情境二：{名稱}（機率 ~XX%）
（同格式）

情境三：{名稱}（機率 ~XX%）
（同格式）
```

規則：
- 機率三個加起來 ~100%
- 每個情境必須有可觀測的觸發條件（不能是「若市場惡化」）
- 最後一個情境通常是「市場已定價」的基本情境

---

### 第五段：本週觀察清單

3 個具體事件，格式：

```
- **{日期} {事件}**：若 {X 發生} → {影響}；若 {Y 發生} → {影響}
```

每條必須有 if-then，不能只說「值得關注」。

---

## 執行步驟

### Step 1：取得數據

呼叫 CMO agent 或讀取 `data/regime/current.json`，取得：
- 當前 Regime（Goldilocks / Overheat / Stagflation / Recession）及移動方向
- 本週最重要的 3 個數據（含數值與方向）
- 最大外生風險因子（下週情境分析的材料）

**CMO 提供原始數字，本指令負責把數字轉化為敘事。**

### Step 2：寫報告

按五段結構撰寫，**總字數 500-700 字**（不計表格和矩陣）。

### Step 3：存檔並推部落格

**3a. 存內部記錄：**
路徑：`data/reports/weekly/macro-YYYY-WW.md`

**3b. 推部落格（MDX 格式）：**
路徑：`src/content/notes/Xompass/投資報告/macro-YYYY-WW.mdx`

Frontmatter：
```yaml
---
title: '【總經週報】YYYY 第 WW 週｜{主題核心，10字以內}'
description: '{核心張力一句話，40字以內}'
category: 'Xompass'
subcategory: '投資報告'
topic: '總經報告'
pubDate: 'YYYY-MM-DD'
---
```

MDX 檔案第一行（frontmatter 之後）：
```mdx
import Callout from '@components/Callout.astro'
```

---

## 規則

- **第一段必須有判斷**：「本週通膨與就業數據拉鋸」是描述；「市場選擇相信就業，忽視通膨」才是判斷
- **數據表只放 3 個指標**，且每個指標都要接一句「對投資人的含義」
- **Regime 必須有方向和確信度**，不能只說「當前為滯脹」
- **推演必須有機率估計**，讓讀者知道你押哪個情境
- **觀察清單必須有 if-then**，否則等於沒說
- **字數上限 700 字**：超出就是在堆砌，刪，不是加更多小節
- 報告格式為 `.mdx`，不是 `.md`
- 不做買賣建議，不預測股價方向
