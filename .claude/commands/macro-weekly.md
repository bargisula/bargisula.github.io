# /macro-weekly：總經週報

每週對外發布的宏觀經濟報告。**敘事優先，數據佐證**——先找本週的核心張力，再用數字支撐它，不是把數據全部列出來讓讀者自己解讀。目標讀者：投資人，閱讀時間 3 分鐘。

---

## 設計原則

**這樣不對：**
> Fed 維持利率不變。CPI 3.1%。PMI 52.7。非農 +145k。市場上漲。

**要這樣：**
> 本週的矛盾不在 AI 本身。通膨降溫比預期快，但就業韌性讓降息時間表繼續後移——這個拉鋸決定了成長股的走法。漲了，是市場又在賭降息；跌了，是市場終於信了 Fed。

數字是佐證，不是報告本身。每個數字出現都要回答：這告訴投資人什麼？

報告使用 **MDX 格式**（`.mdx`），引入 Callout 與 RegimeGrid 兩個元件做視覺區隔。

---

## 五段結構

### 第一段：本週主題（核心張力 + Callout）

**選擇張力的敘事模型**，依當週市場情境選最貼切的一種（選定後說明為何選此類型，不輪流）：

| 模型 | 適用情境 | 切入方式 |
|---|---|---|
| **預期錯置型** | 基本面強但資金收縮，或反之 | 「X 的高確信 vs Y 的冷酷定價——兩者不會同時正確」 |
| **信號撕裂型** | 硬數據（非農、零售）與軟數據（PMI 信心）方向相反 | 「硬數據說過熱，軟數據說即將衰退——市場押哪個先到？」 |
| **跨資產背離型** | 債市已定價高利率，股市仍賭降息 | 「債市和股市不可能同時對——有一邊在說謊」 |
| **外生衝擊型** | 地緣政治事件、聖嬰/拉尼娜、重大政策轉向直接移動 Regime 位置 | 「X 事件不需要等貨幣政策傳導——它直接改變了通膨底線」。例：「聖嬰推升農產品通膨 → PCE 黏著 → Fed 鴿轉鷹窗口關閉，這不是週期，是外生衝擊重設邊界條件」 |

用 `<Callout type="insight">` 包住張力段：
- **粗體第一句**：判斷句（市場在面對什麼矛盾），不是描述句
- 第 2–3 句：一邊的論點（具體數字）
- 第 4–5 句：另一邊的論點（具體數字）
- 最後一句：留開放結尾，不強行給結論

字數：150 字以內。

---

### 第二段：本週數據（三維指標 + 小結）

**3 個指標必須橫跨三個不同維度**，防止同質性過高（例如不得同時放 CPI + 核心 CPI + PCE）：

| 維度 | 代表指標（擇一） |
|---|---|
| **增長 / 通膨核心** | Core PCE、ISM 製造業 PMI、非農就業 |
| **資金價格 / 壓力** | US 10Y 殖利率、TED Spread、聯邦基金利率期貨 |
| **波動 / 流動性來源** | MOVE Index（美債波動率）、DXY、USD/JPY、VIX |

格式：

```
| 指標 | 數值 | 方向 | 含義 |
|---|---|---|---|
```

表格後接**數據小結（1-2 句）**：把三個指標組合在一起的意義說出來，不讓讀者自己解讀。

---

### 第三段：Regime 座標（RegimeGrid 元件）

使用 RegimeGrid 元件取代 ASCII 矩陣（RWD 相容，手機不跑版）：

```mdx
<RegimeGrid current="Stagflation" trend="right" confidence="medium" />
```

`current` 合法值：`Recovery` | `Overheat` | `Stagflation` | `Recession`

`trend` 合法值：`right` | `left` | `up` | `down` | `up-right` | `down-right` | `up-left` | `down-left`

`confidence` 合法值：`high` | `medium` | `low`

元件後接敘事段（3-4 句）：
- 現在在哪個象限，往哪個方向移動，以及這個方向代表什麼
- 對高估值資產配置最直接的含義（一句話）

---

### 第四段：推演（情境分析，傳導鏈三步到估值）

取本週最重要的外生變數，展開 2-3 個情境。

**若本週 CMO 面向五（骨牌推演）為 🔴 活躍**，情境分析必須沿用骨牌地圖的傳導路徑，不能另起一套邏輯。複雜情境（跨兩個以上面向）需從外生衝擊出發，逐步傳導至 Xompass 持倉的估值乘數影響。

**傳導鏈格式強制規範：**

```
情境一：{名稱}（機率 ~XX%）
觸發條件：{具體可觀測的事件，不能是「若市場惡化」}
連鎖效應：{第一步：直接市場反應} → {第二步：傳導機制} → {第三步：持倉影響，必須精確到估值乘數}
```

**第三步的寫法**——

這樣不對：
> → 科技股下跌 → 對持倉不利

要這樣寫：
> → 成長股股權風險溢價（ERP）被動壓縮 → **持倉中 forward P/E 超過 50x 的標的面臨 10–15% 的估值乘數修正壓力**

第三步必須包含：
1. 哪個財務指標受影響（ERP / forward P/E 乘數 / FCF 折現率）
2. 量化估算範圍（「10–15%」，不是「大幅」）

機率規則：三個情境加總 ~100%，最後一個通常是市場已定價的基本情境。

---

### 第五段：本週觀察清單

3 個具體事件，格式：

```
- **{日期} {事件}**：若 {X 發生} → {影響}；若 {Y 發生} → {影響}
```

每條必須有 if-then，不能只說「值得關注」。

## 執行步驟

### Step 1：取得數據（CMO 六面向掃描）

呼叫 CMO agent，CMO 必須先執行**六面向活躍度掃描**，確認本週 🔴 活躍面向後，再提供以下素材：

- 面向活躍度總覽（六面向各自的 🔴🟡🟢 狀態）
- 當前 Regime 裁定（象限 + 移動方向 + 確信度）
- 本週 🔴 活躍面向的關鍵指標（含值 + 方向↑↓→ + 斜率）
- 本週核心外生風險（地緣/聖嬰/政策轉向，若有）
- 骨牌傳導地圖（若面向五活躍）

**macro-weekly 只負責把 CMO 的分析素材轉化為對外敘事，不重新分析數字。**

**API Fallback：** 若 `localhost:8000` 無回應，CMO 執行 WebSearch 補充缺口數據，並在報告數據表末加注：「* 數據來源：WebSearch，{日期}」

---

### Step 2：選張力模型，寫報告

先確認本週屬於哪種張力類型（預期錯置型 / 信號撕裂型 / 跨資產背離型），再按五段結構撰寫。**總字數 500-700 字**（不計表格與元件）。

---

### Step 3：存檔並推部落格

**推部落格（MDX 格式，唯一數據源）：**
路徑：`src/content/notes/Xompass/投資報告/macro-YYYY-WW.mdx`

MDX 檔案開頭（frontmatter 之後）：
```mdx
import Callout from '@components/Callout.astro'
import RegimeGrid from '@components/RegimeGrid.astro'
```

Frontmatter：
```yaml
---
title: '【總經週報】YYYY 第 WW 週｜{主題核心，10字以內}'
description: '{核心張力一句話，40字以內}'
category: 'Xompass'
subcategory: '投資報告'
topic: '總經報告'
pubDate: 'YYYY-MM-DD'
---
```

**存檔前自我檢核（不符合則修正後再寫入）：**
- [ ] 數據表是否剛好 3 行（不多不少）
- [ ] 3 個指標是否橫跨三個不同維度（增長核心 / 資金壓力 / 波動流動性）
- [ ] 情境機率是否加總約 100%
- [ ] 每條觀察清單是否有 if-then
- [ ] 傳導鏈第三步是否有估值乘數 + 量化範圍
- [ ] 全文有無觸犯禁忌詞彙（見下方）

## 寫作禁忌詞彙

存檔前強制過濾，發現任何一條則重寫該段：

| ❌ 禁止 | ✅ 改用 |
|---|---|
| 「投資人應保持謹慎 / 密切關注...」 | 「我們將 {X 指標} 視為持倉的防線，一旦 {Y 發生} 則重新評估」 |
| 「未來走勢仍有待時間觀察」 | 「下週的 {X 數據} 將直接裁定此邏輯是否失效」 |
| 「市場充滿不確定性」 | 「當前 MOVE Index 飆升，顯示定價分歧已達極限」 |
| 「對持倉不利 / 有利」（無量化） | 「forward P/E 壓縮 X–Y%」或「ERP 上升 Z bps」 |
| 「值得持續關注」 | 明確寫 if-then 觸發條件，不用「關注」二字 |
| 「AI 趨勢仍然強勁」（無佐證） | 必須附具體數字（例如：hyperscaler capex 季增 +X%）|

## 達里歐詞彙庫（情境適用時使用，非裝飾）

僅在情境確實對應時引用，不作裝飾性點綴。錯誤使用術語比不用更傷品牌。

| 術語 | 適用情境 |
|---|---|
| **美麗去槓桿 (Beautiful Deleveraging)** | 債務/GDP 下降但名目成長維持，去槓桿不引發崩潰 |
| **推繩子 (Pushing on a String)** | 降息後信用擴張無效，貨幣政策傳導失靈 |
| **貨幣化債務 (Debt Monetization)** | 央行購債直接為財政赤字融資 |
| **實質利率擠壓** | 名目利率不變但通膨下降，實質利率被動上升 |
| **流動性陷阱** | 接近零利率後貨幣擴張無法刺激需求 |

---

## 規則

- **第一段必須有判斷**：「本週通膨與就業數據拉鋸」是描述；「市場選擇相信就業，忽視通膨」才是判斷
- **三個指標跨三個維度**：選最重要的，拒絕同質性堆積
- **Regime 必須有方向和確信度**：`<RegimeGrid />` 三個 props 都必須填
- **推演傳導鏈第三步精確到估值乘數**：有財務指標 + 量化範圍，不說「不利」
- **觀察清單必須有 if-then**，否則等於沒說
- **字數上限 700 字**：超出就是在堆砌，刪，不是加更多小節
- 報告格式為 `.mdx`，不是 `.md`，`src/content/notes/` 為唯一數據源
- 不做買賣建議，不預測股價方向
