# company-profile — 公司底稿生成

**用途：** 針對單一股票，依標準格式生成結構化公司底稿（靜態事實層 / Bible 層）。  
適用美股、台股。輸出為 MDX，推上部落格。

**呼叫時機：** 使用者說「幫我寫 [TICKER] 底稿」「建立 [公司] 公司檔案」「company profile [TICKER]」  
**跳過時機：** 產業分析、深度分析、財報解讀（這些有各自 skill）

---

## 底稿定位

底稿是**靜態事實層**，不含論點、不含裁示：
- 事實改變 → 改底稿
- 論點改變 → 寫新的深度分析或更新 insights
- 兩者分開維護，底稿永遠乾淨

---

## 執行流程

### Step 0：確認資訊充足

詢問或確認：
- **Ticker** 與交易所（NASDAQ / NYSE / TWSE）
- **市場**：美股 / 台股
- 是否有現成資料（貼上的文字、已有的分析文章）

若有現成資料（如聯發科格式的公司介紹）→ 直接解析套用  
若無 → 呼叫 WebSearch 抓取公司 IR 頁、SEC 10-K、或公開觀測站

---

### Step 1：資料採集

**美股：**
```
1. SEC EDGAR → 10-K Item 1（Business）+ Item 1A（Risk Factors）
2. 10-Q 最新季 → Segment Revenue breakdown
3. 公司 IR 頁面 → 合作夥伴、里程碑新聞
```

**台股：**
```
1. 公開資訊觀測站 → 年報、重大訊息
2. 公司官網產品頁
3. 法說會簡報（可用 WebSearch 找）
```

---

### Step 2：套用底稿框架

依以下五章節填入，**只寫事實，不寫觀點**：

#### 一、公司簡介
1. **沿革與背景**：成立年、創辦人、掛牌資訊、總部、簡短定位
2. **業務分類與營收結構**：產品/業務線表格 + 最新一季各類占比

#### 二、產品與技術
1. **核心產品說明**：主力產品技術特點、規格比較表
2. **供應商與製造**：主要原材料、代工廠、關鍵供應商

#### 三、市場與競爭
1. **目標市場與客戶**：市場定位、主要客戶、銷售地區、合約概況
2. **競爭廠商比較表**：至少三家競爭者，列技術路線 / 市場定位 / 現況

#### 四、財務概況
關鍵指標表（收入、毛利率、淨損/益、現金、重要前瞻指引），來源標注 SEC/公開資料

#### 五、策略聯盟（選填）
若合作深度對投資論點重要才寫（例如：獨家合約、預付款已到帳）

---

### Step 3：輸出 MDX

**美股 frontmatter：**
```yaml
---
title: '【公司底稿】[TICKER] [公司中文名]'
description: '60字內，核心業務+一句關鍵數字'
category: '投資'
subcategory: '美股'
topic: '公司底稿'
pubDate: 'YYYY-MM-DD'
---
```

**台股 frontmatter：**
```yaml
---
title: '【公司底稿】[代號] [公司名]'
description: '60字內摘要'
category: '投資'
subcategory: '台股'
topic: '公司底稿'
pubDate: 'YYYY-MM-DD'
---
```

**檔案路徑：**
- 美股 → `src/content/notes/投資/美股/公司底稿/[TICKER]-公司底稿-YYYY-MM-DD.mdx`
- 台股 → `src/content/notes/投資/台股/公司底稿/[代號]-公司底稿-YYYY-MM-DD.mdx`

---

### Step 4：更新維護說明

底稿完成後提醒使用者：
```
更新規則：
- 財報後 → 更新財務概況表，加 updatedDate
- 有新合約/新產品 → 在對應章節追加一行
- 論點變化 → 不改底稿，另開深度分析
```

---

## 打包給其他 LLM 使用

直接複製以下 prompt 給任何 LLM：

```
你是一個股票分析師，請幫我生成一份公司底稿。

底稿定位：靜態事實層，不含論點、不含買賣建議。
只寫事實，事實改了才更新，論點另開文章維護。

格式要求（五章節）：

一、公司簡介
  1. 沿革與背景（成立年、創辦人、掛牌、總部、定位）
  2. 業務分類與營收結構（表格，含各類占比）

二、產品與技術
  1. 核心產品說明（規格比較表）
  2. 供應商與製造

三、市場與競爭
  1. 目標市場與客戶（含合約概況）
  2. 競爭廠商比較表（至少三家）

四、財務概況
  關鍵指標表，來源要標注

五、策略聯盟（選填，只在合作深度重要時才寫）

輸出語言：繁體中文
目標股票：[TICKER]
```
