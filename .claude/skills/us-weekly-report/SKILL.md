# 美股週報框架 SKILL

## 核心工具：產業瀑布（Supply Chain Waterfall）

任何產業主題，都先建立三層瀑布：

```
主題觸發點（新聞/財報/政策）
  ↓
第一層（直接受益）→ 已被市場定價，股價反映預期
  ↓
第二層（零組件/軟體）→ 1–2 季滯後，訂單確認後才啟動
  ↓
第三層（設備/材料）→ 最長週期，資本支出計畫確定後才反映
  ↓
輸家（被替代 / 被繞過 / 市佔下降）
```

**分析原則：**
- 第一層通常已 priced in，不是好進場點
- 第二層是週報重點：有訂單確認訊號但股價尚未反映
- 第三層是最長線布局，波動最小但確定性最高
- 輸家必須點名，不能只說「傳統業者受壓」

## 五節週報結構

### 節一：本週主題定位

- 一句話說本週核心主題（AI 算力 / 記憶體 / 電動車 / 生技 / 國防）
- 觸發點：什麼事件（財報 / 政策 / 競品動作）讓這個主題本週變熱
- 市場現在的共識 vs. 你的看法（是否有分歧？）

### 節二：產業瀑布圖（核心）

從 `references/waterfall.md` 選取對應主題的瀑布圖，並：
- 標注「本週新增資訊」在哪一層有更新
- 指出哪個環節從「敘事期」升級到「數字期」
- 如果是新主題，從零建立三層瀑布

**敘事期 vs. 數字期：**
- 敘事期：技術未量產、無法確認訂單、股價反映預期
- 數字期：試產良率出爐 / 訂單確認 / 資本支出計畫明確 → 可以開始計算財務影響

### 節三：本週看到的機會

- 第二層標的 1–2 支：為什麼這週出現新訊號
- 第三層標的 1 支：長線布局邏輯
- 每支一段：論點 + 觀察到的信號 + 觀察指標（什麼情況會改變判斷）

### 節四：輸家 / 風險提示

- 本週哪些標的或賽道出現不利訊號
- 被替代的傳統環節（必須點名 ticker）
- 市場在哪些假設上可能錯誤

### 節五：下週關注清單

- 3–5 個具體可觀察事件（法說、數據公布、試產結果）
- 每項：「如果出現 X，對 Y 的影響是 Z」

## 輸出格式

MDX 文章，存放路徑：
```
C:\Users\alpha\my-blog\src\content\notes\投資\美股\美股週報-YYYY-MM-DD.mdx
```

frontmatter 必填：
```yaml
title: '美股週報｜[MM/DD]：[核心主題 10 字內]'
description: '[本週核心論點，含一個具體數字，60字內]'
category: '投資'
subcategory: '美股'
topic: '週報'
pubDate: 'YYYY-MM-DD'
```
