# 歐洲週報 SKILL

## 觸發方式

說「歐洲週報」、「寫歐洲週報」、「歐洲本週」時觸發。

---

## 工作流程（四步，不可跳過）

### Step 1：確認現有文章，避免重複

讀取 `src/content/notes/國際情勢/歐洲/` 底下的現有文章與最近 commit 記錄。
- 已報導過的事件，不再列為候選題
- 若本週有重大後續發展，標記為「接續追蹤」並說明新變化

### Step 2：搜尋本週時事

針對歐洲各次區域瀏覽網路，取得當週最新發展：
- 英國、北歐（挪威/瑞典/丹麥/芬蘭）、西歐（德/法/荷/比）、南歐（義/西/葡/希）、東歐（波蘭/捷克/羅馬尼亞/波羅的海）
- 優先方向：地緣政治、能源、國防、選舉、經貿、科技政策、移民
- 每個次區域最多 3 個候選事件，少而精優於多而雜

### Step 3：提出候選題，等待確認

以次區域分組列出候選題，每題附一行說明「為什麼這週這件事重要」。

格式：

```
**英國**
1. [事件標題] — [一句話：為什麼重要]
2. ...

**西歐**
1. ...

**東歐**
1. ...
（以此類推）
```

若使用者主動提供主題（如「能源」「選舉」「北約」），以該主題作為貫穿脊柱。

**等待使用者選題後才進入 Step 4。**
除非使用者明確說「自動跑」，否則不跳過這步。

### Step 4：撰寫、確認、推上 GitHub

依使用者選定的題目撰寫文章。一個題目一篇，除非使用者說合併。

## 文章規格

### Frontmatter

```yaml
---
title: '歐洲週報 YYYY-MM-DD｜[15字內標題]'
description: '[60字內，含主題、關鍵國家、一個讓人意外的角度]'
category: '國際情勢'
subcategory: '歐洲'
topic: '週報'
pubDate: 'YYYY-MM-DD'
---
```

### 存檔路徑

```
src/content/notes/國際情勢/歐洲/YYYY-MM-DD-短標題.md
```

### 文章結構（固定）

```markdown

| --- | --- | --- |
| ... | ... | ... |

## 事件說明

### 1. [事件標題]

[2–4 段：背景、本週發展、為什麼重要]

### 2. ...

[1–2 段：跨事件的共同邏輯，或反直覺的角度]
```

---

## 寫作原則

- 繁體中文
- 判斷優先於摘要：「一句話判斷」欄要有立場，不能只是複述標題
- 短段落 + 數字錨點 + 粗體強調關鍵判斷
- 表格只做橫向比較，不把整篇文章變成表格
- 不用 raw HTML（Callout 元件在 `.md` 不支援）
- 不在 body 重複 frontmatter 的 title（版面已自動渲染）
- 接續追蹤文章開頭需說明前篇連結與本週新增的變化
