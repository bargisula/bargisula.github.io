## 步驟 2：搜尋資料（五個面向，每項都要搜，不可省略）

**2a. 技術定義**
搜尋「[KEYWORD] 是什麼 原理 2025 2026」（若你有網路搜尋能力請搜尋，否則根據已知知識填入）

**2b. 瓶頸識別**
搜尋「[現有技術] 瓶頸 限制 產能天花板」
搜尋「[KEYWORD] 為什麼需要 原因 觸發點」

**2c. 台股供應鏈**

## 步驟 4：撰寫 MDX 文章

### frontmatter（必須完全一致）

```
---
title: '[KEYWORD] [15字內核心論點，含方向性判斷]'
description: '[60字內，含技術定位、受益邏輯、一個關鍵數字]'
category: '投資'
subcategory: '台股'
topic: '產業分析'
pubDate: '[YYYY-MM-DD]'
---
```

### MDX 第一行（必須加，不可省略）

```
import Callout from '../../../../components/Callout.astro';
```

### Callout type 只有這五種（其他一律不用，尤其禁用 info）

| type | 用途 |
|---|---|
| data | 數據表格、供應鏈結構、時間軸 |
| insight | 正面機會、突破訊號、受益邏輯 |
| warning | 風險、瓶頸描述、輸家、值得注意 |
| quote | 一句話結論、核心論點收尾 |
| link | 外部參考連結 |

---

### 文章結構（依序撰寫六節）

**開場白（3句以內）**
一句話定位「是什麼」，一句話說「為什麼現在重要」，一句話預告核心論點。

---

**## 一、技術定位**

`<Callout type="data">` 做對比表格：
欄位：項目 | 現有技術 | [KEYWORD] | 影響

說明觸發點：為什麼現在才重要（成本到臨界點 / 客戶需求升規 / 現有技術物理見頂）

---

**## 二、供應鏈卡片**

`<Callout type="data" title="[KEYWORD] 供應鏈三層結構">`
欄位：層級 | 環節 | 台灣標的（代號）| 角色說明

三層：核心製造 / 設備材料 / 上游原材料
若某層台廠空缺 → 標注「台廠目前空缺，外流至 [國家] 廠商」

---

**## 三、瓶頸→溢出分析**

先說現有技術的瓶頸（物理限制 + 具體數字）。

畫出溢出圖：
```
現有技術瓶頸（具體描述 + 數字）
  ↓ 溢出方向
[KEYWORD]（解法）
  ↓ 誰受益
1. [標的]：原因
2. [標的]：原因
  ↓ 誰受壓
[被替代者]：原因
```

`<Callout type="warning">` 框出一句話瓶頸描述。

最後一行：量化換算（差 X% = 有效產出差 Y%，約等於 Z 億美元市場規模差距）

### 寫作底線（必須遵守）

- 每個數字都要有來源語境，不寫孤立數字
- 瓶頸→溢出必須給出量化換算，讀者要能自己算帳
- 輸家必須點名具體公司，不能只說「傳統業者受壓」
- 時間軸必須具體到年份，不能說「未來幾年」
- 敘事期 vs 數字期必須明確標注其中一個
