# wisdom — 知識機制觸發掃描

**用途：** 分析任務開始前，掃描 Xompass 知識機制庫，識別當前環境已激活的傳導鏈，避免遺漏已知的因果框架。

**呼叫時機：** 宏觀推演、產業分析、個股分析、財報解讀、情報研判
**跳過時機：** 純操作任務（推送、格式修正、行事曆查詢、數字採集）

---

## 執行流程

### Step 1：動態掃描觸發條件

用 Glob 列出所有機制檔案，再逐一讀取 frontmatter 中的 `trigger` 欄位：

```
Glob: data/knowledge/mechanisms/*.md
對每個檔案讀取前 20 行（trigger、confidence、last_validated 欄位）
```

### Step 2：比對當前環境

根據對話描述的情境與用戶提供的數據，逐一判斷：

- 觸發條件有具體數字（如 `Brent > 90`）→ 用戶若提供數據則直接比對；未提供則標記「待確認」
- 觸發條件為情境描述 → 根據對話語境判斷是否符合
- `gpt-macro-cycle`（AI 建設期）為**常駐背景**，永遠激活，不需特別比對

### Step 3：選擇性載入

- ✅ **已激活** → 讀取完整機制文件，納入分析框架
- ⚠️ **監測中**（情境接近但未達閾值）→ 只讀取「可觀測早期指標」段落
- ⬜ **未觸發** → 列名稱即可，不載入

### Step 4：輸出激活報告

```
【知識機制激活報告】
✅ 已激活：[機制名] — [一句觸發原因]
⚠️ 監測中：[機制名] — [距觸發條件的差距]
⬜ 未觸發：[機制名]

多鏈交叉：[若多個機制同時激活，說明交叉強化邏輯]
```

輸出激活報告後，**繼續執行呼叫方 agent 的主要任務**，將激活的機制框架融入分析。
