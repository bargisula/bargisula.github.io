# Sector Deep Dive 報告格式

## 適用條件

下列情況選此格式（vs. 國防/地緣格式）：

| 產業特徵 | 選此格式 | 選國防格式 |
|---|---|---|
| 子板塊行為分歧大（保險 vs 生技 vs 設備） | ✓ | |
| 法規週期是主要驅動力（FDA、CMS、NDAA 以外的機構） | ✓ | |
| 技術採用曲線決定爆發點 | ✓ | |
| 地緣政治 / 採購週期主導 | | ✓ |
| backlog / book-to-bill 是核心指標 | | ✓ |
| 物理產能瓶頸是最大約束 | | ✓ |

適用產業：醫療、科技（SaaS/AI應用）、能源轉型、消費、金融科技

---

## 文章結構（固定順序）

```
版本更新日誌（Callout type="data"，可選）
---
一、產業核心邏輯（散文 + 三個結構性力量）
二、市場規模與宏觀數據（表格）
三、子板塊深度解析（H3 per 子板塊，含評等）
四、關鍵政策 / 監管風險（散文 + 表格）
五、技術革命主題（散文，點出最大結構性顛覆）
六、競爭格局與代表性公司（表格）
七、主線判斷與投資框架（三層：高確定性 / 中性觀察 / 迴避）
八、關鍵追蹤指標（表格）
```

## 各節寫法

### 版本更新日誌（可選）

```mdx
<Callout type="data" title="版本更新日誌">
| 修正日期 | 更新重點 | 關聯事件 |
| :--- | :--- | :--- |
| YYYY-MM-DD | **初始版本建立** | [觸發事件] |
</Callout>
```

---

### 一、產業核心邏輯

**格式：** 一段總覽散文（產業規模 + 2026 年核心命題），然後三個結構性力量（編號清單）。

```
[產業] 是 [規模描述]。2026 年的核心命題是：[一句話概括主要張力]。

三個結構性力量決定未來走向：

1. **[力量 A 標題]**：[一句說明，嵌入關鍵數字]
2. **[力量 B 標題]**：[一句說明，嵌入關鍵數字]
3. **[力量 C 標題]**：[一句說明，嵌入關鍵數字]
```

三個力量的框架：
- 力量 A：**不可逆的需求基礎**（人口、資本支出、監管義務）
- 力量 B：**當前的逆風或政策壓力**（削減、定價管制、競爭）
- 力量 C：**技術或創新的正向顛覆**（新藥、AI、新商業模式）

---

### 二、市場規模與宏觀數據

```mdx
| 指標 | 數值 | 備注 |
| :--- | :--- | :--- |
| [年份] 市場總規模 | **[金額]** | [來源] |
| 年均成長率 | **[%]** | [預測期間] |
| 10 年 CAGR | **[%]** | [預測期間]，對比 GDP 成長 [%] |
| [關鍵人口/結構指標] | **[數字]** | [說明] |
| [子板塊最大推力] | **[數字]** | [說明] |
```

來源優先順序：CMS（醫療）、EIA（能源）、Mordor Intelligence、Grand View Research

---

### 三、子板塊深度解析

每個子板塊一個 H3 節。格式：

```
### [編號]. [子板塊名稱]（[Managed Care / Pharma / Biotech / Medtech / Health Tech 等]）

**評等：[一句話 + 短期方向]**

[2–3 段散文：描述子板塊的核心邏輯、最新數據、關鍵公司表現]

[若有多公司比較，接一個小表格]

[若有警示，接 Callout type="warning"]
```

評等語法（固定格式）：
- `**評等：最強主線，持續加速**`
- `**評等：逆風中重建，短期謹慎**`
- `**評等：穩健，等待催化劑**`
- `**評等：結構性壓力，迴避**`

---

### 四、關鍵政策 / 監管風險

散文說明最重要的一到兩個政策風險機制，然後接表格：

```mdx
| 政策議題 | 影響對象 | 投資意涵 |
| :--- | :--- | :--- |
| [議題] | [受影響公司/族群] | [做多/做空/中性說明] |
```

---

### 五、技術革命主題

**格式：** 純散文，2–4 段。說清楚：
1. 是什麼技術在改變這個產業（具體產品/平台）
2. 直接受益者是誰（附數字錨點）
3. 間接影響鏈（哪些子板塊意外受惠或受損）
4. 時程估計（何時成為主流，用市場預測數字錨定）

---

### 六、競爭格局與代表性公司

```mdx
| 子板塊 | 龍頭標的 | 核心競爭力 | 主要風險 |
| :--- | :--- | :--- | :--- |
| [子板塊] | [Ticker1, Ticker2] | [一句話護城河] | [一句話風險] |
```

---

### 七、主線判斷與投資框架

```mdx
<Callout type="insight" title="[年份] [產業名] 核心投資主線">
  [一句話說清楚：誰受益、為什麼、最大的結構性機會在哪]
</Callout>

**高確定性（建立暴露）：**
- [標的/主題]：[一句邏輯]
- [標的/主題]：[一句邏輯]

**中性觀察（等待更清晰訊號）：**
- [標的/主題]：[等什麼信號]

**迴避或做空（高風險）：**
- [標的/主題]：[做空邏輯]
```

---

### 八、關鍵追蹤指標

```mdx
| 指標 | 監測頻率 | 意義 |
| :--- | :--- | :--- |
| [指標名稱] | 每季財報 / 每月 / 每年 | [為什麼重要] |
```

提供 5–7 個指標，覆蓋：
- 財報指標（MLR、ARR、毛利率等，依產業選）
- 政策事件（年度審批、季度數據發布）
- 市場滲透率指標（處方量、月活、設備裝機數）
- M&A 景氣指標

## Callout 規則（同全局規定）

| type | 用途 |
|---|---|
| data | 數據表格、版本日誌、競爭比較 |
| insight | 投資主線、核心受益邏輯 |
| warning | 政策風險、結構性壓力、做空邏輯 |
| quote | 失效條件、一句話核心結論 |
| link | 來源連結 |

## 禁止事項

- 禁止使用「癌點」，改用「做空邏輯」「失效條件」「結構性壓力」
- 禁止把分析推理塞進表格欄位（表格只做比較，論點用散文）
- 數字必須來自搜尋，不使用訓練資料中的市場數字
