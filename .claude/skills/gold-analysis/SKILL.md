# 黃金分析框架 SKILL

## 核心驅動因子（五維分析）

每次分析黃金時，從以下五個維度切入：

### 1. 美元 / 實質利率
- 實質利率（10Y TIPS yield）與金價負相關
- 美元指數（DXY）走弱 → 黃金支撐
- 聯準會降息預期 → 實質利率下降 → 利好黃金
- 關鍵數字：實質利率 < 0% 時黃金強勢期

### 2. 央行購金動態
- 追蹤：中國人民銀行、印度 RBI、波蘭 NBP、土耳其 TCMB
- 世界黃金協會（WGC）每季公布官方儲備數據
- 「去美元化」主題驅動新興市場央行持續購金
- 若月度購金量 > 50 噸 → 強烈看多訊號

### 3. ETF 資金流向
- 主要 ETF：GLD（SPDR Gold Shares）、IAU（iShares Gold Trust）
- ETF 持倉增加 → 機構資金進場 → 趨勢確認
- ETF 持倉減少但金價維持 → 實體需求支撐，更健康

### 4. 地緣風險溢價
- 中東衝突、俄烏戰爭、台海緊張 → 避險需求
- 風險溢價通常是短期爆拉後回落
- 長期看：地緣風險改變央行持金邏輯（更結構性）

### 5. 技術面 / 週期位置
- 關鍵支撐：前高、200日均線
- 關鍵阻力：整數關卡（2500、3000、3500）
- 黃金與銅比值（Gold/Copper ratio）：比值上升 → 避險情緒上升

## 常見問題分析架構

**「黃金還會漲嗎？」**
→ 看實質利率方向 + 央行購金是否持續

**「黃金 vs 比特幣，哪個是真避險？」**
→ 央行不持比特幣，機構面選黃金；個人投資者兩者都是替代美元選項

**「目標價怎麼看？」**
→ 分析師目標價沒有太大意義；真正重要的是實質利率走向和央行政策
