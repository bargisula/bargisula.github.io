# 快篩 SKILL

## 三種文章類型對照

| 類型 | 標題格式 | 觸發時機 | 字數 |
|---|---|---|---|
| `quick-scan` | 【快篩】 | 有新聞事件，快速判斷值不值得深研 | 600–900 字 |
| `us-tech-analysis` | 無前綴（產業快訊） | 財報季，系統性分析 | 1,200–1,800 字 |
| `deep-analysis` | 【深度分析】 | 重大個股，先討論架構再動筆 | 2,000–3,500 字 |

---

## 六節固定結構

### 第 0 節｜公司是什麼（必填，放在最前面）

**這是最常被遺漏、但最重要的一節。**

讀者可能完全不認識這家公司，必須在第一節用 3–5 句話說清楚：

1. **這家公司做什麼**（用一個具體的比喻或場景，不用官方說法）
2. **主要客戶是誰**（企業 / 政府 / 消費者）
3. **跟競爭對手最大的不同是什麼**（一句話）
4. **最後一句：簡單說：＿＿＿**（給讀者一個帶走的定位句）

格式：純文字段落，不用 Callout，保持輕讀感。

---

### 第 1 節｜觸發事件

說明為什麼現在看這家公司：
- 財報發布（超預期 / 不如預期 / 指引下修）
- 重大新聞（裁員、轉型、併購、IPO）
- 股價異常（單日大漲 / 大跌）

結尾必須有一句話說明「為什麼這個事件值得多看一眼」。

---

### 第 2 節｜財務快照

**一律用表格，數字必須來自搜尋，不用訓練資料。**

至少包含：
- 最新季度營收 + YoY 成長率
- 毛利率（GAAP 或 Non-GAAP 選一個，標清楚）
- EPS vs 預期
- 下季 / 全年指引

若是 IPO 公司：
- 定價區間 / 估值
- 超額認購倍數
- 關鍵財務預估（年度營收，標注是預估還是官方指引）

---

### 第 3 節｜快篩核心論點

這是全文最重要的節，必須說清楚：

1. **市場現在看到的**（為什麼股價這樣反應）
2. **應該看的**（市場可能沒讀懂的角度）
3. **支撐論點的具體證據**（數字、事件、產品）

若看多：用 Callout type="insight" 框核心邏輯
若有疑慮：用 Callout type="warning" 點出矛盾

---

### 第 4 節｜需要觀察的指標

列出 2–3 個「這個論點要成立，需要看到什麼數字或事件」。

用 Callout type="warning" 框住，格式：
```
**指標 1：XXX**
說明為什麼這個指標重要，以及判斷門檻。
```

---

### 第 5 節｜快篩結論

**固定格式：一個表格 + 一句話。**

表格：

| 維度 | 評分 |
|---|---|
| 財報質量 | ✅ / ⚠️ / ❌ + 一句說明 |
| 核心論點可信度 | ✅ / ⚠️ / ❌ + 一句說明 |
| 估值 | ✅ / ⚠️ / ❌ + 一句說明 |
| 短期進場時機 | ✅ / ⚠️ / ❌ + 一句說明 |

一句話結論：**「一句話：＿＿＿」**，必須給出明確立場（不能說「需要持續觀察」這種廢話）。

## Callout 使用規範

| type | 用途 |
|---|---|
| data | 財務表格、競爭對手比較 |
| insight | 看多論點、被市場低估的角度 |
| warning | 風險、需要觀察的指標、矛盾點 |
| quote | 一句話核心洞見（可選） |

**禁用：** `type="info"`

## frontmatter 格式

```yaml
title: '【快篩】[TICKER] [公司名]：[15字內，點出觸發事件或核心論點]'
description: '[80字內，含：觸發事件 + 財務數字 + 一句核心判斷]'
category: '投資'
subcategory: '美股'
topic: '產業分析'
pubDate: 'YYYY-MM-DD'
```

**MDX 第一行（必填）：**
```
import Callout from '../../../../components/Callout.astro';
```

**存放路徑：**
```
src/content/notes/投資/美股/[TICKER]-快篩.mdx
```

## 多支同時快篩

使用者給多個 ticker 時（如「快篩 NET、CBRS、NVDA」）：

1. 並行搜尋各標的財務 + 觸發事件數據
2. 各自產出一篇獨立 MDX
3. 一次 git commit 全部推上
