# 美股產業技術分析框架 SKILL

## 核心方法論：瓶頸→溢出

```
美股公司（技術/產品/市場地位）
  ↓
瓶頸識別（現有技術/市場限制）
  ↓
溢出受益（美股第一層供應鏈）
  ↓
輸家（被替代的舊供應鏈）
```

台股連動為**加分項目**：若該公司有明確的台灣供應鏈（代工、封裝、設備、材料），則加入模組 5 並點名具體代號；若無台股連動，直接省略模組 5，其餘六模組照常產出，**不影響文章是否撰寫**。

---

## 七模組結構

### 模組 1：公司定位
- 一句話說明「這家公司做什麼」「市值/營收規模」
- 為什麼「現在」值得分析（新產品、財報超預期、技術突破、競爭格局改變）
- 與競爭對手的差異表格（Callout type="data"）

### 模組 2：財務快照
- 最新季度營收、毛利率、EPS vs 預期
- 下季度指引
- 關鍵指標：本益比、本益成長比（PEG）、自由現金流
- Callout type="data" 做表格

### 模組 3：核心護城河
- 技術壁壘是什麼（專利、製程、生態系、網路效應）
- 量化：市占率、客戶黏性、毛利率相對同業
- Callout type="insight"

### 模組 4：瓶頸→溢出（核心）
- 現有技術/市場的瓶頸（同 tech-analysis 方法論）
- 溢出方向：誰受益、誰受壓
- Callout type="warning" 框出瓶頸

### 模組 5：台股連動（加分項，非必填）
- **有台股連動才寫此模組**；若無明確台灣供應商，整個模組省略，直接跳模組 6
- 有就寫：直接供應商（代工、封裝、基板、設備）
- 每家給出：台股代號、供應比重（若可搜到）、受益程度（高/中/低）
- Callout type="data" 做表格
- 結尾：哪家台股標的與這支美股正相關度最高

### 模組 6：催化劑與時程
- 未來 3–6 個月的具體催化劑（財報日、產品發布、法規、競爭對手動態）
- 時間軸表格：時間 | 事件 | 對股價影響方向
- Callout type="insight"

### 模組 7：風險與輸家
- 最大的 1–3 個下行風險（量化：若發生，影響幾個百分點）
- 被替代的競爭對手或舊供應鏈
- Callout type="warning"

## 寫作規則

**Callout type 使用規範（只有這五種）：**
| type | 用途 |
|---|---|
| data | 財務數據、供應鏈表格、時間軸 |
| insight | 護城河、正面催化劑、受益邏輯 |
| warning | 風險、瓶頸、輸家、值得注意 |
| quote | 一句話結論 |
| link | 外部參考 |

**禁用：** `type="info"`

> 📝 此寫作規則與 tech-analysis 保持一致。若修改 Callout 規範或 MDX 規則，須同步更新兩個 skill。

**MDX 第一行（必填）：**
```
import Callout from '../../../../components/Callout.astro';
```

**frontmatter：**
```yaml
title: '[TICKER] [公司名]：[15字內核心論點]'
description: '[60字內，含公司定位、核心優勢、台股連動關鍵詞]'
category: '投資'
subcategory: '美股'
topic: '產業分析'
pubDate: 'YYYY-MM-DD'
```

**文章存放路徑：**
```
src/content/notes/投資/美股/[TICKER]-產業分析.mdx
```

**深度原則：**
- 財務數字必須是最新季度，附上對比預期的漲跌幅
- 瓶頸→溢出必須給量化換算
- 催化劑必須給具體日期或時間區間
- 台股連動若存在，必須點名具體代號，不能只說「台灣供應商」；若不存在則省略模組 5

**文章是否產出的判斷標準（只看這兩點）：**
1. 財務數據是否充足（有最新季度財報即可）
2. 投資論點是否清楚（護城河 + 催化劑能說清楚即可）
台股有無連動不影響文章是否產出。
