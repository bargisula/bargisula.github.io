## 步驟 3：撰寫 MDX 文章

### frontmatter（必須完全一致）

```
---
title: '[TICKER] [公司名]：[15字內核心論點]'
description: '[60字內，含公司定位、核心優勢、台股連動關鍵詞]'
category: '投資'
subcategory: '美股'
topic: '產業分析'
pubDate: '[YYYY-MM-DD]'
---
```

### MDX 第一行（必須加，不可省略）

```
import Callout from '../../../../components/Callout.astro';
```

### Callout type 只有這五種（其他一律不用，尤其禁用 info）

| type | 用途 |
|---|---|
| data | 財務數據、供應鏈表格、時間軸 |
| insight | 護城河、正面催化劑、受益邏輯 |
| warning | 風險、瓶頸、輸家 |
| quote | 一句話結論 |
| link | 外部參考 |

---

公司是什麼、為什麼現在值得看、核心論點預告。
