# 深度分析 SKILL

## 與「產業快訊」的根本差異

| | us-tech-analysis（產業快訊） | deep-analysis（深度分析） |
|---|---|---|
| 數據來源 | 最新財報整理 | 原始申報文件 + 多來源交叉驗證 |
| 分析核心 | 供應鏈溢出、財務數字 | 跨域連結的原創洞察 |
| 趨勢章節 | 催化劑列表 | 市場尚未定價的結構性趨勢 |
| 標題 | `[TICKER] [公司]：[論點]` | `【深度分析】[TICKER] [公司]：[論點]` |
| 動筆前 | 直接執行 | **必須先討論架構，使用者確認才動筆** |

---

## 執行流程

```
收到指令
  ↓
步驟 1：快速 scan（3–5 次搜尋）
  → 公司基本面是否有足夠數據
  → 有沒有 3 個「非顯而易見」的洞察角度
  ↓
步驟 2：提出架構草案，與使用者討論
  → 說明各節內容方向
  → 說明第 5 節（洞察）的三個角度，讓使用者確認或修改
  ↓
步驟 3：使用者確認架構後，並行搜尋各節所需數據
  ↓
步驟 4：撰寫全文
  ↓
步驟 5：寫檔 + git push
```

**關鍵規則：步驟 2 使用者未確認前，不動筆寫文章。**

## 六節架構

### 第 1 節｜業務本質
**目的：建立理解邊界，讓讀者知道這家公司「能做什麼、做不到什麼」**

- 用一個具體的技術或商業邏輯說明公司核心運作方式（不是官方說法的改寫）
- 必須包含「能力邊界表格」：✅ 能做 / ❌ 不能做
- 避免行銷語言，用機制說話

寫作原則：讀者看完這節，應該能向別人解釋這家公司的技術原理，而不只是「他們做 XX 的」。

---

### 第 2 節｜市場：供給 ＋ 需求，有數字才寫
**目的：定位公司在市場中的位置，並量化市場的成長性**

**需求端：**
- 市場規模（總市場 TAM + 可服務市場 SAM）
- 成長驅動因子（2–3 個，要有邏輯，不只是「市場在成長」）
- 若有 CAGR 數字，寫出來；若沒搜尋到，直接說「未取得可信數字，不估算」

**供給端（競爭格局）：**
- 主要競爭者比較表（Callout type="data"）
- 分析「競爭者的真實能力差距」，不只是列名字
- 點出哪個競爭威脅被市場高估、哪個被低估

**規則：沒有數字的地方不要硬填，寫「目前未取得可驗證數字」。**

---

### 第 3 節｜護城河：競爭優勢的本質
**目的：說明為什麼這家公司的優勢「難以複製」，而不是「很好」**

每個護城河必須說明：
1. 這個壁壘的**物理或制度機制**是什麼
2. 複製它需要**多少時間和金錢**
3. 現有競爭者距離這個壁壘有多遠

常見護城河類型（選適用的，不強求全部）：
- 監管認證（政府 clearance、藥物 FDA 核准）
- 歷史數據飛輪（資料越多，產品越好，新進者追不上）
- 客戶轉換成本（嵌入作業流程後的替換代價）
- 規模效應（單位成本隨規模下降）
- 網路效應（用戶越多，價值越高）

使用 Callout type="insight" 框出核心壁壘洞察。

---

### 第 4 節｜財務軌跡
**目的：用數字驗證商業模式是否在運作，所有數字必須來自搜尋，不使用訓練資料**

格式規定：**一律用表格**，至少包含 2–3 年度對比。

必填欄位（有搜到才填，沒有寫「未取得」）：
- 年度營收 + YoY 成長率
- 毛利率
- 淨利（虧損）
- 訂單積壓（若有）
- 關鍵業務指標（ARR、客戶數、每客戶收入等，依公司性質選擇）

IPO / 剛上市公司的額外項目：
- IPO 募資金額與定價
- 資金用途揭露
- 鎖定期到期時間（潛在賣壓）

**財務品質分析：** 不只列數字，要說明數字背後的品質。例如：訂單積壓的覆蓋率、收入的政府 vs 商業比例、毛利率的趨勢方向。

---

### 第 5 節｜結構性趨勢：三個被市場低估的洞察
**這是深度分析與產業快訊最大的分野，也是最核心的部分。**

**目的：找出三個「現有分析師報告沒有連結、但真實存在」的驅動因子**

洞察的來源：跨域連結
- 軍事動態 × 商業需求
- 法規變化 × 市場結構
- 地緣政治 × 供應鏈
- 科技演進 × 既有基礎設施的淘汰

每個洞察的寫法：
1. **標題說明是什麼趨勢**（具體事件或數字作為錨點）
2. **為什麼市場沒有充分定價**（解釋為何這是被低估的）
3. **對這家公司的直接影響**（量化或邏輯連結）

Callout 使用：
- type="insight"：正面趨勢連結
- type="warning"：讓讀者思考的反向邏輯

**規則：三個趨勢必須是「非顯而易見」的連結。如果一個趨勢在公司官方 IR 簡報裡已經提過，它就不夠深。**

---

### 第 6 節｜風險
**目的：提供平衡視角，不是為了嚇人，是讓讀者知道什麼會讓論點失效**

每個風險必須包含：
1. **機制**：什麼情況下這個風險會發生
2. **量化影響**（若可搜到）：發生了對營收 / 估值的影響幅度
3. **減緩因子**：有沒有緩衝

最多列 3 個風險，用 Callout type="warning" 框住。

---

## 結語規範

每篇文章必須有一個**結語段落**，格式：
1. 1–2 句話說明「市場現在定價的是什麼」
2. 1–2 句話說明「市場沒有定價的是什麼」（呼應第 5 節洞察）
3. 一個 Callout type="quote" 做一句話核心洞見

---

## 寫作通用規則

**Callout type（只有這五種）：**
| type | 用途 |
|---|---|
| data | 財務數據、競爭者比較表、能力邊界表 |
| insight | 護城河洞察、正面趨勢連結、受益邏輯 |
| warning | 風險、能力邊界的限制、競爭威脅 |
| quote | 結語的一句話核心洞見 |
| link | 外部參考 |

**禁用：** `type="info"`

**MDX 第一行（必填）：**
```
import Callout from '../../../../components/Callout.astro';
```

**frontmatter：**
```yaml
title: '【深度分析】[TICKER] [公司名]：[20字內核心論點]'

category: '投資'

topic: '產業分析'
pubDate: 'YYYY-MM-DD'
```

## 資料搜尋原則

1. **所有財務數字必須透過搜尋取得**，不使用訓練資料中的財務數字
2. 數據優先順序：官方 IR / SEC 申報 > 財經媒體 > 分析師報告 > 市場研究報告
3. 若找不到可信數字，寫「目前未取得可驗證數字」，**絕不硬生成**
4. 搜尋至少涵蓋：財務數據、競爭格局、市場規模、各趨勢所需的事件數據
