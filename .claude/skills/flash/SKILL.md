# Flash 市場快訊記錄 SKILL

## 觸發後的行為

使用者貼新聞或說「幫我記下來」時，**直接執行，不要先問確認**。
唯一例外：內容語意不清時，先輸出解析結果讓使用者確認。

---

## 步驟 1：解析輸入內容

從使用者的輸入中自動提取：

| 欄位 | 解析規則 |
|---|---|
| **情緒** | 含「看多/樂觀/上調/買進/目標價上調」→ 看多；「看空/悲觀/下調/賣出/警告」→ 看空；其餘 → 中性或事件 |
| **標的** | 公司名、股票代號（NVDA、2330）、商品（黃金、原油、美債）、指數（台股、S&P） |
| **來源** | 人名或機構（高盛、摩根、達利歐、Bridgewater）|
| **類型標籤** | 分析師觀點→`#觀點`；總經數據→`#數據`；法說會→`#法說`；財報→`#財報`；地緣事件→`#地緣`；產業動態→`#產業` |
| **核心內容** | 去除標籤、代號後的主體文字，保留原意，壓縮至 2–3 句以內 |

---

## 步驟 2：寫入本機檔案

路徑：`C:\Users\alpha\flash-notes\YYYY-MM.md`（YYYY-MM 為當前年月）

- 檔案存在 → 直接追加
- 檔案不存在 → 先建立標頭再追加：

```markdown
# 市場快訊｜YYYY 年 MM 月

> 隨手記錄多空觀點、市場事件、數據與個股動態

---

## 本月標的速覽
<!-- flash-index -->
（本區塊自動更新）
<!-- /flash-index -->

---
```

追加格式：

```markdown
### HH:MM｜MM/DD｜{圖示} {標的}

{來源（若有）}：{核心內容}

> {標籤列表}

---
```

**情緒圖示：**
- 看多 → 🟢
- 看空 → 🔴
- 中性 → ⚪
- 純事件/數據（無情緒） → 📌

---

## 步驟 3：更新本機標的速覽表

掃描本月所有快訊，更新 `<!-- flash-index -->` 區塊：

```markdown
<!-- flash-index -->
| 標的 | 🟢 看多 | 🔴 看空 | 📌 事件 | 最後更新 |
|---|---|---|---|---|
| 黃金 | 2 | 1 | 0 | 05/09 |
| 台積電 | 0 | 1 | 1 | 05/09 |
<!-- /flash-index -->
```

---

## 步驟 4：同步寫入部落格 MDX

路徑：`C:\Users\alpha\my-blog\src\content\notes\投資\當月快訊\YYYY-MM.mdx`

- 檔案存在 → 在最後一筆 `---` 前追加新快訊
- 檔案不存在 → 建立新 MDX 檔：

```markdown
---
title: '市場快訊｜YYYY 年 MM 月'
description: '台股、美股、黃金、總經 — YYYY 年 MM 月多空觀點與市場事件紀錄'
category: '投資'
subcategory: '當月快訊'
topic: '市場快訊'
pubDate: 'YYYY-MM-01'
---

import Callout from '../../../../components/Callout.astro';

> 隨手記錄多空觀點、市場事件、數據與個股動態。台股、美股、黃金、總經每則皆含情緒標注。

---
```

追加格式（與本機一致）：

```markdown
### HH:MM｜MM/DD｜{圖示} {標的}

{來源（若有）}：{核心內容}

> {標籤列表}

---
```

## 步驟 5：git commit 並推上 GitHub

在 `C:\Users\alpha\my-blog` 執行：

```
git add src/content/notes/投資/當月快訊/YYYY-MM.mdx
git commit -m "flash YYYY/MM/DD {標的}｜{內容前20字}"
git push origin main
```

## 步驟 6：輸出確認（簡潔）

```
✅ [HH:MM] 已記錄並推上部落格
   {圖示} {標的}｜{內容前 30 字}...
   本月共 N 則｜2026-05.mdx 已更新
```

若解析結果與輸入有明顯出入，加一行：
```
💬 解析為「看多/黃金」，若有誤請說「改成看空」或「不用記」
```

## 查閱快訊

使用者說「看一下快訊」「本月記了什麼」「黃金的觀點」時：

- 無篩選 → 讀本機 `flash-notes\YYYY-MM.md`，輸出速覽表 + 最近 5 則標題
- 有篩選詞（標的或情緒）→ 輸出符合條件的完整快訊

```
📋 2026-05 快訊（共 N 則）

【速覽】
| 標的 | 🟢 | 🔴 | 📌 |
...

【最近 5 則】
🟢 14:24 05/09  黃金｜達利歐：大動盪期建議配置 5–15%
...
```
