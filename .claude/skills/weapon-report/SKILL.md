# 武器裝備日報 SKILL

## 執行流程

```
搜尋新聞 → 去重篩選（排除已有主題）→ 產出草稿（對話預覽）→ 等待確認 → 寫 MDX 檔 → git push
```

**關鍵規則：草稿確認前不寫任何檔案。**
使用者說「確認」「OK」「推上去」→ 全部推
使用者說「推第一篇」「推第二篇」→ 只推指定篇
使用者說「修改第一篇第二節：[內容]」→ 修改後重新預覽再確認

---

## 步驟 1：取得今日日期與現有文章清單

取得今日日期（YYYY-MM-DD）。

讀取現有武器裝備文章清單，以防止主題重複：
路徑：`C:\Users\alpha\my-blog\src\content\notes\軍事\武器裝備\`
（或 worktree 路徑）

記錄已有的武器系統、平台、事件名稱。

---

## 步驟 2：搜尋近 24 小時武器裝備新聞

搜尋以下主題組合，選出最多 3 個各不重複的主題：

- 搜尋：`武器裝備 新型 海軍 [今日日期]`
- 搜尋：`military weapons system latest [今日日期]`
- 搜尋：`新型戰機 潛艦 飛彈 無人機 軍艦 [今日日期]`
- 搜尋：`US Navy Air Force Army new weapon system [今日日期]`
- 搜尋：`台灣 國防 武器採購 [今日日期]`
- 搜尋：`Taiwan defense procurement military [今日日期]`

**選題標準（依優先順序）：**
1. 有具體規格數字（射程、速度、載彈量、噸位）
2. 有新系統亮相、測試、部署或採購消息
3. 與台海防禦有直接關聯（優先）
4. 排除純政治新聞，聚焦武器平台與技術

**去重規則：**
- 對照現有文章清單，相同武器系統/平台/事件不重複撰寫
- 若找不到 3 個新主題，寫幾篇就幾篇（最少 1 篇）

---

## 步驟 3：產出 MDX 草稿（對話預覽，不寫檔）

每篇格式如下：

```mdx
---
title: '[武器系統或事件名稱]技術解析'
description: '[60字內摘要，含主要規格與戰術意義]'
category: '軍事'
subcategory: '武器裝備'
pubDate: '[YYYY-MM-DD]'
---

import Callout from '../../../../components/Callout.astro';

## 綜述

[武器系統背景、來源國、研發脈絡、為何重要，3–4 段]

---

## 技術能力

[主要技術特點，含具體數字：射程、速度、精度、載具相容性等]

| 規格項目 | 數值 |
|---|---|
| [項目] | [數值] |
...

---

## 戰術運用

[作戰場景分析：如何使用、在哪種作戰框架中發揮作用]

<Callout type="insight">
關鍵戰術洞見一句話。
</Callout>

---

## 對台海的意義

[對台灣防衛或台海局勢的具體影響、是否台灣有採購可能或應對需求]

<Callout type="data">
關鍵數字或政策背景。
</Callout>

---

## 技術規格摘要

| 項目 | 說明 |
|---|---|
| 研發國 | |
| 類型 | |
| 射程 / 航程 | |
| 推進方式 | |
| 彈頭 / 載荷 | |
| 現役狀態 | |

---

**資料來源**：[來源1](URL) ／ [來源2](URL)
```

**Callout 只能用以下 type：`data` / `insight` / `warning` / `quote` / `link`。絕對不能用 `info`。**

---

## 步驟 4：草稿輸出格式

輸出所有草稿後，在對話結尾加上：

```
---
📋 武器裝備日報草稿完成，共 N 篇。

【篇目清單】
1. [標題]
2. [標題]
3. [標題]（若有）

請確認：
- 輸入「確認」→ 全部寫檔並推上 GitHub
- 輸入「推第一篇」→ 只推第 1 篇
- 輸入「推第一篇第二篇」→ 推指定篇次
- 輸入「修改第 N 篇 [哪節]：[修改內容]」→ 修改後重新預覽
- 輸入「跳過」→ 不推任何篇
```

---

## 步驟 5：收到確認後寫 MDX 檔

**檔名格式：**
`[YYYY-MM-DD]-[武器系統關鍵詞].mdx`

例：`2026-05-09-F47戰機首飛解析.mdx`

**路徑：**
`C:\Users\alpha\my-blog\src\content\notes\軍事\武器裝備\[檔名].mdx`

寫入前先確認同名檔案不存在；若已存在，告知使用者。

---

## 步驟 6：git commit 並推上 GitHub

在 `C:\Users\alpha\my-blog` 執行（依確認篇數調整）：

```bash
git checkout main
git pull origin main
git add src/content/notes/軍事/武器裝備/[檔名1].mdx
git add src/content/notes/軍事/武器裝備/[檔名2].mdx  # 若有
git add src/content/notes/軍事/武器裝備/[檔名3].mdx  # 若有
git commit -m "add 武器裝備 [YYYY-MM-DD] [主題1]、[主題2]"
git push origin main
```

完成後輸出：
```
✅ 已推上 GitHub
   [檔名1].mdx
   [檔名2].mdx（若有）
   [檔名3].mdx（若有）
```

---

## 寫作品質規則

- 每篇聚焦一個武器系統或作戰事件，不混搭
- 必須有技術規格表格
- 「對台海的意義」一節不能省略
- 語氣客觀中立，分析技術而非政治立場
- 數字要有來源（可在文末資料來源中標注）
- 只用標準 Markdown + Callout 元件，不用其他自訂元件
- 所有連結必須可點（不能只寫來源名稱）
