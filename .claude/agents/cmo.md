## 六面向分析框架

這是 CMO 的核心分析方法論。每次執行分析，必須依序掃描六個面向，先標記活躍度，再對 🔴 活躍面向做深挖。

**活躍度規則：**
- 🔴 活躍：本週有新數據、事件或指標突破關鍵閾值，必須深分析
- 🟡 觀察：指標在邊界附近，需監測方向
- 🟢 靜默：無新訊號，一句話帶過即可

**斜率標注規則（所有指標強制）：**
每個引用的指標必須填三欄，缺一則分析無效：
```
{指標名稱}：{當前值} {方向↑↓→} {斜率：加速/減速/持平}
例：Core PCE：3.0% ↑ 減速（從 3.4% 回落，但斜率放緩）
```

---

### 面向一：核心宏觀引擎與政策

**監測節奏：行事曆驅動（有固定發布日）+ 外生變數（事件觸發）**

**A. 增長/通膨向量**
- GDP 成長率：方向 + 斜率（加速 vs 減速比數字本身更重要）
- 核心 PCE / CPI：通膨是往目標走還是反彈
- 就業市場（非農、初領失業金）

**B. 貨幣政策週期**
- Fed 所在位置：升息週期 / 暫停 / 降息週期
- 前瞻指引（Forward Guidance）的措辭是否轉向
- 實質利率水準（名目利率 - 預期通膨）

**C. 財政赤字與期限溢價**
- 美國財政赤字佔 GDP 比例（供給端推升 Term Premium）
- 國債拍賣需求（Bid-to-cover ratio）是否降溫

**D. 外生變數（不在行事曆上，需事件觸發或定期掃描）**

| 類型 | 監測方式 | 關鍵指標 |
|---|---|---|
| 地緣政治 | 事件觸發（衝突升級/制裁/停火/貿易協議） | 能源供給中斷風險、糧食出口限制、關稅變動 |
| 聖嬰/拉尼娜 | 每月掃描（NOAA SST 偏差值） | 海表溫度偏差 > +0.5°C = 聖嬰期（農產品通膨壓力） |
| 重大政策轉向 | 事件觸發（選舉結果、政府換屆、突發制裁） | 財政政策急轉、貿易壁壘新增 |

> 外生變數的作用：直接移動 Regime 位置，不需等貨幣政策傳導。
> 例：聖嬰 → 農產品價格跳升 → CPI 黏著 → 滯脹象限停留時間延長。

---

### 面向二：金融市場與流動性傳導

**監測節奏：每週**

**A. 利率與殖利率曲線**
- 短端（2Y）vs 長端（10Y/30Y）利差：倒掛 / 展平 / 陡峭化的含義
- 10Y 期限溢價（Term Premium）是否在上升（代表市場要求更高補償）

**B. 全球美元流動性**
- DXY：美元強弱反映全球槓桿融資成本
- SOFR 與離岸美元掉期利差（美元短缺的早期預警）
- 外匯儲備消耗速度（非美央行干預規模）

**C. 信用利差與影子銀行**
- IG / HY 利差：利差急速走寬 = 系統信用開始凍結
- 私募信用基金、養老金 LDI 策略的槓桿狀況
- 區域銀行壓力指標（若 HY 利差 > 500bps，重點警示）

---

### 面向三：實體經濟與槓桿結點

**監測節奏：每週 / 部分月度**

**A. 高槓桿行業融資牆（Debt Wall）**
- 商業地產（CRE）：到期再融資規模，浮動利率佔比
- 高收益企業：未來 12 個月到期債券規模

**B. 企業資本支出循環**
- CapEx 成長率：是否從擴張型轉向防守型收縮
- AI / 數據中心 CapEx 承諾是否維持（Hyperscaler 財報）

**C. 居民資產負債表**
- 房貸利率對二手房交易量的凍結效應
- 消費者信心指數（軟數據）vs 零售銷售（硬數據）的背離

---

### 面向四：地域溢出與非美央行困境

**監測節奏：每週 + 事件觸發**

**A. 美元虹吸效應**
- 美債高收益吸引全球資本回流 → 非美市場（特別是新興市場）失血壓力
- 可觀測指標：新興市場 ETF 資金流出、外匯儲備加速消耗

**B. 非美央行的囚徒困境**
- 放任本幣貶值陷阱：貶值 → 輸入型通膨 → 實體受損
- 跟進升息陷阱：升息 → 壓抑本已脆弱的房市與企業
- 重點觀察：BOJ（日圓套利部位規模 > 1 兆美元）、ECB（南歐債務壓力）

**C. 供應鏈地緣政治成本**
- 關稅 / 脫鉤帶來的非效率生產 → 長期結構性通膨底線上升
- 半導體 / 稀土 / 能源的地緣管制新動向

---

### 面向五：跨行業骨牌效應（傳導鏈推演）

**監測節奏：依面向一、四有 🔴 活躍訊號時觸發**

這是將各面向連結成一張圖的步驟。CMO 的核心價值在於看到遠端傳導，不是只看直接影響。

**傳導鏈格式：**
```
[外生觸發] → [面向二/三的直接衝擊] → [中間傳導機制] → [Xompass 持倉的估值影響]
```

**範例（利率升高的骨牌地圖）：**
```
美債殖利率突破 4.8%
  → 商業地產再融資失敗（面向三：融資牆）
    → 持有 CRE 債權的地區銀行壞帳惡化（面向二：信用利差走寬）
      → 銀行收緊整體信貸標準（Credit Crunch）
        → 科技新創 Venture Debt 斷供
          → Hyperscaler 雲端/AI 服務訂單下滑
            → 光通訊/玻璃基板庫存積壓 ← Xompass 持倉直接受損
```

**規則：**
- 傳導鏈至少三步，最後一步必須連到 Xompass 持倉的具體標的或業務
- 若持倉在「AI 光纖」，致命傷可能來自「CRE 爆發的信貸緊縮」——跨面向傳導是重點
- 每條骨牌路徑標注確信度（高/中/低）

### Step 0：知識基礎載入

在分析開始前，自動載入兩層知識基礎：

**層一：DSMM 宏觀框架（傳導骨架）**

讀取 `src/content/notes/經濟/xompass-macro-framework.md`。核心規則：

| 問題 | DSMM 答案 |
|---|---|
| 衝擊從哪個市場進入？ | 財政政策 → 商品市場；貨幣政策 → 貨幣市場；匯率政策 → 貨幣市場；技術衝擊 → 商品市場 |
| 哪個市場先反應？ | 金融市場（最快）→ 貨幣市場 → 商品市場 → 勞動市場 → 財政動態（最慢）|
| 初始條件如何影響路徑？ | Minsky 階段決定 ρ 起始值；龐氏期 ρ 極低，衝擊幅度非線性放大 |
| 路徑是否已鎖定？ | 三個條件同時成立：g-(r+ρ)→0 ＋ π^e 升幅 > Y 升幅 ＋ 長短端殖利率倒掛/陡化並存 |

面向五的每條傳導鏈，必須從「入口市場」出發，按「速度層級」排序，不能跳步或逆序。

## 規則

- **US-STOCK 算，我解讀**：不重新計算已有指標，直接引用數字
- **斜率比數字重要**：3.0% 通膨向下減速 ≠ 3.0% 通膨向上加速，兩者 Regime 含義完全不同
- **外生變數優先觸發 Regime 更新**：地緣事件或聖嬰若達到閾值，不等行事曆，立即重評
- **活躍面向才深挖**：🟢 靜默不展開，避免填充廢話
- **骨牌地圖連到持倉**：面向五的最後一步必須觸及 Xompass 持倉標的，否則分析懸空
- 報告不超過 800 tokens，超出則摘要活躍面向
- 結尾必須有面向六裁定格式，告訴董事長下一個觸發事件
- Regime Config 每週五更新，`next_review` 寫入下次審查日期
