# AI 數據中心電力基礎設施 論點追蹤｜建立於 2026-06-07

---

## 當前論點 v1

**一句話論點：** AI GPU 集群的功耗密度已超越傳統電力基礎設施的規劃假設，電網設備與機房電源管理形成硬性瓶頸，供給擴張週期長達 3–5 年，定價窗口早於市場預期開啟

**建立日期：** 2026-06-07  
**上次更新：** 2026-06-07  
**建立背景：** Regime 明確列入 focus_sectors（INS-004 電力瓶頸），DSMM 兩次 run（10Y480、TARIFF）均確認 AI capex 鏈不受利率週期直接衝擊，電力需求具長期合約能見度。知識圖譜（power-infra-nodes.json）已建立 19 節點四層供應鏈地圖

---

## 產業結構速覽

```
Layer 0A（核電 / SMR）：CEG、OKLO、CCJ
Layer 0B（傳統發電）：VST、NRG、BE、NEE
Layer 1（電網設備）：GEV、ETN、PWR、HUBB   ← 主要追蹤層
Layer 2（機房電源）：VRT、SBGSY、SMCI       ← 主要追蹤層
Layer 3（超大型雲端）：MSFT、AMZN、GOOG、META（需求端）
```

**論點核心在 Layer 1 + Layer 2**：設備交貨週期 18–36 個月，產能無法快速擴張，需求端卻是多年合約鎖定，供需缺口持續擴大。

**裁定規則：**
- 所有 C 成立 → 論點完整成立，繼續持有邏輯
- C2 或 C5 出現 ⚠️ → 論點弱化但未失效，需追蹤法說
- 任一出現 ❌ → 評估是否需要重寫論點

## 標的優先序

| 優先序 | 標的 | 核心邏輯 | 主要風險 |
|---|---|---|---|
| 1 | **VRT（Vertiv）** | Layer 2 機房電源龍頭，backlog 能見度最強，直接受益 GPU 密度提升 | 估值偏高；若 backlog 動能放緩市場反應劇烈 |
| 2 | **GEV（GE Vernova）** | Layer 1 電網設備，變壓器交貨週期 2–3 年是供給瓶頸代表，定價能力強 | 業務分散（風電/燃氣），電力設備只是其中一塊 |
| 3 | **ETN（Eaton）** | Layer 1 電力分配 + UPS，跨 Layer 1/2 受益，估值相對合理 | 業務多元，AI 電力純度低於 VRT |
| 4 | **CEG（Constellation）** | Layer 0A 核電 PPA 最大受益者，長期合約鎖定現金流 | 監管風險；核電重啟時程不確定性 |
| 觀察 | **PWR（Quanta Services）** | Layer 1 電力工程建設，受益電網現代化工程量 | 訂單能見度需確認；IRA 撥款依賴度較高 |
| 暫避 | **SMCI（Super Micro）** | Layer 2 但財務不透明度高，審計問題未完全解決 | 財務信譽風險 |

## DSMM 座標

依據 RUN-20260607-10Y480 + RUN-20260607-TARIFF：

- **10Y 高位場景**：AI capex 鏈「中性（相對抗跌）」，電力需求不受住宅利率影響，長期合約保護現金流 → 論點維持
- **關稅衝擊場景**：AI capex 鏈「中性」，硬體供應鏈部分影響，但電力基礎設施以美國本土為主，關稅暴露有限 → 論點維持
- **Regime 壓力方向**：down-right（Overheat→Stagflation）對 Layer 0 發電廠略有影響（電力成本↑），但對 Layer 1/2 設備商是正向（替代與升級需求↑）
