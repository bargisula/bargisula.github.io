## 核心命題

**AI 是本週期最大的外生變數。它對總體經濟的衝擊分兩波，時間錯開 3-5 年，市場幾乎只定價了第一波。**

```
第一波：AD 衝擊（2022-2026）
  Capex 拉動需求 → 半導體 / 電力 / 建設 / 製造業訂單上行
  → 名目 GDP 上行，但核心通膨黏性（晶片、電力需求推升生產成本）

第二波：AS 衝擊（2027-2029+）
  AI 生產力釋放 → 白領服務業人工替代開始
  → 潛在 GDP 上行，通膨長期均衡下移
  → 實質利率均衡（r*）受雙向力量拉扯：生產力上升拉高 r*，通縮壓力拉低 r*
```

**市場當前定價**：AD 面已充分定價（AI 晶片股估值 40-60x P/E），AS 面幾乎未定價。
**Xompass 的 alpha 來源**：識別 AD→AS 轉折點，比市場早 12-18 個月重新定位。

## 物價路徑（主線 vs 分叉）

### 主線（60% 確信）
```
2026：通膨黏性 3.0-3.5%（AI capex 推升能源 / 建設成本）
2027：通膨開始下行（AS 效應局部出現，白領服務業成本下降）
2028-2029：通膨均衡可能突破 2% 下限進入通縮壓力區間
```

### 分叉 1 - 滯脹路徑（25% 確信）
```
觸發：Warsh 妥協 Fed 公信力受損 + 油價地緣推升
→ 通膨 >3.5% 延續至 2027，Fed 被迫升息
→ 高倍數估值修正，AI capex 週期縮短
```

### 分叉 2 - 早期通縮路徑（15% 確信）
```
觸發：AGI 早期突破（2027 前）+ 企業大規模裁員
→ AS 衝擊提前到來，通膨快速跌破 2%
→ Fed 被迫降息，但失業率上行，類 1990s 科技衝擊
```

## 實質利率長期均衡（r*）

當前估計：1.8-2.2%（高於疫情前 0.5%，AI Capex 拉動需求是主因）

**方向性判斷：**
- 短期（2026-2027）：r* 維持高位，AI Capex 撐住需求
- 中期（2027-2028）：AS 效應出現後，r* 有下行壓力
- 長期（2029+）：取決於 AI 生產力能否持續，若是，r* 可能重回 1% 以下

**投資含義**：現在押長久期資產（長債 / 高倍數成長股）的折現率風險仍高。

## 衝突仲裁連結

- 若 NVDA 推理晶片佔比 >40%：快變數更新，同步確認 AS 先行指標，考慮升級 INS-002 tier
- 若核心 PCE 突破 3.5%：觸發 Regime 複核（滯脹路徑概率上升），Bible 物價路徑分叉重新評估
- 若 Hyperscaler capex 出現兩季 QoQ 負成長：AD 頂部訊號，考慮啟動 Bible 快變數緊急更新
