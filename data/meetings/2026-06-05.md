### 討論二：NVIDIA Harness + Agent OS 框架

**觸發：** 董事長提出 NVIDIA Harness 與代理人作業系統議題。

**Harness 定義：**
NVIDIA 官方：「Autonomous agents require a software layer called a harness to turn the model into an agent with functions like orchestration, context, memory, tool use and security.」

**作業系統類比：**

| 1990 年代 PC | 2026 年 AI |
|---|---|
| 硬體（CPU/RAM） | 模型（Claude/GPT） |
| 作業系統（Windows） | Harness / Agent OS |
| 應用程式（Word/Excel） | AI 應用（財報分析器/客服 agent） |

誰定義 runtime 標準，誰收取所有 agent 的過路費。三方搶位：NVIDIA（硬體往下定義執行環境）、Microsoft（Windows 原生 + 開源治理）、Anthropic（model API 往上攻 control plane）。

**AVGO 與 Harness 的連結：**
AVGO 不需要自己做 Harness 軟體，機會在於成為「所有 Harness 都必須跑在上面的硬體地基」——等同 Intel 在 PC 時代對 Windows 的關係。關鍵動作：加入 FUSION，讓 Tomahawk 網路交換晶片成為 NVIDIA Harness 生態的強制標準組件。

**FUSION 時間壓力：** Marvell 已在 FUSION 內，MediaTek 搶推論工作量後，AVGO 每晚加入一季，推論工作量的網路流量就多一部分繞過 Tomahawk。

### 討論四：新 Insight 建立

**INS-2026-06-05-006（L1，confidence 0.65）：**

> 「AI agent 時代的平台標準制定者將取得持續性過路費收益；硬體層的標準制定者比軟體層更難被替代」
