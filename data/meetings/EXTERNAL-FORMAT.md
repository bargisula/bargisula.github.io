# 外部晨會摘要格式標準 v1.0

> 適用：發送給外部讀者（客戶、合作方）的晨會摘要版本
> 對應：內部 `data/meetings/YYYY-MM-DD.md` → 外部 `src/content/notes/投資/晨會摘要/YYYY-MM-DD.mdx`

---

## Frontmatter

```yaml
---
title: '【晨會】YYYY-MM-DD 市場摘要'
description: '60字內，點出本期最重要的一件事'
category: '投資'
subcategory: '當月快訊'
topic: '晨會摘要'
pubDate: 'YYYY-MM-DD'
---
```

---

## 文章結構（六節，固定順序）

### 節一：市場快照（Market Snapshot）

**目的：** 讓讀者在 30 秒內掌握前一交易日數字。數字用表格，不夾在散文裡。

**格式模板：**

```mdx
## 市場快照｜YYYY-MM-DD

### 美股
| 指數 | 收盤 | 漲跌 |
|---|---|---|
| **S&P 500** | 7,584 | +0.41% |
| **Nasdaq** | 26,831 | -0.09% |
| **Dow** | 51,561 | +1.73% |

| 情緒指標 | 數值 |
|---|---|
| VIX | 15.40 |
| 10Y 殖利率 | 4.47% |

### 台股
| 指標 | 數值 | 漲跌 |
|---|---|---|
| **加權指數** | 45,071 | -1.33%（-607 點）|
| **台積電** | 2,365 元 | +0.84% |

### 市場訊號
```

**Regime 格式（Callout，非 code block）：**

```mdx
<Callout type="data">
**當前 Regime：** AI 資本支出週期（Risk-on）

**尾部風險：** 若 NFP 超預期（＞18 萬）且 10Y 快速升破 4.6%，
則 Warsh 鷹派壓力升溫，通膨路徑重估。
</Callout>
```

**規則：**
- 美股、台股各一個表格，不混在一起
- 漲跌欄用 `+` 標正數，直接寫百分比
- VIX 與殖利率單獨在情緒指標表
- Regime 用 `data` Callout，不用 code block
- **不寫散文鋪陳**，表格就是全部

---

### 節二：本期三則重要新聞

**目的：** 篩選 3 則最影響論點的新聞，每則一行結論。

**格式模板：**

```mdx
## 本期重要新聞

① **[公司/事件]** — 一行結論，說清楚「發生什麼 → 對什麼有影響」
② **[公司/事件]** — 同上
③ **[公司/事件]** — 同上
```

**規則：**
- 剛好三則，不多不少
- 每則不超過 40 字
- 新聞標題要白話，不寫英文縮寫（FOMC 要加「聯準會利率決策會議」說明）

---

### 節三：本期焦點（對應內部「今日議題」）

**目的：** 本次討論的核心問題是什麼，一段話鋪陳背景。

**格式模板：**

```mdx
## 本期焦點

**[議題名稱]**
[2-3 句背景：發生什麼事 → 為什麼重要 → 我們在問什麼問題]

**[議題名稱]**
[同上]
```

**規則：**
- 去掉所有內部追蹤代號（INS-001 等）
- 去掉持股數量、進場價位等私人資訊
- 以「問題意識」為主，不是結論

---

### 節四：觀點結論（對應內部「裁定」）

**目的：** 本次分析後的立場與行動方向。

**格式模板：**

```mdx
## 觀點結論

<Callout type="insight">
**[標的/主題]**
[一句話：我們怎麼看 + 邏輯核心]
觀察條件：[什麼情況會讓這個觀點改變]
</Callout>
```

**規則：**
- 每個 Callout 對應一個標的或主題
- 用行動語言（繼續持有、等待進場、暫緩觀察），不只是現況描述
- **不寫具體股數、成本價、個人倉位**
- 失效條件（觀察條件）必填

---

### 節五：深度解析（對應內部「深入討論」）

**目的：** 分析正文，給讀者最有價值的洞察。

**規則：**
- 直接繼承內部討論的表格與數據，不用重寫
- 去掉觸發者（「CEO 調度 DNI」等內部流程描述）
- 段落開頭直接進結論，不用鋪陳「本次討論由...」
- 數字表格保留，補上白話說明
- 可以有 `insight` / `warning` Callout

---

### 節六：下次關注（對應內部「檢查點」）

**目的：** 告訴讀者下一個重要節點。

**格式模板：**

```mdx
## 下次關注

| 日期 | 事件 | 關注重點 |
|---|---|---|
| MM/DD | [事件名稱] | [一句話：我們在看什麼] |
| MM/DD | [事件名稱] | [同上] |
```

**規則：**
- 只寫 3-5 個，不要全列
- 「持續監控」類的不寫，只寫有明確日期的
- 事件名稱要白話（「5 月非農就業數據」不是「NFP」）

---

## 美編規則總結

| 元素 | 內部格式 | 外部格式 |
|---|---|---|
| 市場數字 | 夾在散文裡 | **表格** |
| Regime | code block | **`data` Callout** |
| 失效條件 | 裁定文字內 | **`warning` Callout** 或表格末行 |
| 重要洞察 | 散文 | **`insight` Callout** |
| 操作裁定 | code block 條列 | **`insight` Callout，一個主題一個** |
| 內部代號 | INS-001、DNI 等 | **去掉或改白話** |

---

## 不寫什麼（外部禁止事項）

- 具體持股數量（「1 股 AVBO」）
- 成本價、進場條件價位（「$198 以下建倉」）
- 內部代號（INS-001, INS-002, GLW Week 2）
- 內部流程語言（「CEO 調度 DNI」、「carry-over 第三次」）
- 個人帳戶操作動詞（「分批出脫」改為「評估減碼」）

## 市場快照完整範例（以 2026-06-05 為例）

```mdx
## 市場快照｜2026-06-05

### 美股（6/4 收盤）
| 指數 | 收盤 | 漲跌 |
|---|---|---|
| **S&P 500** | 7,584 | +0.41% |
| **Nasdaq** | 26,831 | -0.09% |
| **Dow** | 51,561 | +1.73% |

| 情緒指標 | 數值 | 說明 |
|---|---|---|
| VIX 恐慌指數 | 15.40 | 低恐慌，市場平靜 |
| 10 年期美債殖利率 | 4.47% | 長端利率穩定 |

### 台股（6/5 收盤）
| 指標 | 數值 | 漲跌 |
|---|---|---|
| **加權指數** | 45,071 | -1.33%（-607 點）|
| **台積電** | 2,365 元 | +0.84% |

<Callout type="data">
**當前市場 Regime：** AI 資本支出週期，整體偏向 Risk-on

**今日催化劑：** 美東時間上午 8:30 公布 5 月非農就業數據，
若超預期（＞18 萬），長期利率可能快速走升，高估值科技股承壓。
</Callout>
```
