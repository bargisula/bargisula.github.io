# 結構知識層（Structures）

## 用途

存放產業結構、供應鏈地圖、市場競爭格局等較為穩定的結構性知識。

## 建議格式

每份文件包含：
- 供應鏈層次圖（文字描述或 Mermaid）
- 關鍵玩家與各自角色
- 定價機制與週期規律
- 歷史結構性轉變
- 與 mechanisms/ 的連結（哪些衝擊會打到這個結構的哪個節點）
