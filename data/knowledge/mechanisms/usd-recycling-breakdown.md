## 核心命題

美元體系的穩定依賴「美元回流閉環」：美國進口 → 美元流出 → 貿易盈餘國（日、中、海灣）持有美債 → 美元回流 → 美國低成本融資。

當這個閉環在多個節點同時斷裂，美國必須靠**更高殖利率**（而非美元霸權紅利）才能賣出同等數量的債，形成長期增長稅，且有財政主導陷阱風險。

**這是結構性退潮，不是週期性波動。**

---

## 三條拋債動機（同時啟動）

```
A. 通膨預期升高       → 持債者拋售（實質報酬惡化）
B. 去美元化           → 央行儲備多元化拋售（戰略轉向）
C. EM 匯率危機        → 緊急拋售保護幣值（土耳其型）
```

A/B/C 三條動機的**來源不同，但結果相同**：美債邊際需求下降，殖利率必須上升以清算供需缺口。

---

## 美元回流閉環的三個斷裂點

| 節點 | 歷史狀態 | 現在 |
|---|---|---|
| 中國 | 出口盈餘大量回流美債 | 戰略轉向，減持美債至2008年以來最低 |
| 日本 | 最大持債國，長期穩定持有 | 防衛日圓，持續減持（2026/3月單月-477億） |
| 海灣產油國 | 石油美元協議：油以美元計價，盈餘回流美債 | 部分轉向人民幣結算，石油美元機制鬆動 |

## 傳導鏈

```
觸發：外資官方儲備機構大規模撤出美債
  │
  ├─ 需求側缺口 → 殖利率上升（term premium 擴大）
  │     10Y: 4.6%、30Y: 5.2%+（2026/5，2007年以來最高）
  │
  ├─ Fed 政策壓力：
  │     通膨數據惡化（CPI 3.8%、PPI 6.0%）
  │     × 新主席 Warsh（鷹派文化）就任
  │     × 鴿派 Waller 轉向（就任同日）
  │     → Fed 升息機率 70%（CME, 2026/5）
  │
  ├─ 財政滾債成本暴增：
  │     更高利率 × 龐大存量債務
  │     → 利息支出占財政比例上升
  │     → 財政赤字更難收斂
  │
  └─ 路徑分叉：
        A. 更高殖利率自我清算（通縮性緊縮）
             → 壓抑資本投資、房地產、消費信貸
             → 長期增長速度下降
        B. Fed 被迫貨幣化（QE 救債市）★
             → 通膨惡化
             → 實質利率更負
             → 更多外資撤退（惡性循環）
             → 財政主導陷阱（歷史上極難退出）

★ B 路徑是市場當前低估的尾部風險
```

## 政策選項評估

### 選項一：增加石油供給（壓低通膨預期）

**有效但有限：**
- 打供給端，方向正確
- 但 energy→PCE Wave 2（食品/化肥，6-26週）已在傳導中，油供增加壓不住這一波
- 頁岩油經濟性下限約 WTI 60 美元，增產空間受限
- 時間差：大規模增產需 6-12 個月

### 選項二：關稅（減少赤字）

**無效，且可能反效果：**
- 關稅解決的是**貿易赤字**，財政赤字靠稅收與支出結構，兩個不同缺口
- 關稅實質是消費稅，短期推高通膨，讓 Fed 更難降息
- 報復性關稅壓縮出口 → 稅基縮小 → 財政赤字可能更大

### 選項三：強制各國投資美國（Mar-a-Lago Accord 思路）

**短期有效，長期加速自我毀滅：**
- 用貿易/安全槓桿迫使盟友買美債（強制石油美元回流）
- 被脅迫的流入是脆弱的，槓桿失效即刻反轉
- 非被脅迫國家（中、俄及陣營）去美元化步伐加快
- 對比：1970s 石油美元協議是自願合作（沙烏地利益一致），現在靠脅迫，品質截然不同

### 唯一真正的出口：AI 生產力紅利

```
若 GPT 第二階段（2028-2035）TFP 增速大幅提升
  → 稅基擴大
  → 財政赤字靠成長稀釋
  → 不需要靠貨幣化或外部強制買盤

但時間差是問題：
  債市壓力：現在（2026）
  AI 生產力紅利：2028 年後
  危險視窗：2026-2028（最需要警戒）
```

## 歷史先例

### 英國 2022 LDI 危機
- 觸發：Truss 政府擴張性財政預算 → 英國公債殖利率急升 → 養老基金保證金 call → 強制平倉 → 殖利率進一步急升
- 結局：英格蘭銀行緊急介入 QE，Truss 下台
- 類比含義：**財政主導陷阱可以在幾週內引爆**，不是緩慢發展

### 日本 YCC（殖利率曲線控制）2022-2024
- 觸發：全球通膨升溫，日本試圖人工壓住殖利率上限
- 結局：2024 年被迫放棄 YCC，10 年期殖利率從 0.25% 上升至 1.5%+
- 類比含義：**貨幣化（B 路徑）只能延緩，無法避免最終調整**

### 1970 年代美國滯脹
- 觸發：越戰財政赤字 + 石油衝擊 + 尼克森關閉黃金窗口
- 結局：Volcker 升息至 20% 才打破通膨預期
- 類比含義：**若通膨預期失錨，所需的修正利率遠高於市場預期**

## 已知缺口

- **石油美元替代速度**：海灣產油國轉向人民幣結算的實際比例尚無完整數據
- **美國財政赤字的政治上限**：國會在什麼壓力下才真正削減支出，難以預測
- **AI 生產力紅利的量化**：GPT 第二階段對 TFP 的實際貢獻，2028 年前無法驗證
- **Warsh 的實際升息節奏**：鷹派文化不等於激進行動，需觀察首次 FOMC
