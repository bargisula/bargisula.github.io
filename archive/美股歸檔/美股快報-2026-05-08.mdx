NFP 出來了，市場得到了它想要的答案。

**+115,000 個工作機會，預期只有 62,000。** 遠超預期，但沒有熱到讓 Fed 重新拿起升息大棒。失業率 4.3% 原地不動。盤前三大期指同步走高——市場把這份數據當成「Goldilocks」來喝彩。

但油價 $110、中東戰火未熄、下週 Trump-Xi 峰會——Goldilocks 坐在一個有熊的森林裡。

## 🧠 今日三件事

<Callout type="insight" title="① NFP +115K vs 預期 62K——Goldilocks 劇本成立">

**四月就業報告是今日最大變數，已確認：超預期但不過熱。**

- 新增就業 **+115,000**（預期 +62,000，前月 +228,000 下修至 +185,000）
- 失業率 **4.3%**（原地不動，符合預期）
- 薪資月增 **+0.3%**（未過熱）
- 強項：醫療 +37K、運輸倉儲 +30K、零售 +22K
- 弱項：聯邦政府 −9K、科技業 −13K、製造業 −2K

**解讀框架：**

| 數字解讀 | 市場含義 |
| :--- | :--- |
| 就業強→不是衰退 | 「軟著陸」敘事存活，risk-on 有底氣 |
| 就業不算爆熱 | Fed 不需要升息，降息預期不會大幅後退 |
| 科技 −13K | 科技業仍在精簡，但不影響 AI 資本支出邏輯 |

Fed 四月 28-29 日維持利率 3.5–3.75%，並出現 1992 年以來最多的四票反對——三票反對「降息偏向」措辭，一票主張立即降息。這份 NFP 給了就業韌性的背書，但強度不足以改變 Fed 路徑。

**短期方向：看多。就業韌性 + 半導體共振 + 外交對話 = 三重利多並行。**

</Callout>

<Callout type="insight" title="② 半導體雙彈：AMD +16%、SMCI 毛利修復">

**AMD Q1 2026 財報（週二公布）——破圈的數字：**

| 指標 | 實際 | 預期 |
| :--- | ---: | ---: |
| **調整後 EPS** | $1.37 | $1.29 |
| **營收** | $10.25B | $9.89B |
| **資料中心營收** | **$5.8B** | — |

資料中心年增 **57%**，不是跟著 NVIDIA 沾光——是 AMD 自己在雲端大廠（AWS、Meta、Microsoft）拿下實際工作負載。MI300X 進入生產環境的訊號愈來愈多，AI 算力市場「雙雄格局」正在確立。

**SMCI Q3 FY2026（週一公布）——毛利修復才是主角：**

| 指標 | 實際 | 預期 |
| :--- | ---: | ---: |
| **調整後 EPS** | $0.84 | $0.62 |
| **營收** | $10.2B | $12.39B |
| **毛利率** | **10.1%** | — |

EPS 超預期 35%，營收 miss——但市場給 **+18~20%** 的反應，因為毛利從上季 6.4% 回升至 10.1% 是過去一年最受質疑問題的答案。定價權回來了。

**產業瀑布（半導體雙彈帶出的第二、三層）：**

```
AMD + SMCI 需求確認
    │
    ▼ 第二層（上游受益）
    MU Micron — HBM 需求擴散至非 SK Hynix；盤前 +4.1%
    INTC Intel — AI PC + 伺服器 CPU 同步受益；盤前 +4.5%
    │
    ▼ 第三層（基礎設施）
    散熱 / 液冷廠（機架密度提升）
    電力 / 資料中心 REIT（高密度算力耗電增加）
    銅線 / 光模組（高頻寬互連需求）
```

</Callout>

<Callout type="warning" title="③ 地緣複合風險：油價 $110 + Trump-Xi 峰會下週登場">

**美伊衝突持續：** 中東局勢緊張，WTI 原油現價約 $110/桶。油價維持高位意味著：
- 通膨壓力不消失 → Fed 降息更難
- 航空、物流、化工類股成本承壓
- 能源股（XLE）短期有支撐，但若全球需求放緩則翻臉

**下週 Trump-Xi 峰會（傳聞 5/14–15 北京）** 是今年最大地緣政治事件之一：
- 90 天停火延伸的關稅協議到期壓力升高
- 晶片出口鬆綁的傳言是「峰會前熱身」還是真正鬆綁？
- QCOM、NVDA 逾 60% 中國營收曝險直接受峰會影響

| 峰會結果情境 | 半導體股反應 |
| :--- | :--- |
| 達成框架協議、鬆綁具體化 | QCOM / NVDA / AMD 再漲一波 |
| 「友好但無結論」 | 已 price-in，震盪回吐 |
| 破局或川普推文施壓 | 快速回調，本週漲幅存疑 |

**下週半導體的走勢，很可能取決於峰會後的第一篇聲明。**

</Callout>
